เลขสไลด์ = เลขหน้า PDF (69 หน้า — ตั้งแต่หน้า 8 เลขที่พิมพ์บนสไลด์จะมากกว่า)

0. เป้าหมาย (สไลด์ 1–2)

  • สร้าง+ใช้ function | อธิบาย OOP ใน JS | อธิบาย HTML DOM | ใช้ OOP + DOM เขียนโปรแกรม JS

1. Function (สไลด์ 3–7)

  • ⭐ ทำไมใช้: Reusability (เรียกซ้ำ) | Modularity (แตกปัญหาใหญ่) | Organization (จัดโครง) | Maintainability (แก้แค่ function นั้น)
  • 6 ชนิดในบท: Function, Constructor, First Class, High-order, Callback, Arrow
  • ไม่ return showMessage() → alert | return sum(a, b) → a + b (sum(2,3) = 5)
  • ข้อมูลที่ส่งเข้า = Parameters / Arguments | ⭐ default value text="no message" → showMessagefromuser("Ann") → Ann: no message

2. Arrow function (สไลด์ 8–9)

  • ⭐ let func = (arg1, ...argN) => expression = function (...) { return expression; }
  • let sum = (a,b) => a + b; | ไม่มี parameter → () => alert("Hello!") | ⭐ หลายบรรทัด → ต้อง { } + return (subtract(5,3) → 2)

3. Constructor function (สไลด์ 10–13)

  • กลไกสร้าง object หลายตัวที่มี property ชุดเดียวกัน | สร้างแบบ function ปกติ
  • ⭐ เรียกด้วย new | this = object ที่กำลังสร้าง | ค่าเริ่มผ่าน parameter | function ข้างใน: public = this, private = var/let
  • function Person(firstName, lastName, age) { this.firstName = ...; this.getInfo = function(){...} } → new Person("Wudhichart","Sawangphol",30) → getInfo() = Wudhichart Sawangphol Age is 30
  • เพิ่ม property on the fly ได้ | inherit constructor function อื่นได้ (⚠️ "See example." แต่ PDF ไม่มีตัวอย่าง)

4. First-class function (สไลด์ 14–18)

  • ⭐ = function ถูกปฏิบัติ เหมือนตัวแปร (ใช้ดีใน functional programming) → 4 อย่าง:
ทำได้ ตัวอย่าง → ผล
assign ให้ตัวแปร var function2 = function (wide) {...Math.pow(wide,2)} → function2(3) = 9
ส่งเป็น argument flexible(sumFunction, 3, 4) → 7
return ออกมา calculateAreaofSquare2(4) คืน arrow → เรียก → calculateAreaofSquare2: 16
เก็บใน data structure myFuncs[0](5) → calculateAreaofSquare: 25 (⚠️ ใช้ function ที่นิยามในสไลด์ 19)

5. High-order function (สไลด์ 19–20)

  • ⭐ = รับ function เป็น argument หรือ return function
  • [2,7,9,10].map(calculateAreaofSquare) (ส่งไม่ใส่ ()) → Map: 4,49,81,100
  • .filter((num) => num % 2 === 0) → evenNumbers: 2,10

6. Callback function (สไลด์ 21–22)

  • ⭐ ตอบสนอง event/action ที่ asynchronous หรือคาดเดาไม่ได้ | API = library ของ object + method | function ที่เราเขียนส่งให้ API = callback
  • setTimeout(greet, 2000) → ครบ 2 วินาที API เรียก greet() → alert "Howdy!" | ⚠️ สไลด์ใช้ smart quote ’ → SyntaxError

7. Scope & Lifetime (สไลด์ 23–29)

  • function ≈ แผนกในสำนักงาน | lexically scoped ยกเว้น var | ⭐ ประกาศนอก function = Global (ทั้งหน้า) | ใน function = Local (ทั้ง function) | scope ควรเล็กที่สุด
  • ⭐ let/const = block-scoped | var = function ที่ใกล้ที่สุด หรือ global
⭐ โค้ด ผล
if (true) { const myName = "Wudhichart"; console.log(myName) } Wudhichart
+ console.log(myName) นอก if (สไลด์ 25) ReferenceError: myName is not defined
var myFullname ใน if แล้ว log นอก if ใน function เดียวกัน (สไลด์ 26) ไม่ error → Wudhichart Sawangphol
const ใน <script> ธรรมดา แล้วใช้อีก <script> (Global) Wudhichart Sawangphol
const jidapa ใน <script type="module"> แล้วใช้ script อื่น ReferenceError (module มี scope ของตัวเอง)
  • ⭐ Lifetime: Global = ประกาศ → ปิดหน้าเว็บ | Local = function ถูกเรียก → function จบ | ชื่อซ้ำ → ใช้ local

8. Closure (สไลด์ 30)

  • ⭐ function + references to variables defined outside of it → เข้าถึงตัวแปรนอก scope ได้แม้ function นอกจบแล้ว
  • displayFullname(name) คืน () => console.log(name) → printFullname() → Wudhichart Sawangphol

9. OOP: class & object (สไลด์ 31–38)

  • OOP = แทนสิ่งของจริง (รถ คน บัญชี) | กำหนด data type ของ data structure + function ที่ใช้กับมัน
  • ⭐ Class = template/model (properties + functions) | Object = class ที่เติม values มีทุก property/method | สร้าง = instantiation
  • Instructor: properties firstName, lastName, subjects | methods sayHello(), teach() | objects: swudhichart, kjidapa, ppisit
  • ⭐ syntax class X { constructor(p1,...){ this.p1 = p1; } method1(){} } | constructor ถูกเรียกทุกครั้งที่สร้าง object | ใส่ใน <script type="application/javascript">
  • ⭐ ต้องนิยาม class ก่อน สร้าง object | let obj = new X(...) | อ่าน/แก้ obj.propName | เรียก obj.methodName()
  • ⭐ OUTPUT สไลด์ 38 (kjidapa, subjects ["HTML","OOP:JS"], เปลี่ยน firstName เป็น "Aj. Pa"): Jidapa Kraisangka / Aj. Pa / Hey! I'm Aj. Pa. Nice to meet you!!! / I teach HTML,OOP:JS. (array ต่อ string คั่น , ไม่มีเว้นวรรค)
  • ⚠️ กล่อง object ในสไลด์เขียน "JS:OOP" / Hey! I am ...!! แต่โค้ดจริง "OOP:JS" / Hey! I'm ...!!! → ตอบตามโค้ด

10. Inheritance & Polymorphism (สไลด์ 39–42)

  • ⭐ subclass ได้ ทุก property+method ของ superclass (inheritance) + มีของเฉพาะตัว (polymorphism ตามสไลด์)
  • ⭐ class Sub extends Super { constructor(...){ super(cprop...); this.scprop = ...; } } — define แค่ method เฉพาะ subclass | ต้องนิยาม superclass ก่อน
  • UnivInstructor extends Instructor: super(_firstName,_lastName,_subjects) + university, campus, getUniversity() (⚠️ กล่องเขียน "UniInstructor")
  • ⭐ OUTPUT สไลด์ 41 (kjidapa2, Mahidol University, Salaya): Jidapa@Mahidol University / Hey! I'm Jidapa. Nice to meet you!!! / I teach HTML,OOP:JS. / My office is at Mahidol University, Salaya.
  • ⭐ OUTPUT สไลด์ 42: kjidapa2.nickName → undefined (ไม่ error) | ตั้ง "Pa" → Pa (on the fly) | kjidapa2.sayMyName() → TypeError: kjidapa2.sayMyName is not a function → script หยุด | ถ้าไม่หยุด → I am Jidapa or Pa

11. DOM (สไลด์ 43–49)

  • ⭐ DOM = มาตรฐาน W3C | programming interface ให้ script เข้าถึง/อัปเดต content, structure, style แบบ dynamic
  • 3 ส่วน: Core DOM (structured document ทุกชนิด) | XML DOM | HTML DOM
  • HTML = tree of objects | เข้าถึงทุก element/text/attribute | แก้/ลบ/สร้างใหม่ได้ | ⭐ platform & language independent (Java, JavaScript, Python)
  • ⭐ Everything is a node: document | element (ทุก tag) | text | attribute | comment (สี: น้ำเงิน document, ดำ element, แดง text, เขียว attribute)
  • ⭐ ความสัมพันธ์: <head> parent ของ <title> | <h1> กับ <p> = siblings | <html> = ancestor ของทุก text node (text = descendant)

12. document & element methods (สไลด์ 50–54)

  • JS จัดการได้ทุกส่วน: element, attribute, event, CSS ผ่าน document
⭐ Document method คืน
getElementById() element ตัวเดียว ตาม ID
getElementsByClassName() / getElementsByTagName() NodeList หลายตัว
querySelector() element ตัวแรก ที่ตรง selector
querySelectorAll() static NodeList ทุกตัวที่ตรง
write() / writeln() เขียนลงเอกสาร / + newline
  • Element object = opening tag + attribute(s) + text + closing tag (<h1 style="color:blue;">DOM Lesson one</h1>)
  • ⭐ innerHTML (HTML ของลูกหลาน) | textContent (ข้อความตัวมัน+ลูกหลาน) | nodeValue | childNodes (live NodeList) | firstChild (หรือ null) | getRootNode()

13. หา / เพิ่ม / ลบ / attribute (สไลด์ 55–61)

  • ⭐ getElementById("div_content") (ไม่มี #) = querySelector("#div_content") (มี #) → textContent This is sample text. (⚠️ สไลด์ 56 smart quote)
  • ⭐ ByClassName("colors") วน for ต่อข้อความ → This is sample text.Color: R G B (ไม่มีเว้นวรรคหลัง text.) + R G B
  • ⭐ ByTagName("span") เติม i: → 0:Red 1:Green 2:Blue | ⚠️ สไลด์ว่า NodeList / "format of array" — Chrome ได้ HTMLCollection (ตอบตามสไลด์)
  • ⭐ เพิ่ม: innerHTML = "<p>First</p>" หรือ createElement("p") + createTextNode("Second") → p2.appendChild(txt) ก่อน → divDemo.appendChild(p2) (ลูกตัวสุดท้าย) → <div><p>First</p><p>Second</p></div>
  • ⭐ ลบ: parent.removeChild(child) — หา child ให้ถูกก่อน → ลบ Green เหลือ Red, Blue
  • ⭐ attribute: spanColor[i].setAttribute("class","colors") → span ทุกตัวได้ class="colors"

14. Events (สไลด์ 62–67)

  • ⭐ event = สิ่งที่ browser ทำ หรือ ผู้ใช้ทำ
กลุ่ม events
เมาส์ onclick, ondblclick, onmousedown (กด), onmouseup (ปล่อย), onmousemove, onmouseover (เข้า), onmouseout (ออก)
คีย์ onkeydown (กดลง), onkeypress (กดแล้วปล่อย), onkeyup (ปล่อย)
ฟอร์ม onchange (select ใหม่ / text แก้แล้วเสีย focus), onfocus, onsubmit, onreset, onselect (input/textarea)
หน้า onload (element+ลูกโหลดเสร็จ), onunload, onresize, onabort (โหลดรูปถูกขัด)
  • ⭐ Sum: <button onclick="sum()"> → parseFloat(...value) ×2 → บวก → .value ช่อง sum → 3 + 5 = 8
  • ⭐ Mouse div: over → I put my mouse OVER this! | out → This is me!!!! | down → I am pressing... + เขียว | up → This is me!!!! + แดง
  • ⭐ JS: element.addEventListener("click", MyClick) (ไม่มี on, ไม่ใส่ ()) | ⚠️ สไลด์ 67 smart quote

15. Wrap Up & References (สไลด์ 68–69)

  • JS = ภาษา OOP (class เอง / pre-defined) | HTML = tree ของ element | DOM → จัดการทุก element ด้วย method/property
