0. Unit + เป้าหมาย (สไลด์ 2–4)

  • Part I Intro (Hello World, Module System, first server) | Part II Express | Part III Cookies, Session, Database
  • เป้า: เข้าใจ Node | ใช้ Node modules พื้นฐาน | สร้าง web server from scratch

1. Front/Back-end, Client/Server-side (สไลด์ 5–6)

  • Front-end = HTML, CSS, JS | Back-end = Database, API, Framework | ทั้งคู่ = Full-stack
  • ⭐ Client-side = HTML/CSS/JS รัน ใน browser | Server-side = เลือกเนื้อหาตอบ request, ภาษา PHP, Python, Ruby, C#, Node.js | เข้าถึง OS + file system ได้เต็มที่

2. Request / Response 6 ขั้น (สไลด์ 7–8)

  • ⭐ #1 browser ส่ง HTTP GET → #2 web server ดูว่า resource อยู่ไหน (static #7 = CSS/JS/images → ข้ามไป #5) → #3 dynamic → web app อ่าน database (request data: URL encoding, GET/POST data, cookies) → #4 รวม data + HTML templates → #5 ส่ง response HTML → #6 client ได้หน้า HTML

3. Server, IP, Port (สไลด์ 9–10)

  • IP: 10.34.111.111, localhost | Port: 3000, 8080, 8081 | รูปตึก: IP ≈ ที่อยู่ตึก, port ≈ ห้อง
  • ตัวอย่างจอ nodemon: Running at Port 3000, Request made at /mypage → 404: Invalid accessed, /shabu, /bbq | port 8080 + Connected DB: tinycollege, 6 rows → insert ITCS-223 → 7 rows

4. Node.js คืออะไร (สไลด์ 11–12)

  • ⭐ asynchronous JavaScript runtime built on Chrome's V8 | "open-source server environment"
  • ⭐ No DOM, no document/window, no Cookies | มี JS + Modules: File system, HTTP, Utilities

5. Architecture (สไลด์ 13–15)

  • ⭐ Single thread event loop: main thread รับ request → ส่งไปหน่วยที่เหมาะ (File System / Database / Computation) → ไม่รอ = non-blocking รับ request ถัดไป → หน่วยเสร็จ → thread ตอบกลับ

6. Node.js Facts (สไลด์ 16)

  • ✅ highly-scalable, data (I/O) intensive, real-time | JavaScript all the time | JSON APIs | ⭐ ❌ computation-intensive

7. Getting started + Hello World (สไลด์ 17–19)

  • ติดตั้ง LTS จาก nodejs.org | เช็ก node --version (สไลด์: v24.21.0)
  • เขียน .js → เปิด CLI ไปที่ directory → node filename.js → ดูผลใน command line หรือ browser
  • helloworld.js → Hello World!! / In the command line
  • ⭐ console.log() ใน Node ไม่ใช่ window.console.log() — Node ไม่มี window

8. Global objects (สไลด์ 20)

  • ใช้ได้ทุก module โดยไม่ import: __dirname, __filename, exports, module, require(), console.log(), process | ⭐ global = global namespace
  • ⭐ __dirname = โฟลเดอร์ปัจจุบัน | __filename = full path รวมชื่อไฟล์ | global.console.log(message) → Sam I am

9. Module (สไลด์ 21–24)

  • ⭐ ทุกไฟล์ JS = module | ของข้างใน local / private | ฟังก์ชันชื่อซ้ำคนละไฟล์ไม่ทับกัน (file1/file2 มี sayHello ทั้งคู่)
  • ⭐ module.exports 3 แบบ:
แบบ โค้ด ใช้
Literal (msg.js) module.exports="Hello World!" msg
Object (ictgreet.js) module.exports.greetICT = message ictgreet.greetICT
Function (hello.js) module.exports.sayHi = sayHello eng.sayHi() (ไม่ใช่ sayHello)
  • ⭐ greet.js: require("./hello"), require('./message/ictgreet'), require('./message/msg') → output Hello / Hello World! / Hello ICT
  • ⚠️ สไลด์ 24 มี smart quote (”, ’) → copy ไปรันได้ SyntaxError

10. Built-in modules (สไลด์ 25)

  • Path, URL, File System, HTTP | ref: nodejs.org/docs/latest/api/

11. Path (สไลด์ 26–28)

  • path ต่างตาม OS → ให้ module จัดการ
  • path.resolve(__filename) → /Users/jidapa.kra/Documents/demo/path.js | path.extname → .js | path.join(__dirname,'test.js') → .../demo/test.js
  • ⭐ path.parse() → root '/' | dir '/Users/jidapa.kra/Documents/demo' | base 'path.js' | name 'path' | ext '.js'

12. URL (สไลด์ 29–31)

  • parse ด้วย new URL('...') ได้ URL object
  • ส่วนของ URL: protocol, username/password (auth), hostname, port, host = hostname:port, origin, pathname, search (query), hash, href
  • ⭐ https://www.covid19.com:8080/p/a/t/h?country=TH&time=now →
property ค่า
protocol https:
host www.covid19.com:8080
port 8080
pathname /p/a/t/h (comment สไลด์เขียน /P ผิด)
search ?country=TH&time=now
searchParams URLSearchParams { 'country' => 'TH', 'time' => 'now' }
searchParams.get('time') now

13. File System (สไลด์ 32–40)

  • ⭐ คู่ async / Sync: read readFile | create appendFile | write writeFile | delete unlink | rename rename (+Sync)
  • ⭐ Sync = blocking (JS ที่เหลือรอจน read/write เสร็จ) | Async preferred
  • สไลด์ 34: async fs.writeFile → other work → done → callback | sync fs.writeFileSync → waiting → done → resume execution
  • fs.readFile(path, "utf8", function(err, contents){...}) — err → Error:, ไม่ err → พิมพ์ contents (Hello This is README.txt (#1))
  • ⭐ readFile 3 ไฟล์ async → ลำดับไม่แน่นอน (สไลด์ 37 รัน 4 ครั้ง ได้ 4 แบบ)
  • ⭐ ต้องการลำดับ: Sync version | nested callback | Promise / Async-Await (เลี่ยง callback hell)
  • fs.readFileSync(path,"utf8") → return ค่าเลย → ลำดับ 1→2→3 เสมอ
  • ⭐ nested callback → ลำดับแน่นอน แต่ บันได }) = Callback Hell อ่านยาก ดูแลยาก NOT a good practice
  • output ที่เรียงถูก: Hello This is README.txt / README2.txt with some content / I have another README file (#3)

14. HTTP module (สไลด์ 41–42)

  • Node ส่งข้อมูลผ่าน HTTP | สร้าง HTTP server ที่ listen port และตอบ response เมื่อมี request

15. Simple server (สไลด์ 43–49)

  • server รับ request ส่ง response — เป็น plain text, HTML pages, JSON object ได้ | localhost, port 8081, http://localhost:8081
  • ⭐ ขั้นตอน: require("http") → http.createServer((req,res)=>{...}) (ทำงานทุก request) → res.statusCode = 200 (OK) → res.setHeader("Content-Type","text/plain") → res.write("Hello World!") → res.end() → myServer.listen(8081, ()=>console.log("Listening on the port 8081")) (bind localhost:8081)
  • รัน node myFirstNodeServer.js → Listening on the port 8081 → เปิด browser → Hello World! | Ctrl+C หยุด
  • ⚠️ สไลด์ 49 พิมพ์ http:/locahost:8081 ผิด | log "The new request comming" ไม่มีในโค้ดสไลด์ 45–48

16. req / res (สไลด์ 50)

  • ⭐ req.url, req.method → เปิด localhost:8081 ได้ url /, method GET, url /favicon.ico, method GET
  • browser ได้ Request made! (ภาพสไลด์เขียน "Request maded" ผิด)

17. Routing (สไลด์ 51–55)

  • route ตาม req.url | http://localhost:8081/bbq → req.url = "/bbq"
  • ⭐
