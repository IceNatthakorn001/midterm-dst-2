ภาค 1: Internet & WWW

1. Internet คืออะไร (สไลด์ 3–6)

  • ⭐ เครือข่าย ใหญ่ที่สุดในโลก | ใช้มาตรฐานเดียวกัน TCP/IP | เกิดจาก American research and defense work ช่วง 1970's–1980's
  • ⭐ 1966 ARPA | 1969 ARPANET node แรก (UCLA) | 1973 เชื่อมต่างประเทศ | 1974 TCP design | 1983 DNS | 1990 ARPANET ปิด + เกิด WWW
  • Apps: Communication & Social (Gmail, FB, IG, Outlook, Twitter, LINE) | Knowledge (Wikipedia, Stack Overflow, CNN, Google, w3schools) | Business & Services (Agoda, Grab, SCB, Netflix, Lazada)

2. Internet ทำงาน + องค์ประกอบ (สไลด์ 7–8)

  • google.com → ได้ IP 74.125.71.102 → ข้อมูลแบ่งเป็น packet วิ่งผ่านหลาย Network ไป server ปลายทาง (ทุกจุดใช้ TCP/IP)
  • ⭐ Client = request | Server = response (web/mail server) | Network: Router/gateway เชื่อม 2 network, Firewall ดูแลความปลอดภัย

3. TCP/IP (สไลด์ 9)

  • ⭐ TCP = แบ่งข้อมูลเป็น packet + ประกอบกลับ | IP = ส่ง packet / routing ถึงปลายทาง

4. IP / Port / DNS (สไลด์ 10–12)

  • IPv4 และ IPv6 | ⭐ IPv4 ###.###.###.### แต่ละส่วน 0–255 (2⁸) | cnn 64.236.16.116 | yahoo 64.58.76.179 | ebay 216.33.156.119
  • ⭐ IP = ตึก, port = เลขห้อง | HTTP 80 | FTP 21 | Telnet 23 | SMTP 25
  • Domain name = IP ในรูปชื่อ, โครงสร้าง hierarchy (.com .edu .gov .org .th; root . → .th → .ac → .mahidol → www/student)
  • ⭐ DNS จับคู่ IP ↔ domain เช่น www.google.com. = 66.249.89.104

5. WWW (สไลด์ 13–17)

  • ⭐ World Wide Web = "the Web" | 1992 Tim Berners-Lee | บริการข้อมูลหนึ่งใน Internet | navigation ด้วย hyperlinks | ใช้ HTTP
  • ⚠️ สไลด์ 5 ว่า WWW เกิด 1990 แต่สไลด์ 14 ว่า introduced 1992
  • Web Server (+ Web pages เช่น HTML) | Web Client (+ Web browser) | Browser → HTTP Request → Server → Response (html)
  • ⭐ URL http://john:secret@www.example.com:8080/demo/index.html = protocol | username:password | domain name | port | path
  • Browser แปลคำสั่ง HTML (+CSS) แล้วแสดงผล

6. Develop a Web Page (สไลด์ 18–19)

  • Front-end: HTML, CSS, JavaScript | Back-end: Database, API, Framework | Full-stack = ทั้งคู่
  • วิชานี้: Front-end (HTML, CSS, JS Part 1–3) → Back-end (Web Service, Node.js Part 1–3, Web Service with Node.js) → Trends (React)

ภาค 2: HTML Part I

7. HTML (สไลด์ 21–25)

  • ⭐ HyperText Markup Language | ภาษาหลักของเว็บ | markup tags บอก browser | ไฟล์ .html / .htm
  • เขียนด้วย plain text editor (VS Code, Notepad, Notepad++) → เปิดด้วย browser ใดก็ได้
  • ⭐ 1991 Tim Berners-Lee สร้าง | 1995 HTML2 | 1997 HTML3 | 1999 HTML4 | 2000 XHTML | 2014 HTML5 | 2017 HTML5.2

8. กฎ Tag (สไลด์ 26–30)

  • Content + Tag (Element): <tag-name>Content</tag-name> (opening / closing)
  • ⭐ case insensitive (นิยมตัวเล็ก) | ⭐ nested ได้ ห้าม overlap
  • ⭐ ไม่ต้องปิดทุกตัว เช่น <br> | unknown tags ignored (ไม่ error เพื่อเพิ่ม tag ใหม่ในอนาคตได้)
  • Attribute อยู่ใน opening tag name="value" เช่น <html lang="en"> | ดู reference ที่ W3School
  • ⭐ ค่า attribute ต้องมี quote เสมอ | double นิยมสุด | ค่ามี " ข้างใน → ต้องใช้ single: value='John "ShotGun" Nelson'

9. โครงเอกสาร (สไลด์ 31–33, 37)

Tag หน้าที่
⭐ <!DOCTYPE html> สิ่งแรกสุด ก่อน <html>
<html> container ของทุก element (ยกเว้น DOCTYPE)
<head> title, scripts, styles, meta
<body> เนื้อหาที่แสดง: text, links, images, tables, lists
<title> ชื่อบน browser toolbar
  • Tip: เริ่มด้วย DOCTYPE, html, head, title, body เสมอ | indent element ที่ซ้อนกัน

10. Comment & Validation (สไลด์ 34–35)

  • ⭐ <!-- comment --> (! แค่หลัง < ตัวเปิด) | browser ignore
  • validator.w3.org | ตัวอย่าง error: head ขาด title

11. h / p / br (สไลด์ 36–41)

  • ⭐ h1 ใหญ่สุด, h6 เล็กสุด | browser เพิ่มบรรทัดว่างก่อน-หลังหัวข้อ
  • <p> ย่อหน้า | ⭐ เว้นวรรคหลายครั้ง → เหลือวรรคเดียว | ขึ้นบรรทัดใหม่หลังย่อหน้าอัตโนมัติ
  • ⭐ Enter ในโค้ด ไม่มีผล ("Hello, I want a new line." บรรทัดเดียว) | <br> ขึ้นบรรทัด ณ ตำแหน่งนั้น ไม่มี closing tag
  • <p>This <br>is a para<br>graph with line breaks</p> → This / is a para / graph with line breaks

12. Hyperlinks (สไลด์ 42–46)

  • ⭐ <a> (Anchor) + href | ในหน้าเดียวกันหรือระหว่างหน้า | <a href="https://mycourses.ict.mahidol.ac.th/"><h1>MyCourses</h1></a>
  • ⭐ Absolute = URL เต็ม href="http://www.google.com" | Relative = เทียบจากเอกสารปัจจุบัน href="1_headings.html"
  • ⭐ Email: <a href="mailto:abc@example.com">Send Email</a>

13. Lists (สไลด์ 47–51)

  • ⭐ <ol>+<li> = มีเลข | <ul>+<li> = จุด | <dl>+<dt>(คำ)+<dd>(คำอธิบาย)
  • Nested: <ul> ลูกอยู่ใน <li> ของแม่ | <a> ใส่ใน <dt> ได้ | tag ส่วนใหญ่ซ้อนกันได้

14. Images (สไลด์ 52–55)

  • ⭐ <img src="URL"> ไม่มี closing tag | src = URL หรือ path (เช่น Images/Usagi_Clap.gif)
  • GIF Graphic Interchange Format | JPEG Joint Photographic Experts Group | PNG Portable Network Graphics | SVG Scalable Vector Graphics
  • ⭐ alt = อธิบายรูป → accessible (screen reader) | <img> ใน <a> = clickable image
  • ⚠️ สไลด์ 53 พิมพ์ <imgsrc="URL"> ตกเว้นวรรค

15. Character Entities (สไลด์ 56–59)

  • ⭐ & + name หรือ #number + ; | < = &lt; หรือ &#60; | ⭐ case sensitive
ตัว entity number
nbsp &nbsp; &#160;
< &lt; &#60;
> &gt; &#62;
& &amp; &#38;
" &quot; &#34;
' &apos; &#39;
¢ £ ¥ § &cent; &pound; &yen; &sect; 162, 163, 165, 167
© ® × ÷ &copy; &reg; &times; &divide; 169, 174, 215, 247

16. Table (สไลด์ 60–65)

  • ⭐ <table> | <tr> แถว | <td> ช่อง | ข้อมูล/tag อื่นต้องอยู่ใน <td> เท่านั้น
  • ⭐ default ไม่มีเส้นขอบ → ต้องกำหนด border (table, tr, th, td { border: 1px solid black; })
  • ⭐ <th> = heading cell bold + center อัตโนมัติ
  • Empty cell: <td>&nbsp;</td> | ⭐ colspan="3" = กว้าง 3 คอลัมน์ไปขวา | rowspan="2" = สูง 2 แถวลงล่าง
  • ตัวอย่าง Usagi: <td rowspan="3">รูป + <th colspan="3">หัว → แถว 2–3 เขียนแค่ 3 เซลล์ (⚠️ ป้ายสไลด์เรียกช่องรูปว่า header cell แต่จริงเป็น <td>)

17. Style Guide (สไลด์ 66–67)

  • ⭐ <!DOCTYPE html> | ปิดทุก element ที่ปิดได้ | ชื่อ element/attribute ตัวเล็ก | double quote เสมอ | blank lines & indentation | spaces & equal signs (href="..." ไม่เว้นวรรครอบ =)
  • อ่านเพิ่ม: w3schools, validator.w3.org, learn.shayhowe.com

คู่ที่มักสับสน

A B ต่างกัน
Internet WWW เครือข่าย (TCP/IP) vs บริการบน Internet (HTTP)
TCP IP แบ่ง/ประกอบ packet vs routing
IP Port ตึก vs ห้อง
IP Domain ตัวเลข vs ชื่อ (DNS จับคู่)
Router/gateway Firewall เชื่อม 2 network vs ความปลอดภัย
<head> <body> ข้อมูลเอกสาร vs เนื้อหาที่แสดง
<title> <h1> แท็บ browser vs หัวข้อในหน้า
<p> <br> ย่อหน้าใหม่ vs ขึ้นบรรทัด (ไม่มี tag ปิด)
Absolute Relative URL เต็ม vs เทียบจากเอกสารปัจจุบัน
<ol> <ul> เลข vs จุด
<dt> <dd> คำ vs คำอธิบาย
<td> <th> ข้อมูล vs หัวตาราง (bold+center)
colspan rowspan หลายคอลัมน์ vs หลายแถว
Tag Entity case insensitive vs case sensitive
&lt; &gt; < (#60) vs > (#62)
อ่านจบแล้ว ลองทดสอบความเข้าใจ
