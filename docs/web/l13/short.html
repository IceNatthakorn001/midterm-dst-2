6. CORS (สไลด์ 38–45)

  • ⭐ Same-origin policy: script เข้าถึงข้อมูลหน้าอื่นได้ iff origin (domain) เดียวกัน
  • ⭐ CORS: กลไกให้ restricted resources (เช่น fonts) ถูก request จาก domain อื่นได้
  • ⭐ ข้าม origin = ต่าง domain / subdomain / port / protocol
  • error ตัวอย่าง: fetch localhost:3000/student/1 จาก origin localhost:3100 → blocked: No 'Access-Control-Allow-Origin' header
  • ⭐ npm install --save cors + var cors = require('cors'); app.use(cors()); = All CORS (รันจริง ACAO = *)
  • เฉพาะ route: app.get('/student/:id', cors(), ...) → "This is CORS-enabled for a Single Route"
  • corsOptions = { origin: 'http://localhost:3100', methods: 'GET,POST,PUT,DELETE' } → app.use(cors(corsOptions))
  • หลาย origin: origin: whiteList (array 3100, 3200) — รันจริงตอบ origin ที่อยู่ใน list, นอก list ไม่มี header
  • ไม่ใช้ package: res.header("Access-Control-Allow-Origin", "http://localhost:3200"), res.header("Access-Control-Allow-Methods", "GET")
  • ⚠️ สไลด์ 44 'http://localhost:3200’] → SyntaxError

7. Token-Based Authentication (สไลด์ 46–48)

  • ทำให้ app/service ปลอดภัย — จัดการ user access ได้ปลอดภัยและมีประสิทธิภาพ
  • ⭐ Flow: 1 User Login {username, password} → 2 Authentication Service → 3 Token Generator → 4 Access Token → 5 เก็บใน Local Storage / Session Storage / Cookies → 6 HTTP request {Authorization: Bearer} → 7 Student WS → 8 Success or Deny

8. JWT (สไลด์ 49–53)

  • ⭐ JSON object ตาม RFC 7519 ส่งข้อมูลระหว่างฝ่ายอย่างปลอดภัย | use case: Authorization, Information Exchange
  • ⭐ 3 ส่วนคั่นจุด xxxxx.yyyyy.zzzzz = Header.Payload.Signature
  • Header = type (JWT) + signing algorithm (HS256, RS256, HS384)
  • ⭐ Payload = claims: Registered (iss, exp, sub, aud, iat) | Public (ควรลง IANA JSON Web Token Registry กันชน) | Private (ตกลงกันเอง)
  • ⭐ Signature = encoded header + encoded payload + secret + algorithm ใน header → sign
  • รันจริง: header {"alg":"HS256","typ":"JWT"}, payload {email, userid:"1", iat, exp}

9. jsonwebtoken (สไลด์ 54–56)

  • packages: jsonwebtoken (ใช้ในวิชา), express-jwt
  • ⭐ sign(payload, secretOrPrivateKey, [options, callback]) | options: algorithm (default HS256), expiresIn (60, "2 days", "10h", "7d"), audience, issuer, header
  • ⭐ verify(token, secretOrPublicKey, [options, callback]) | options: algorithms (["HS256","HS384"]), audience, issuer, ignoreExpiration (true = ไม่ตรวจหมดอายุ)
  • ⚠️ สไลด์ 55 เขียน sign ใช้ "PEM encoded public key" สำหรับ RSA/ECDSA ทั้งที่ชื่อพารามิเตอร์คือ PrivateKey

10. JWT Implementation (สไลด์ 57–66)

  • ⭐ npm install --save jsonwebtoken | jwt = require("jsonwebtoken") | .env: SECRET = "secret"
  • เพิ่มปุ่ม Login (ตัวอย่างเพื่อขอ token)
  • ⭐ router.post("/signin"): jwt.sign({ email: user.user.email, userid: user.user.userid.toString() } (Payload), process.env.SECRET (Secret), { expiresIn: "1h" } (Option)) → res.status(200).json({ token: jwtToken, message: user }) | รันจริง exp−iat = 3600
  • ⭐ auth.js: token = req.headers.authorization.split(" ")[1] → jwt.verify(token, process.env.SECRET) → next() | catch → 401 {error:true, message:"Authentication failed!"}
  • ⭐ authorize = require("./middlewares/auth"); router.get('/students', authorize, ...)
  • รันจริง: ไม่มี token / token มั่ว / secret อื่น / หมดอายุ → 401 | token จาก /signin → 200
  • client login: callStudentWS(url, method, token = "", sentData = {}) → "login" = POST + Content-Type: application/json + body: JSON.stringify(sentData)
  • ปุ่ม Login: user_data = { user: { email: "test@test.com", userid: 1 } } → token = data.token
  • ⭐ select ส่ง token: headers: { 'Authorization': 'Bearer ' + token }
  • ⚠️ สไลด์ 62 'application/json’ → SyntaxError
  • ⚠️ สไลด์ 65 เรียก callStudentWS(url, token, "select") สลับลำดับ → รันจริงได้ undefined ต้องเป็น (url, "select", token)
  • Open question: เก็บ JWT ยังไงให้ปลอดภัย?

11. Axios (สไลด์ 67–78)

  • packages: HTTP, Request, Needle, Axios, SuperAgent, Got, Node-fetch | npm install axios
  • ⭐ Axios ทำงานทั้ง Browser + Node.js | ข้อดี: older browsers, abort, response timeout, built-in CSRF protection, upload progress, automatic JSON, works in Node.js
  • ⭐ get/delete(url[, config]) | post/put/patch(url[, data[, config]]) | axios(config): url, method, params, data
  • spoonacular: ตัวแปร API key, query ("pizza"), params { number: 20, query, apiKey }, searchURL .../recipes/complexSearch? → axios.get(searchURL, { params, responseType: "json" }) → The number of results: 20 + ตาราง (index, id, title, image, imageType)
  • ⚠️ สไลด์ 75: ”Your API Key" → SyntaxError | Console.table → ReferenceError ต้องเป็น console.table
  • ⭐ Student WS: axios.get("http://localhost:3000/students", {responseType:'json'}).then(res => console.log(res.data)) → object { error:false, data:[...], message:'Student list.' } | ใช้ async/await ได้

12. VSCode Debugger (สไลด์ 79–82)

  • ⭐ เพิ่มโฟลเดอร์เข้า workspace → เมนู debug → create a launch.json file → เลือก folder + Node.js
  • launch.json อยู่ใน .vscode ของ working folder (Example1) | "type": "node", "request": "launch", "name": "Launch Program", "skipFiles": ["<node_internals>/**"], ⭐ "program": "${workspaceFolder}\\server.js"
  • ใส่ breakpoint → start debugging (ภาพ: หยุดที่ breakpoint, console Debugger attached.) | ⚠️ ภาพเป็น SQLserver.js
