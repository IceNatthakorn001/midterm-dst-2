0. บทนี้ต้องได้อะไร? สไลด์ 1–2

แก่นควบคุมหน้าตาเว็บด้วย style sheet — เขียน CSS (selector, property, value) เป็น และใส่ CSS ในเอกสาร HTML ได้ทั้ง 3 แบบ (inline / internal / external)

Course Objective (สไลด์ 2):

  • ควบคุมหน้าตา (appearance) ของเว็บไซต์ ด้วยการสร้าง style sheets
  • รู้วิธีเขียน CSS ซึ่งประกอบด้วย selector, property และ value
  • รู้วิธีใส่ CSS ลงในเอกสาร HTML ทั้ง inline styles, internal style sheets และ external style sheets

💡 หน้า objective เขียนไว้แค่เรื่องพื้นฐาน CSS แต่เนื้อหาจริงส่วนใหญ่ของบทนี้ (สไลด์ 12–62) คือ layout: float, flexbox, responsive, Bootstrap — อ่านส่วนนั้นให้ละเอียด

1. ทบทวน: CSS คืออะไร เขียนยังไง ใส่ได้กี่วิธี และถ้าชนกันใครชนะ? สไลด์ 3–11

แก่นCSS บอกว่า element ของ HTML จะแสดงผลยังไง และแยก "หน้าตา" ออกจาก tag HTML กฎ CSS = selector + { property: value; } ใส่ได้ 3 วิธี และถ้าหลายที่กำหนดค่าชนกัน: Inline > Internal > External > Browser Default

1.1 CSS คืออะไร ทำไมต้องใช้? สไลด์ 3

  • CSS = Cascading Style Sheets สร้างมาเพื่ออธิบายว่า element ของ HTML จะ แสดงผลยังไง บนจอ บนกระดาษ หรือสื่ออื่น ๆ
  • CSS แยก style formatting ออกจาก tag HTML — HTML ดูแลเนื้อหา, CSS ดูแลหน้าตา
  • ใช้ CSS จัดการ style ของหน้าเว็บ — โดยเฉพาะถ้าใช้ external style sheet จะประหยัดแรงได้มาก (แก้ไฟล์ .css ไฟล์เดียว ทุกหน้าเปลี่ยนตาม)

1.2 กฎ CSS หนึ่งข้อมีส่วนประกอบอะไรบ้าง? สไลด์ 4

แก่นselector เลือก element → declaration block { } เก็บ declaration หลายข้อ → แต่ละข้อเขียนแบบ property : value; ส่วน comment เขียนใน /* */

body {
  background-color: red;
  font-family: Arial;
}
/* More CSS declaration
   blocks defined below */

ส่วน ในตัวอย่าง ทำหน้าที่
Selector body บอกว่าจะแต่ง element ไหน
Declaration block ทุกอย่างใน { ... } กลุ่มของ declaration ของ selector นั้น
Declaration background-color: red; คำสั่งแต่งหนึ่งข้อ รูปแบบ property : value;
Comment /* ... */ คำอธิบายในโค้ด

1.3 ใส่ CSS ลงในหน้าเว็บได้กี่วิธี? สไลด์ 5–10

แก่น3 วิธี — External (ไฟล์ .css แยก ลิงก์ด้วย <link>), Internal (<style> ใน <head>), Inline (attribute style ใน tag)

วิธี เขียนที่ไหน มีผลกับ จุดเด่นตามสไลด์
1. External CSS ไฟล์แยกนามสกุล .css แล้วลิงก์ด้วย <link> ใน <head> ทุกหน้า ที่ลิงก์ไฟล์นี้ ไฟล์ CSS เดียวใช้กับ HTML ทั้งชุด → ประหยัดแรง
2. Internal CSS ใน <style> ภายใน <head> ของหน้านั้น หน้านั้นหน้าเดียว หน้านี้มีหน้าตาไม่เหมือนหน้าอื่นได้
3. Inline CSS attribute style ของ element นั้น ๆ element นั้นตัวเดียว style ใส่ CSS rule อะไรก็ได้

External CSS (สไลด์ 6–7)

  • declaration ทั้งหมดอยู่ใน ไฟล์แยก เขียนด้วย text editor อะไรก็ได้ แล้ว save เป็น .css
  • ไฟล์ CSS ไฟล์เดียวใช้กับ HTML ทั้งชุด → "Save a lot of efforts :)"
  • ทุกหน้า HTML ต้องอ้างถึงไฟล์นี้ ด้วย element <link> ที่อยู่ใน <head>
<head>
  <link rel="stylesheet" href="myStyle.css" />
</head>
  • <link> ใช้ลิงก์ไปยังไฟล์ภายนอก เช่น CSS
  • ตัวอย่างสไลด์ 7: หน้า "Only on PlayStation" — <header> + <article class="row"> ที่ข้างในมี <article class="column"> 2 อัน (Days Gone, Marvel's Spider-man แต่ละอันมี <h2> + ข้อความ + <div class="more">[Learn more]</div>) + <footer>Thanks to the PS4 online</footer> ผลลัพธ์: header แถบน้ำเงินเข้มตัวหนังสือขาว, 2 article เรียงซ้าย-ขวาเป็น 2 คอลัมน์ (มีเส้นประคั่น), "[Learn more]" สีม่วง, footer แถบน้ำเงินเข้ม — สไตล์ทั้งหมดมาจาก myStyle.css

Internal CSS (สไลด์ 8–9)

  • declaration ทั้งหมดอยู่ใน element <style> ภายใน <head> ของหน้านั้น
  • <style> ใช้กำหนด style information ของเอกสาร HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    body { /* Style of <body> */
      background-color: darkblue;
      font-family: Arial;
    }
    h1 { /* Style of <h1> */
      color: white;
      font-style: italic;
    }
  </style>
</head>
<body>
  <h1>This HTML page is unique from the rest, I can apply the Internal CSS.</h1>
</body>
</html>

→ พื้นน้ำเงินเข้ม, <h1> สีขาวตัวเอียง

Inline CSS (สไลด์ 10)

  • เขียน CSS ใน attribute style ของ element ตัวนั้น — style ใส่ CSS rule ได้ทุกแบบ
<body style="background-color: red; font-family: Arial;">
  <p style="color: white; font-size: 10em;">
    This page has a lot of the inline CSS :)
  </p>
</body>

1.4 ถ้ามีหลาย style กำหนดให้ element เดียวกัน จะใช้อันไหน? (Cascading Order) สไลด์ 11

แก่นInline CSS > Internal CSS > External CSS > Browser Default — ตัวที่อยู่ซ้ายกว่าทับ (override) ตัวที่อยู่ขวา

  • ตัวอย่างในสไลด์: CSS ทั้ง 3 แบบกำหนด background-color และ font-family ให้ <body> พร้อมกัน → ค่าจาก inline CSS ทับ (overrides) ค่าใน internal CSS, external CSS และ browser default ตามลำดับ
  • ภาพผลลัพธ์ในสไลด์: หน้าเว็บพื้นสีเขียวอ่อน ข้อความ "Show Cascading Order" ตัวหนา

💡 เปรียบเหมือนคำสั่งงาน: คำสั่งที่เจาะจงตัวคุณ (inline) ชนะคำสั่งของแผนก (internal) ซึ่งชนะนโยบายบริษัท (external) และถ้าไม่มีใครสั่ง ก็ทำตามค่าเริ่มต้น (browser default)

⚠️ สไลด์ 11 เขียนว่า "As shown in the example" แต่ไม่ได้แสดงโค้ดตัวอย่างไว้ในสไลด์ — มีแค่ภาพผลลัพธ์

2. Web Page Layout หน้าตาแบบไหน และมีกี่วิธีสร้าง? สไลด์ 12–17

แก่นlayout พื้นฐาน = Header / Navigation Bar / Content + Main Content + Content / Footer จำนวนคอลัมน์ควรเปลี่ยนตามอุปกรณ์ (มือถือ 1, แท็บเล็ต/แล็ปท็อป 2, เดสก์ท็อป 3) สร้างด้วย tag แบบ container + CSS ได้ 5 วิธี (table ไม่แนะนำ)

2.2 layout ควรเปลี่ยนตามอุปกรณ์ยังไง? สไลด์ 14

2.3 ใช้ tag อะไรสร้าง layout ด้วย CSS? สไลด์ 15

แก่นใช้ tag ที่เป็น "กล่อง" (container-like) คู่กับ CSS เช่น property float

2.5 สร้าง layout หลายคอลัมน์ได้กี่วิธี? สไลด์ 17

แก่น5 วิธี — table (ไม่แนะนำ), float, flexbox, framework, grid — บทนี้สอน float, flexbox, framework ส่วน framework + grid เป็น "ของสนุกไปลองต่อในโปรเจกต์"

# วิธี คำอธิบายตามสไลด์ ในบทนี้
1 HTML tables ไม่แนะนำ สำหรับ layout — <table> มีไว้แสดง ข้อมูลแบบตาราง ขีดฆ่าทิ้ง
2 CSS float property จัด layout ด้วย property float สอน (หัวข้อ 3)
3 CSS flexbox layout ที่ยืดหยุ่น responsive สำหรับอุปกรณ์ต่าง ๆ สอน (หัวข้อ 4)
4 CSS framework วิธีสร้าง layout ที่เร็ว เช่น Bootstrap framework สอน (หัวข้อ 6) + "Fun things to explore in the project"
5 CSS grid ระบบ layout แบบ grid มี rows และ columns "Fun things to explore in the project"

3. จัด layout ด้วย CSS Float ทำยังไง? สไลด์ 18–23

แก่นfloat: left/right ทำให้ element ลอยชิดซ้าย/ขวาแล้วให้ของอื่นไหลอ้อม ส่วน clear ห้ามมี float อยู่ข้างนั้น ทำ 3 คอลัมน์ได้ด้วย .column { float: left; width: 33.33%; } แล้ว clear float หลังกล่องที่ครอบ

3.1 float กับ clear ทำงานยังไง? สไลด์ 18

โค้ด ผลในภาพตัวอย่าง
img { float: left; } รูปกระต่าย "clap clap" ลอยไปชิดซ้าย แล้วข้อความ Lorem ipsum ไหลอ้อมอยู่ด้านขวาของรูป (ข้อความใต้หัวข้อ "Previewing Layout" บอกว่ากำหนด float ได้ทั้งซ้ายหรือขวา)
img { float: left; } + p { clear: left; } ย่อหน้า <p> (พื้นสีส้มอ่อน) ไม่ยอมอยู่ข้างรูป แต่ลงไปเริ่ม ใต้รูป แทน
  • clear: left = "Not allowed any float elements on its left" — ห้ามมี element ที่ float อยู่ทางซ้ายของมัน

💡 เปรียบเหมือนรูปที่วางในหน้านิตยสาร: float = วางรูปชิดขอบแล้วให้ตัวหนังสือพันรอบ, clear = บอกว่าย่อหน้านี้ต้องขึ้นใต้รูป ห้ามพันรอบ

<header>

</header>
<nav>

  <a href="#">Link</a>
  <a href="#">Link</a>
</nav>
<article class="container">
  <article class="column">
    <h2>Column1</h2>
    <p>Lorem ipsum dolor sit amet … </p>
  </article>
  <article class="column">
    <h2>Column2</h2>

3.3 เขียน CSS ทีละขั้นยังไงให้ได้ layout นั้น? สไลด์ 20–23

แก่นขั้น 1 แต่ง header/footer → ขั้น 2 แต่ง nav ให้ลิงก์ float ขวา → ขั้น 3 ระบายพื้น container ให้เห็นขอบเขต → ขั้น 4 ให้ .column float ซ้ายกว้าง 33.33% แล้ว clear float

ขั้น 1 (สไลด์ 20) — ฟอนต์ทั้งหน้า + header/footer

* {
  font-family: sans-serif;
}
header,footer {
  overflow: hidden;
  background-color: #f1f1f1;
  padding: 3px;
  text-align: center;
}
  • * = เลือกทุก element → ทั้งหน้าเป็น sans-serif
  • header,footer = เลือก 2 อย่างพร้อมกัน → พื้นเทาอ่อน #f1f1f1, ระยะใน 3px, ตัวหนังสืออยู่กลาง
  • ผล: Header/Footer เป็นแถบเทาตัวหนังสือกลาง แต่ลิงก์ยังเป็นตัวเล็กขีดเส้นใต้ และ 3 คอลัมน์ยังเรียงลงมา

ขั้น 2 (สไลด์ 21) — แถบ nav

nav {
  overflow: hidden;
  background-color: darkblue;
}
nav a {
  float: right;
  display: block;
  color: #f2f2f2;
  text-align: center;
  padding: 14px 16px;
  text-decoration: none;
}
  • nav พื้นน้ำเงินเข้ม
  • nav a (ลิงก์ที่อยู่ใน nav) float: right → ลิงก์ไปชิดขวา, display: block, สีเกือบขาว #f2f2f2, ระยะใน 14px 16px, text-decoration: none = ไม่มีขีดเส้นใต้
  • ผล: แถบน้ำเงินเข้ม มี "Link Link Link" สีขาวชิดขวา

ขั้น 3 (สไลด์ 22) — ระบายพื้นกล่องครอบ (เพื่อ demo ให้เห็นขอบเขต)

.container { /* For demo. the region */
  background-color: gainsboro;
}
  • ผล: บริเวณ 3 คอลัมน์มีพื้นเทา gainsboro (ยังเรียงลงมา)
  • หมายเหตุ: ในสไลด์ 22 บรรทัดแรกเขียนเป็น body { font-family: sans-serif; } แทน * {...} ของสไลด์ 20–21

ขั้น 4 (สไลด์ 23) — ทำ 3 คอลัมน์เคียงกัน + clear float

/* Create 3 equal columns floating next to each other */
.column {
  float: left;
  width: 33.33%;
  background-color: lightskyblue;
}
/* ::after is one of pseudo-elements used to style specified part.
   This block of CSS uses to clear the float after the element with class="row" */
.row::after {
  content: "";
  display: table;
  clear: both;
}
  • .column float: left + width: 33.33% → 3 คอลัมน์ กว้างเท่ากัน ลอยเรียงต่อกันจากซ้าย (พื้นฟ้า)
  • ::after เป็น pseudo-element ตัวหนึ่ง ใช้แต่ง "ส่วนที่ระบุ" ของ element — บล็อกนี้ใช้ clear float หลัง element ที่มี class="row" (clear: both = ห้ามมี float ทั้งซ้ายและขวา)
  • ผล: Header → nav น้ำเงิน ลิงก์ขวา → Column1 | Column2 | Column3 เคียงกัน → Footer

⚠️ ชื่อ class ไม่ตรงกัน: CSS สไลด์ 23 clear float ด้วย .row::after แต่ HTML ของตัวอย่างนี้ (สไลด์ 19) กล่องครอบใช้ class="container" ไม่มี element ไหนมี class="row" (คนละตัวอย่างกับสไลด์ 7 ที่ใช้ class="row") → บล็อก .row::after จึงไม่มีผลกับตัวอย่างนี้

ลองรันจริงใน Chrome: ถ้าข้อความ 3 คอลัมน์ ยาวไม่เท่ากัน กล่อง .container สูง 0px และ footer เลื่อนขึ้นไปแทรกข้างคอลัมน์ที่สั้นที่สุด พอเติม class="container row" ให้กล่องครอบ กล่องสูงตามคอลัมน์และ footer ลงไปอยู่ใต้คอลัมน์ถูกต้อง (ในสไลด์ดูปกติเพราะ 3 คอลัมน์ข้อความยาวเท่ากัน) — ถ้าทำเองให้ใส่ class ที่ clear ให้ตรงกับกล่องครอบ หรือถามอาจารย์

4. จัด layout ด้วย CSS Flexbox ทำยังไง? สไลด์ 24–31

แก่นใส่ display: flex ให้กล่องแม่ (flex container) แล้วลูกโดยตรงทุกตัวกลายเป็น flex items คุมทิศด้วย flex-direction, การขึ้นบรรทัดใหม่ด้วย flex-wrap, การกระจายช่องว่างด้วย justify-content — ทำ layout ได้โดยไม่ต้องใช้ float และ clear

4.1 Flexbox คืออะไร? สไลด์ 24

  • Flexbox (Flexible Box) module ของ CSS ช่วยให้ จัดวาง (lay out), จัดแนว (align) และกระจายพื้นที่ (distribute space) ระหว่าง items ใน container ที่ ขนาดเปลี่ยนได้ (dynamic size) ได้มีประสิทธิภาพกว่าเดิม
  • ออกแบบ layout ที่ยืดหยุ่นแบบ responsive ได้ โดยไม่ต้องใช้ float หรือ positioning

4.2 แนวคิดพื้นฐาน: container กับ items คืออะไร? สไลด์ 25

แก่นกล่องแม่ที่มี display: flex = flex container (parent) / ลูกโดยตรงข้างในทุกตัว = flex items (child)

<section class="container">
  <div>1</div> <!-- *items* -->
  <div>2</div> <!-- *items* -->
  <div>3</div> <!-- *items* -->
</section>

.container {
  /* Enables a flex layout context for all its direct children */
  display: flex;
}
  • display: flex เปิด flex layout ให้ ลูกโดยตรง (direct children) ทุกตัว

💡 เปรียบเหมือนชั้นวางของ: ชั้น = flex container, ของบนชั้น = flex items — ตั้งที่ชั้นทีเดียวว่าจะเรียงแนวไหน ล้นแล้วขึ้นชั้นใหม่ไหม เว้นช่องยังไง ของทุกชิ้นจัดตามนั้นเอง

4.3 property ของ container มีอะไรบ้าง? สไลด์ 26–27

แก่นflex-direction = เรียงทิศไหน, flex-wrap = ล้นแล้วขึ้นบรรทัดใหม่ไหม, justify-content = กระจายช่องว่างตามแนวเรียงยังไง, align-items = จัดแนวอีกแกนหนึ่ง

  flex-wrap: wrap;

flex-wrap nowrap | wrap | wrap-reverse กล่องเต็มแถวแล้ว ขึ้นแถวใหม่ ข้างล่าง (wrap)

5. Responsive Web Design: ทำให้หน้าเว็บเปลี่ยนตามขนาดจอยังไง? สไลด์ 32–44

แก่นRWD = แนวทางออกแบบให้หน้าเว็บแสดงผลดีทุกอุปกรณ์/ทุกขนาดจอ ใช้แค่ HTML + CSS (Media Query) ต้องใส่ <meta name="viewport"> ใน <head> และแนว Mobile first = ออกแบบให้มือถือก่อนแล้วใช้ @media (min-width: ...) ปรับสำหรับจอใหญ่

5.1 Responsive Web Design (RWD) คืออะไร? สไลด์ 32–33

  • สไลด์ 32 = หน้าคั่นหัวข้อ "Responsive Web Design"
  • นิยาม (Wikipedia): "An approach to web design that makes web pages render well on a variety of devices and window or screen sizes." = แนวทาง ออกแบบเว็บที่ทำให้หน้าเว็บแสดงผลได้ดีบนอุปกรณ์หลากหลายและหน้าต่าง/จอหลายขนาด
  • ใช้ แค่ HTML และ CSS (คือ Media Query)
  • ปรับเนื้อหาตามขนาดจอหรืออุปกรณ์
  • Mobile first = แนวทางที่มุ่ง ออกแบบให้มือถือก่อน แล้วค่อยออกแบบให้ desktop หรืออุปกรณ์อื่น — ตรงข้ามกับการออกแบบแบบดั้งเดิม (traditional design)

5.2 CSS Media Query คืออะไร เขียนยังไง? สไลด์ 34–35

แก่น@media mediatype and (expressions) { CSS block } — CSS ในบล็อกจะใช้ก็ต่อเมื่อเงื่อนไขเป็นจริง เช่น ความกว้างจอ

Media query ตรวจได้หลายอย่าง เช่น:

  • ความกว้างและความสูงของ viewport
  • ความกว้างและความสูงของ อุปกรณ์ (device)
  • orientation — แท็บเล็ต/มือถืออยู่ในแนวนอน (landscape) หรือแนวตั้ง (portrait)
  • resolution ความละเอียด

ใช้ media query ปรับ style sheet ให้เข้ากับ desktop, laptop, tablet และมือถือ

@media mediatype and (expressions) {
  CSS Block;
}

ตัวอย่าง (สไลด์ 35):

body { /* Default */
  background-color: black;
}
/* This CSS applied when screen size less than 768px */
@media screen and (max-width: 768px) {
  body {
    background-color: lightgreen;
  }
}
/* This CSS applied when screen size larger than 1000px */
@media screen and (min-width: 1000px) {
  body {
    background-color: red;
  }
}
ความกว้างจอ บล็อกที่ใช้ พื้นหลัง (ตามภาพในสไลด์)
แคบ (max-width: 768px) @media ... (max-width: 768px) lightgreen เขียวอ่อน
ระหว่างกลาง (ไม่เข้าเงื่อนไขไหนเลย) ค่า Default black ดำ
กว้าง (min-width: 1000px) @media ... (min-width: 1000px) red แดง
  • ทั้ง 3 ภาพมีข้อความ "Style change when resizing"
  • max-width: X = ใช้เมื่อจอ ไม่เกิน X | min-width: X = ใช้เมื่อจอ ตั้งแต่ X ขึ้นไป

5.5 <meta> viewport คืออะไร ทำไมต้องใส่? สไลด์ 38

แก่นviewport = พื้นที่ของหน้าเว็บที่ผู้ใช้มองเห็น สำหรับ RWD ต้องใส่ <meta name="viewport" content="width=device-width, initial-scale=1.0" /> ใน <head> เพื่อบอก browser ว่าจะคุมขนาดและการซูมของหน้ายังไง

  • HTML5 มีวิธีให้นักออกแบบเว็บควบคุม viewport ได้ ผ่าน tag <meta>
  • Viewport: พื้นที่ของหน้าเว็บที่ผู้ใช้ มองเห็น (the user's visible area of a web page)
  • สำหรับ RWD ต้อง ใส่คำสั่งนี้ใน <head>:
<head>
  <style> … </style>
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
</head>
ส่วน ความหมาย
width=device-width ให้ความกว้างของหน้า ตามความกว้างจอของอุปกรณ์นั้น ๆ
initial-scale=1.0 ระดับการซูมเริ่มต้น ตอนโหลดหน้า
  • คำสั่งนี้บอก browser ว่าจะควบคุม ขนาด (dimensions) และ การซูม (scaling) ของหน้าเว็บยังไง

5.6 ตัวอย่าง Responsive + Mobile First Layout เขียนยังไง? สไลด์ 39–43

    /* Fill the CSS here */

6. CSS Framework: ใช้ Bootstrap สร้างหน้าเว็บยังไง? สไลด์ 45–62

แก่นCSS framework ให้โครงสำเร็จรูปเริ่มงานได้เร็ว Bootstrap ทำได้ใน 4 ขั้น: template HTML5 + viewport → ใส่ CSS/JS ของ Bootstrap → วาง layout ด้วย grid (container → row → column, แถวละ ≤ 12 หน่วย, 6 breakpoints) → ใส่ class/components

6.1 CSS Framework คืออะไร เลือกยังไง? สไลด์ 45–46

  • สไลด์ 45 = หน้าคั่นหัวข้อ "CSS Framework: Bootstrap"
  • CSS framework ให้ โครงสร้างพื้นฐาน (basic structure) แก่นักพัฒนาเว็บ เพื่อ เริ่มต้นได้เร็ว ตอนออกแบบเว็บไซต์
  • เลือก framework ให้ตรงกับความต้องการ ของงาน โดยดูจาก:
    • Faster-built — สร้างได้เร็ว
    • Performance — ประสิทธิภาพ
    • Easy UI components — มีส่วน UI สำเร็จรูปใช้ง่าย
  • ตัวอื่นให้ลองดู: Bootstrap, Tailwind CSS, Bulma, UIkit ฯลฯ

6.2 Bootstrap คืออะไร? สไลด์ 47

  • Bootstrap = front-end framework ฟรี สำหรับพัฒนาเว็บให้ เร็วขึ้นและง่ายขึ้น (สไลด์บอก Current version: Bootstrap v.5.0)
  • สร้าง responsive design ได้ง่าย
  • มี design templates ที่ใช้ HTML และ CSS
  • Responsive features และแนว Mobile-first เป็นส่วนหนึ่งของแกนหลักของ framework

6.3 สร้างหน้าเว็บด้วย Bootstrap มีกี่ขั้น? สไลด์ 48

แก่น4 ขั้น — template → include → grid → class/components

  1. สร้าง HTML5 document template ที่มีพฤติกรรม responsive ที่ถูกต้อง (เช่น viewport)
  2. ใส่ Bootstrap CSS และ JS script ใน <head>
  3. จัด layout ของหน้าด้วย grid system
  4. ใส่ class/components แล้วสนุกได้เลย ("enjoy")

ภาพประกอบสไลด์ 48: กล่อง container ข้างในมีแถวบน col 4 ช่องกว้างเท่ากัน และแถวล่าง col-8 (กว้าง) + col-4 (แคบ)

6.4 Step 1–2: template และการใส่ Bootstrap เขียนยังไง? สไลด์ 49–50

แก่นBootstrap ต้องใช้ HTML5 doctype + meta charset="utf-8" + meta viewport แล้วดึงไฟล์ CSS (<link>) และ JS (<script>) ที่ compile แล้วจาก CDN

Step 1: HTML5 Doc Template (สไลด์ 49)

<!DOCTYPE html>

        rel="stylesheet" integrity="sha384-..." crossorigin="anonymous">
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/js/bootstrap.bundle.min.js"
          integrity="sha384-..." crossorigin="anonymous"></script>

6.5 Step 3: Container คืออะไร มีกี่แบบ? สไลด์ 51–55

แก่นต้องมี element ครอบเนื้อหาเว็บด้วย container เสมอ มี 3 แบบ: .container (max-width ตาม breakpoint), .container-fluid (กว้าง 100% ทุกขนาด), .container-{breakpoint} (100% จนกว่าจะถึง breakpoint ที่ระบุ)

  • BS ต้องมี containing element ครอบเนื้อหาเว็บ — เลือกใช้ container หรือ container-fluid (สไลด์ 51)
<body>
  <main class="container-fluid">
  </main>
</body>
  • โครงของ grid (สไลด์ 52): Container (กรอบนอก) → ข้างในมี Rows (แถว) → แต่ละแถวแบ่งเป็น Column (แถวบน 3 column เท่ากัน, แถวล่าง column แคบ 1 + column กว้างกินพื้นที่ 2 ช่อง)

  • "Containers are the most basic layout element in Bootstrap and are required when using our default grid system" — Bootstrap (สไลด์ 53) = container เป็นองค์ประกอบ layout พื้นฐานที่สุด และ จำเป็นต้องมี เมื่อใช้ grid system

6.6 Grid system ทำงานยังไง? สไลด์ 56–59

แก่นgrid สร้างด้วย flexbox แถวละไม่เกิน 12 columns เนื้อหาทั้งหมดต้องอยู่ใน column (container → row → column → content) class col-{breakpoint}-{จำนวน} กำหนดความกว้าง และคอลัมน์จะซ้อนกันลงเมื่อจอเล็กกว่า breakpoint นั้น

หลักของ grid (สไลด์ 56):

  • สร้างด้วย flexbox และมีได้ ถึง 12 columns ต่อ 1 row
  • ตอนสร้าง grid layout เนื้อหาทั้งหมดอยู่ใน columns → container to row; row to column; column to content
  • Responsive: คอลัมน์ (.col) จะ จัดเรียงใหม่อัตโนมัติ ตามขนาดจอ หรือ ใช้คู่กับ 6 breakpoints

6 breakpoints (สไลด์ 56)

Breakpoint Class infix Dimensions
X-Small None <576px
Small sm ≥576px
Medium md ≥768px
Large lg ≥992px
Extra large xl ≥1200px
Extra extra large xxl ≥1400px

ตัวอย่าง grid (สไลด์ 57)

<!-- Control the column width and how they should appear on different devices,
     e.g., for sm, the columns will automatically stack on top of each other
     when the screen is less than 576px wide -->
<section class="row">
  <div class="col-sm-6">Row 1, Col 1 (Span 6 units)</div>
  <div class="col-sm-6">Row 1, Col 2 (Span 6 units)</div>
</section>
<section class="row">
  <div class="col-sm-8">Row 2, Col 1 (Span 8 units)</div>
  <div class="col-sm-4">Row 2, Col 2 (Span 4 units)</div>
</section>
<!-- Note: The sum of cols adds up to 12 or fewer -->
  • class="row" = แถว | col-sm-6 = กว้าง 6 หน่วย (จาก 12) ที่ breakpoint sm ขึ้นไป
  • แถว 1: 6 + 6 = 12 (ครึ่ง-ครึ่ง) | แถว 2: 8 + 4 = 12
  • ผลรวม col ในแถวต้อง ≤ 12
  • สำหรับ sm: ถ้าจอ แคบกว่า 576px คอลัมน์จะ ซ้อนกันลงมาเอง (stack on top of each other)

  3. แถว 2 มี 3 กล่อง → 3 + 8 + 1 = 12 พอดี (ไม่เกิน 12)
  4. จอแคบแล้วซ้อนลง → ต้องใส่ breakpoint ใน class (เช่น col-sm-*) ถ้าใช้ col-6 เฉย ๆ (ไม่มี infix = ใช้ทุกขนาดจอ) จะไม่ซ้อนลงเมื่อจอแคบ

::after (pseudo-element) แต่ง "ส่วนที่ระบุ" ของ element — ใช้ clear float หลังกล่อง ส่วนท้ายที่มองไม่เห็น
Flexbox module ของ CSS สำหรับจัดวาง จัดแนว กระจายพื้นที่ใน container ขนาดเปลี่ยนได้ ชั้นวางของ
Flex container กล่องแม่ที่มี display: flex ชั้น
Flex items ลูกโดยตรงของ flex container ของบนชั้น
flex-direction ทิศที่ items เรียง (row / row-reverse / column / column-reverse) เรียงทางไหน
flex-wrap ล้นแล้วขึ้นบรรทัดใหม่ไหม (nowrap / wrap / wrap-reverse) ล้นแล้วตัดแถวไหม
justify-content กระจายช่องว่างตามแนวที่เรียง ชิดไหน / เว้นยังไง
align-items จัดแนว items อีกแกนหนึ่ง ใช้ center ให้อยู่กลาง
space-evenly ช่องว่างเท่ากันทุกช่องรวมขอบ เว้นเท่ากันหมด
RWD (Responsive Web Design) แนวทางให้หน้าเว็บแสดงผลดีทุกอุปกรณ์/ขนาดจอ ใช้แค่ HTML + CSS เว็บยืดหดตามจอ
Mobile first ออกแบบให้มือถือก่อน แล้วค่อยจอใหญ่ — ตรงข้ามแบบดั้งเดิม เล็กก่อนแล้วขยาย
Media Query (@media) CSS ที่ใช้เมื่อเงื่อนไข (เช่นความกว้างจอ) เป็นจริง ถ้าจอ... ให้ใช้ CSS นี้
max-width / min-width ไม่เกิน X / ตั้งแต่ X ขึ้นไป max = เพดาน, min = พื้น
Viewport พื้นที่ของหน้าเว็บที่ผู้ใช้มองเห็น หน้าต่างที่มองเห็น
width=device-width ให้หน้ากว้างตามจออุปกรณ์ ตามจอจริง
initial-scale=1.0 ระดับซูมเริ่มต้นตอนโหลด ซูม 100%
CSS Framework โครงพื้นฐานสำเร็จรูป ช่วยเริ่มทำเว็บได้เร็ว ชุดแต่งบ้านสำเร็จรูป
Bootstrap front-end framework ฟรี responsive + mobile-first ในแกนหลัก ใช้ class แทนเขียน CSS เอง
CDN แหล่งที่ดึงไฟล์ CSS/JS ที่ compile แล้วของ Bootstrap มาใช้ ลิงก์ jsdelivr ใน <head>
Container (BS) กล่องครอบเนื้อหา จำเป็นสำหรับ grid .container / .container-fluid
Grid system (BS) ระบบแบ่ง row เป็น ≤ 12 columns สร้างด้วย flexbox 12 ช่องต่อแถว
Breakpoint ขนาดจอที่ layout เปลี่ยน: sm 576, md 768, lg 992, xl 1200, xxl 1400 จุดเปลี่ยนร่าง
Component (BS) ส่วน UI สำเร็จรูป เช่น Card, Navbar, Modal ชิ้นส่วนพร้อมใช้

สรุปท้ายบท / จุดที่มักออกสอบ

  • CSS แยก style formatting ออกจาก tag HTML · external CSS ประหยัดแรงที่สุด
  • กฎ CSS: selector + declaration block · declaration = property : value; · comment = /* */
  • 3 วิธีใส่ CSS: External (<link rel="stylesheet" href="x.css" /> ใน <head>) · Internal (<style> ใน <head>) · Inline (attribute style)
  • ⭐ Cascading Order: Inline > Internal > External > Browser Default
  • layout ตามอุปกรณ์: Mobile 1 column · Tablet/Laptop 2 · Desktop 3
  • tag ทำ layout: header, nav, footer, article (content), section (ส่วนใน content), div (กล่องครอบเพื่อแต่ง CSS)
  • 5 วิธีทำ multicolumn: table (ไม่แนะนำ, ใช้แสดงข้อมูลตาราง) · float · flexbox · framework (Bootstrap) · grid (rows + columns)
  • float: left = ลอยซ้ายให้ของอื่นไหลอ้อม · clear: left = ห้ามมี float ทางซ้าย · clear: both = ห้ามทั้งสองข้าง
  • Float 3 คอลัมน์: .column { float: left; width: 33.33%; } + .row::after { content: ""; display: table; clear: both; }
  • ⭐ Flexbox: display: flex ที่ container → ลูกโดยตรงเป็น items · flex-direction (row, row-reverse, column, column-reverse) · flex-wrap (nowrap, wrap, wrap-reverse) · justify-content (flex-start, flex-end, center, space-between, space-around, space-evenly, ...) · align-items (flex-start, flex-end, center)
  • Flexbox ไม่ต้องใช้ float และ clear · nav ชิดขวาด้วย justify-content: flex-end
  • ⭐ Ex1: row-reverse + wrap + space-evenly / item: center + center
  • RWD = approach ให้เว็บแสดงผลดีทุกอุปกรณ์ · ใช้แค่ HTML + CSS (Media Query) · Mobile first = ออกแบบมือถือก่อน (ตรงข้าม traditional)
  • media query ตรวจได้: width/height ของ viewport, width/height ของ device, orientation, resolution
  • ⭐ syntax: @media mediatype and (expressions) { CSS Block; } · max-width = ไม่เกิน · min-width = ตั้งแต่
  • ⭐ Ex2: ≤768px → 2em · 769–999px → 4em (ค่าปกติ) · ≥1000px → 8em
  • ⭐ viewport: <meta name="viewport" content="width=device-width, initial-scale=1.0" /> ใน <head> · width=device-width = ตามความกว้างจอ · initial-scale = ซูมเริ่มต้น
  • Mobile-first example: ปกติ nav/.container = column → @media screen and (min-width: 600px) เปลี่ยนเป็น row (nav: row-reverse + flex-start)
  • ทดสอบ responsive ได้ใน Developer Tools ของ browser (เช่น iPhone X 375×812, iPad Pro 1024×1366)
  • เลือก CSS framework ตาม: Faster-built, Performance, Easy UI components
  • Bootstrap: ฟรี, responsive + mobile-first อยู่ในแกนหลัก, v.5.0 ตามสไลด์ 47
  • ⭐ Bootstrap 4 ขั้น: template (doctype + viewport) → include CSS/JS ใน <head> (CDN) → grid → class/components
  • ⭐ container 3 แบบ: .container (max-width ตาม breakpoint) · .container-fluid (100% เสมอ) · .container-{bp} (100% จนถึง bp)
  • ⭐ grid: flexbox, ≤ 12 columns ต่อ row, container → row → column → content, ผลรวม col ในแถว ≤ 12
  • ⭐ 6 breakpoints: X-Small (<576, ไม่มี infix) · sm ≥576 · md ≥768 · lg ≥992 · xl ≥1200 · xxl ≥1400
  • .container max-width: 540 / 720 / 960 / 1140 / 1320 px (sm → xxl), <576 = 100%
  • col-sm-6 = 6 หน่วยตั้งแต่ sm ขึ้นไป · จอ <576px คอลัมน์ซ้อนลง
  • components: Accordion, Card, Carousel, Dropdown, List Group, Navbar, Form, Modal, Toast | Content: Typography, Image, Table, Figures | Utility: Text, Spacing, Vertical align, Color
