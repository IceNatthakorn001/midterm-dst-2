Lecture 4 – Cascading Style Sheet (Part II)

0. เป้าหมาย (สไลด์ 1–2)

  • คุมหน้าตาเว็บด้วย style sheet | เขียน CSS (selector, property, value) | ใส่ CSS แบบ inline / internal / external

1. ทบทวน CSS (สไลด์ 3–11)

  • CSS = อธิบายว่า element แสดงผลยังไง (จอ กระดาษ สื่ออื่น) | แยก style ออกจาก tag HTML | external ประหยัดแรงสุด
  • ⭐ syntax: selector { declaration block } | declaration = property : value; | comment = /* */
วิธี เขียนที่ มีผลกับ
⭐ External ไฟล์ .css + <link rel="stylesheet" href="myStyle.css" /> ใน <head> ทุกหน้าที่ลิงก์
Internal <style> ใน <head> หน้าเดียว
Inline attribute style="..." element ตัวเดียว
  • ⭐ Cascading Order: Inline > Internal > External > Browser Default (inline ทับ background-color, font-family ของที่เหลือ)
  • ⚠️ สไลด์ 11 อ้าง "the example" แต่ไม่มีโค้ด มีแค่ภาพผล

2. Web Page Layout (สไลด์ 12–17)

  • layout ง่าย ๆ: Header / Navigation Bar / Content + Main Content + Content / Footer
  • ⭐ ตามอุปกรณ์: Mobile 1-column | Tablet/Laptop 2-column | Desktop 3-column
  • tag: header | nav | footer | article (content) | section (ส่วนใน content) | div (กล่องครอบเพื่อแต่ง CSS) + ใช้คู่ float
  • Plain HTML = เรียงลงหมด | Layouted = nav น้ำเงินลิงก์ขวา + 3 คอลัมน์เคียงกัน
  • ⭐ 5 วิธีทำ multicolumn: table (ไม่แนะนำ, ไว้แสดงข้อมูลตาราง) | float | flexbox (responsive) | framework (Bootstrap) | grid (rows+columns) — framework+grid = "fun things to explore in the project"

3. CSS Float (สไลด์ 18–23)

  • ⭐ float: left = ลอยซ้าย ข้อความไหลอ้อม | clear: left = ห้ามมี float ทางซ้าย → ลงไปใต้รูป | clear: both = ห้ามทั้งสองข้าง
  • HTML: header > h1 | nav > a×3 | article.container > article.column×3 (h2 + p) | footer > h1
  • ขั้น 1: * {font-family: sans-serif} + header,footer {overflow:hidden; bg #f1f1f1; padding 3px; text-align center}
  • ขั้น 2: nav {overflow:hidden; bg darkblue} + nav a {float:right; display:block; color #f2f2f2; padding 14px 16px; text-decoration:none}
  • ขั้น 3: .container {bg gainsboro} (demo ขอบเขต; สไลด์ 22 ใช้ body แทน *)
  • ⭐ ขั้น 4: .column {float:left; width:33.33%; bg lightskyblue} + .row::after {content:""; display:table; clear:both} (::after = pseudo-element)
  • ⚠️ .row::after แต่ HTML ใช้ class="container" → ไม่ clear จริง (รันแล้ว: container สูง 0, footer แทรกข้างคอลัมน์ถ้าข้อความยาวไม่เท่ากัน) แก้ด้วย class="container row"

4. CSS Flexbox (สไลด์ 24–31)

  • Flexbox = จัดวาง/จัดแนว/กระจายพื้นที่ items ใน container ขนาดเปลี่ยนได้ | responsive ไม่ต้องใช้ float/positioning
  • ⭐ display: flex ที่ container (parent) → ลูกโดยตรง = flex items (child)
property ค่า
⭐ flex-direction row | row-reverse | column | column-reverse
⭐ flex-wrap nowrap | wrap | wrap-reverse
⭐ justify-content flex-start | flex-end | center | space-between | space-around | space-evenly | start | end | left | right
align-items flex-start | flex-end | center
  • ⚠️ สไลด์ 26 // or column ไม่ใช่ comment CSS → รันแล้ว flex-wrap: wrap ถูกทิ้ง (ได้ nowrap) ใช้ /* */
  • ⭐ [Ex1] ภาพ: กว้าง = 5 4 3 2 1 | แคบ = 3 2 1 / 5 4 → container: row-reverse + wrap + space-evenly | item: justify-content: center + align-items: center (รันตรวจแล้ว)
  • Flexbox layout: header,footer ไม่มี overflow | ⭐ nav {display:flex; flex-direction:row; justify-content:flex-end} (ลิงก์ขวา ไม่มี float) | ⭐ .container {display:flex; flex-direction:row; justify-content:space-evenly} → "No more float and clear :)"

5. Responsive Web Design (สไลด์ 32–44)

  • ⭐ RWD = approach ให้เว็บแสดงผลดีทุกอุปกรณ์/ขนาดจอ (Wikipedia) | ใช้แค่ HTML + CSS (Media Query) | ปรับตามจอ
  • ⭐ Mobile first = ออกแบบมือถือก่อน desktop — ตรงข้าม traditional design
  • media query ตรวจ: width/height ของ viewport | width/height ของ device | orientation (landscape/portrait) | resolution
  • ⭐ @media mediatype and (expressions) { CSS Block; }
  • ตัวอย่าง: default black | max-width: 768px → lightgreen | min-width: 1000px → red
  • ⭐ [Ex2] div 4em | ≤768px → 2em | 769–999 → 4em | ≥1000 → 8em (รันแล้ว 32/64/128px)
  • responsive layout: มือถือ = ลิงก์เรียงลง คอลัมน์ซ้อน | จอใหญ่ = ลิงก์แนวนอน 3 คอลัมน์
  • ⭐ Viewport = พื้นที่ที่ผู้ใช้เห็น | HTML5 คุมผ่าน <meta> | RWD ต้องใส่ใน <head>: <meta name="viewport" content="width=device-width, initial-scale=1.0" /> | width=device-width = ตามความกว้างจอ | initial-scale = ซูมเริ่มต้น | คุม dimensions + scaling
Mobile-first ex. (39–43) ปกติ (มือถือ) @media screen and (min-width: 600px)
header #f1f1f1 #F5B7B1
nav flex column row-reverse + justify-content flex-start (ชิดขวา: Link3 Link2 Link1)
.container flex column row
.column #FFC300 #EBDEF0
  • ทดสอบใน Developer Tools (iPhone X 375×812 → แบบมือถือ | iPad Pro 1024×1366 → แบบจอใหญ่)

6. Bootstrap (สไลด์ 45–62)

  • CSS framework = โครงพื้นฐานเริ่มเร็ว | เลือกตาม Faster-built, Performance, Easy UI components | อื่น ๆ: Tailwind CSS, Bulma, UIkit
  • ⭐ Bootstrap = front-end framework ฟรี | responsive ง่าย | templates HTML+CSS | responsive + mobile-first อยู่ในแกนหลัก | v.5.0
  • ⭐ 4 ขั้น: (1) HTML5 template + viewport (2) BS CSS + JS ใน <head> (3) layout ด้วย grid (4) class/components
  • Step 1: BS ต้องใช้ HTML5 doctype | meta charset="utf-8" | viewport → rendering + touch zooming (mobile-first)
  • Step 2: compiled CSS (<link>) + JS (<script> bootstrap.bundle.min.js) จาก CDN
  • ⚠️ เวอร์ชันไม่ตรง: สไลด์ 47 v.5.0 | สไลด์ 49 5.0.2 | สไลด์ 50–51 5.2.0
  • ⭐ ต้องมี container ครอบเนื้อหา (container จำเป็นสำหรับ grid) | container → Rows → Columns
⭐ container ความกว้าง
.container max-width ที่แต่ละ breakpoint
.container-fluid 100% ทุก breakpoint
.container-{bp} 100% จนถึง bp ที่ระบุ
(สไลด์ 54) <576 sm ≥576 md ≥768 lg ≥992 xl ≥1200 xxl ≥1400
.container / -sm 100% 540 720 960 1140 1320
-md 100% 100% 720 960 1140 1320
-lg 100% 100% 100% 960 1140 1320
-xl 100% 100% 100% 100% 1140 1320
-xxl 100% ×5 1320
-fluid 100% ทุกช่อง
  • container = เว้นขอบ | container-fluid = เต็มจอ | class="display-3 text-center" = ใส่หลาย BS class ได้
  • ⭐ grid: สร้างด้วย flexbox | ≤ 12 columns ต่อ row | container → row → column → content | .col จัดใหม่อัตโนมัติ หรือใช้ 6 breakpoints
  • ⭐ breakpoints: X-Small <576 (ไม่มี infix) | sm ≥576 | md ≥768 | lg ≥992 | xl ≥1200 | xxl ≥1400
  • ⭐ col-sm-6 = 6 หน่วยตั้งแต่ sm | จอ <576px ซ้อนลง | ผลรวม col ≤ 12 | ตัวอย่าง: 6+6 / 8+4 (กว้าง 677 เคียงกัน, 424 ซ้อน 4 บรรทัด)
  • ⭐ [EX2] <main class="container"> > row: col-sm-6, col-sm-6 | row: col-sm-3, col-sm-8, col-sm-1 (3+8+1=12) — สไลด์ไม่ระบุ bp ใช้ sm ตามสไลด์ 57 (รันกับ BS 5.2.0 แล้ว)
  • Step 4: Content Typography, Image, Table, Figures | Utility Text, Spacing, Vertical align, Color | Components Accordion, Card, Carousel, Dropdown, List Group, Navbar, Form, Modal, Toast
  • ตัวอย่าง Card: Character Cards 4 ใบ (รูป + ชื่อ + ข้อความ + ปุ่ม More...) จาก Card (Image cap / title / text / Go somewhere)
  • framework อื่น (สไลด์ 62): tailwindcss, Bootstrap, Foundation 6, Bulma + โลโก้ "M" ชมพู (ไม่มีชื่อ)
