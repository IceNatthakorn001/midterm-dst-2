0. เป้าหมาย (สไลด์ 1–3)

  • media (audio/video) | form + form elements + validation | semantic elements → หน้าเว็บมี layout ง่าย ๆ

1. RECAP (สไลด์ 4–9)

  • HTML = HyperText Markup Language | ไฟล์ .html/.htm | ชุด tag บอก browser ว่าแสดงยังไง
  • ⭐ <!DOCTYPE html> ต้องมาก่อนสุด | <html> ครอบทุก element ยกเว้น DOCTYPE | <head> = title, scripts, styles, meta | <body> = เนื้อหา | <title> = แสดงบน toolbar
  • Tip: เริ่มด้วย DOCTYPE/html/head/title/body เสมอ | indent element ที่ซ้อน
  • ⭐ Nesting: tag ซ้อนได้ ห้าม overlap → <t1>..<t2>..</t2>..</t1> ✔ | <t1>..<t2>..</t1>..</t2> ✘
  • Basic tags: h1–h6 (h1 ใหญ่สุด) | p | br | a + href | ol (เลข) | ul (bullet) | li | dl + dt/dd | img + src,alt | <!-- -->
  • table / tr (แถว) / ⭐ th = หนา+กลาง / td = ปกติ+ชิดซ้าย
  • ⚠️ สไลด์ 8 เขียน <p> "No Closing tags" แต่ตัวอย่างอื่นใช้ </p> ตลอด

2. HTML Media (สไลด์ 10–13)

tag format attribute
⭐ Audio <audio> + <source src type="audio/mp3"> MP3, WAV, OGG autoplay, controls
⭐ Video <video> + <source> (หลายอันได้) MP4, WebM, OGG autoplay, controls, width, height
YouTube <iframe> src="https://www.youtube.com/embed/<VideoId>" width, height
  • autoplay = เล่นเอง | controls = ปุ่ม play/pause/volume | ก่อน HTML5 วิดีโอต้องใช้ plug-in (flash)

3. HTML Form (สไลด์ 14–17)

  • form = กลุ่มคำสั่ง รับ input จากผู้ใช้ | <form>...</form> แล้วใส่ form element ข้างใน
  • ⭐ form element ทุกตัวต้องอยู่ใน <form>
  • elements: input | textarea (หลายบรรทัด) | select + option (drop-down) | button (submit/reset/button) | fieldset (กรอบกลุ่ม)
  • ตัวอย่างสไลด์ 16: form > fieldset > legend "Student Information" + label/input (text, text, date) + button submit

4. <input type=...> (สไลด์ 18–28)

type สรุป
text บรรทัดเดียว · ⭐ <label for="x"> ↔ id="x" → ดีต่อ screen readers
password บรรทัดเดียว masked
⭐ radio เลือก 1 · name เดียวกัน = กลุ่ม · checked = default
⭐ checkbox เลือก หลาย · name เดียวกัน · checked default ได้หลายช่อง
tel ตรวจ pattern ตอน submit · [0-9]{3}-[0-9]{3}-[0-9]{4} = XXX-XXX-XXXX · Nah~~~ → "Please match the requested format."
email ตรวจรูปแบบอีเมลตอน submit · I do not care → "Please include an '@'..."
date date picker · จำกัดด้วย min / max เช่น max="2010-01-01"
week / month / datetime-local / time Week 05, 2020 / January 2020 / วัน+เวลา / 09:03 PM

⭐ Regex (pattern) = ลำดับตัวอักษรที่เป็น search pattern ตรวจตอน submit

Regex ความหมาย valid
[A-Za-z]{3} ตัวอักษร 3 ตัว THA tha Tha tHA
[A-Z]{5,} พิมพ์ใหญ่ ≥ 5 HELLO WORLD
.{2,4} อะไรก็ได้ 2–4 ตัว $o Wh@+ T0o
[0-9]{2}88[0-9]{3} ##88### 5088111 6288999

5. textarea / select / button / fieldset (สไลด์ 29–33)

  • textarea = หลายบรรทัด | ขนาด rows / cols | เกิน → scroll bar
  • select + option | value (CS) vs ข้อความที่เห็น (Comp.Sci.) | ⭐ selected = default
  • ⭐ button 3 type: button (เรียก function) | reset (คืนค่าเริ่มต้น) | submit (ส่งทุก input ไป target)
  • fieldset = กรอบกลุ่ม | legend = caption บนกรอบ
  • ⚠️ สไลด์สะกด name="fistname" (ไม่ใช่ firstname) — URL GET ก็เป็น fistname=

6. [EX2] Sign-Up Form (สไลด์ 34)

  • ชื่อ → type="text" | อีเมล → type="email" | ปฏิทินสิ้นสุด 1 ม.ค. 2565 (พ.ศ.) → max="2022-01-01" | <button type="submit"> + <button type="reset"> | ทั้งหมดใน <form>

7. Form Validation (สไลด์ 35–39)

  • browser ตรวจว่า ถูกรูปแบบ + อยู่ใน constraints | ⭐ client side 2 วิธี: HTML5 attributes / JavaScript
  • ⭐ 6 attributes: min | max | pattern (regex) | title (อธิบาย pattern, ใช้คู่ pattern) | placeholder (คำใบ้จาง ๆ) | required (ต้องกรอก)
  • ผล: placeholder "Your e-mail" | required ว่าง → "Please fill out this field." | Country code [A-Z]{3} กรอก "United States" → "Please match the requested format." + ข้อความ title

8. Form Submission (สไลด์ 40–44)

  • ⭐ action = ส่งไปไหน | method = GET / POST
  • Submit → Validation → invalid: กลับไปฟอร์ม | ผ่าน: ไป Server/ปลายทางใน action (HTTP GET/POST)
⭐ GET ⭐ POST
ข้อมูล ใน URL เป็น name=value ข้อมูล ใน packet
somewhere.html?fistname=Jidapa&lastname=K. somewhere.html
ชื่อใน URL = name ในฟอร์ม

9. Semantic Elements (สไลด์ 45–57)

  • Semantic = มีความหมาย | ใช้วาง layout ร่วมกับ CSS | ช่วย screen readers / search engines
  • แบบเก่า: <div class="header|menubar|section|article|footer">
  • ⭐ header (หัวเอกสาร/section) | nav (ลิงก์นำทาง/menu bar) | section (ส่วนของเอกสาร) | article (บทความ) | aside (เนื้อหาข้าง/sidebar) | footer (ท้ายเอกสาร/section)
  • ตัวอย่าง: header <h1> | footer Posted by + Contact | nav ลิงก์ HTML/HTML5/CSS/JavaScript | section Lyrics | aside "should be related to the surrounding content"
  • article ซ้อน article ได้ (Famous Cities > London, Paris, Tokyo)
  • ⭐ article = independent, self-contained (forum post, blog post, news feeds, comments) | section = generic section | ซ้อนกันได้ทั้งสองทาง
  • ตัวอย่างเว็บจริง: แถบบน = header | เมนูซ้าย = nav | Recently accessed courses / Course overview = section

10. Web Layouts (สไลด์ 58–62)

  • พื้นฐาน: Header / Navigation Bar / Content–Main Content–Content / Footer
  • ⭐ ตามอุปกรณ์: Mobile 1-column | Tablet/Laptop 2-column | Desktop 3-column
  • HTML: header > h1 | nav > a×3 | <article class="row"> > <article class="column">×3 | footer > h1
  • ไม่มี CSS → เรียงลงมาแนวตั้งหมด | มี CSS → 3 คอลัมน์ข้างกัน, nav แถบน้ำเงิน
  • CSS: header, footer {background-color:#f1f1f1; padding:3px; text-align:center} | nav {overflow:hidden; background-color:darkblue}
