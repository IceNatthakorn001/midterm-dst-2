1. ทำไมต้องมี CSS? HTML อย่างเดียวไม่พอเหรอ? สไลด์ 3–5

แก่นHTML ช่วยวาง "โครง" หน้าเว็บแต่ไม่มี style — CSS คือภาษาที่บอกว่า element จะแสดงผลยังไง แยก style ออกจาก tag HTML และถ้าใช้ไฟล์ CSS ภายนอกจะประหยัดแรงได้มาก

1.1 หน้าเว็บไม่มี CSS vs มี CSS ต่างกันยังไง? สไลด์ 3–4

แก่นHTML ชุดเดียวกัน — ไม่มี CSS ทุกอย่างเรียงลงมาเป็นตัวหนังสือธรรมดา, ใส่ CSS แล้วกลายเป็น layout ที่มีสี มีแถบเมนู และมี 3 คอลัมน์

โค้ด HTML ส่วน <body> ที่ใช้ (สไลด์ 3):

    <a href="#">Link</a>
    <a href="#">Link</a>

<article class="container">

        <h2>Column1</h2>
        <p>Lorem ipsum dolor sit amet … </p>
    </article>
    <article class="column">

        <p>Lorem ipsum dolor sit amet … </p>

1.2 CSS คืออะไร? สไลด์ 5

แก่นCSS = Cascading Style Sheets ใช้บอกว่า HTML element จะแสดงบนจอ กระดาษ หรือสื่ออื่นยังไง

  • Cascading Style Sheets (CSS) สร้างขึ้นมาเพื่อ อธิบายว่า HTML elements จะแสดงผลยังไง บน screen, paper หรือ media อื่น ๆ
  • CSS แยก style formatting ออกจาก HTML tags — HTML ดูแลโครง/เนื้อหา, CSS ดูแลหน้าตา
  • ใช้ CSS จัดการ style ของหน้าเว็บ โดยเฉพาะเมื่อใช้ external style sheet จะ ประหยัดแรงได้มาก (แก้ไฟล์เดียว เปลี่ยนทุกหน้า — ดูหัวข้อ 5.2)

2. CSS เขียนยังไง? สไลด์ 6–8

แก่น1 rule = selector + declaration block { } ข้างในเป็น declaration หลายอันรูปแบบ property: value; และ comment เขียนด้วย /* ... */ — สีระบุได้ด้วยชื่อสีหรือรหัส hex #RRGGBB

2.1 ส่วนประกอบของ CSS rule มีอะไรบ้าง? สไลด์ 6

แก่นSelector → Declaration block → Declaration (property : value;) + Comment

body {
  background-color: red;
  font-family: Arial;
}
/* More CSS declaration
   blocks defined below */

ส่วน ในตัวอย่าง คืออะไร
Selector body ชี้ว่าจะแต่ง element ไหน
Declaration block ทุกอย่างใน { ... } กลุ่มของ declaration ของ selector นี้
Declaration background-color: red; 1 คำสั่ง รูปแบบ property : value;
Comment /* More CSS declaration blocks defined below */ หมายเหตุ เขียนใน /* */

2.2 Selector, declaration, property ต่างกันยังไง? สไลด์ 7

แก่นselector ชี้ element, declaration = ชื่อ property + value คั่นด้วย : ปิดด้วย ;, property คือ style ที่อยากเปลี่ยน

  • Selector ชี้ไปที่ HTML element ที่ต้องการแต่ง
  • แต่ละ declaration มี ชื่อ CSS property กับ value คั่นด้วย colon (:) และ ปิดท้ายด้วย semicolon (;)
  • CSS Property คือ style attribute ที่ต้องการเปลี่ยน (เช่น สีพื้น ขนาดตัวอักษร)

ตัวอย่าง: แต่ง <header> (สไลด์ 7)

header {
    background-color: darkblue;
    text-align: center;
    padding: 30px;
    font-size: 35px;
    color: white;
}

ผลในรูป: แถบ header สีน้ำเงินเข้ม ตัวหนังสือ "Only on PlayStation" สีขาว อยู่กลาง ตัวใหญ่

declaration ทำอะไร
background-color: darkblue; สีพื้นน้ำเงินเข้ม
text-align: center; จัดข้อความกลาง
padding: 30px; เว้นที่ว่างรอบเนื้อหา 30px
font-size: 35px; ขนาดตัวอักษร 35px
color: white; สีตัวอักษรขาว

2.3 กำหนดสีใน HTML/CSS ยังไง? สไลด์ 8

แก่นใช้ได้ 2 แบบ — ชื่อสี (เช่น red) หรือรหัส RGB เลขฐาน 16 #RRGGBB (2 หลักแรก = แดง, 2 หลักกลาง = เขียว, 2 หลักท้าย = น้ำเงิน)

ชื่อสี รหัส hex ชื่อสี รหัส hex
red #FF0000 orange #FFA500
green #00FF00 gold #FFD700
blue #0000FF ivory #FFFFF0
magenta #FF00FF maroon #800000
cyan #00FFFF etc…
  • ในสไลด์ red / green / blue ไฮไลต์ตำแหน่ง FF ไว้: red = FF อยู่คู่แรก, green = คู่กลาง, blue = คู่ท้าย → เห็นว่าแต่ละคู่คุมสีหนึ่งช่อง
header {
    color: darkblue;
    /* or color: #4169E1; */
}

💡 จำ #RRGGBB ว่า "แดง-เขียว-น้ำเงิน" ตามลำดับ RGB — ดูจาก red #FF0000 / green #00FF00 / blue #0000FF ที่ FF ย้ายจากคู่แรก → คู่กลาง → คู่ท้าย

3. Selector มีแบบไหนบ้าง แต่ละแบบเลือก element ไหน? สไลด์ 9–21

แก่นselector บอกว่า "จะใส่ style ที่ไหน" — * ทุก element, p ตามชื่อ tag, .x ตาม class, #x ตาม id, a, b จับกลุ่ม, a b ลูกหลานที่อยู่ข้างใน, a:hover ตามสถานะ

3.1 HTML ตัวอย่างที่ใช้ทั้งหัวข้อ + โจทย์ สไลด์ 10

แก่นทุกสไลด์ selector ใช้ HTML ชุดเดียวกันและ style ชุดเดียวกัน (กลาง, 30pt, sans-serif, สี coral) เปลี่ยนแค่ selector — ดูว่าบรรทัดไหนเปลี่ยนเป็นสี coral

Selectors define WHERE to apply the CSS style rules เช่น "ทุก <p>" หรือ "ทุก <div> ที่อยู่ใน <p>"

<!DOCTYPE html>
<html>
<head>
    <title>CSS Selectors</title>
</head>
<body>
    <article>
        <p id="p1">This is paragraph 1
            <div>Hello! div 1</div>
        </p>
        <div class="clsSp">This is another
            div</div>
        <p class="clsSp">This is paragraph 2</p>
    </article>
    <p>This is paragraph 3</p>
</body>
</html>

โครงตามที่เขียนในโค้ด:

โจทย์ style (สไลด์ 10): Align in the center, with the font size of 30 pt, sans serif style with the "coral" color → ทุกสไลด์ใช้ declaration ชุดนี้:

text-align: center;
color: coral;
font-family: sans-serif;
font-size: 30pt;

⚠️ ผลรันจริงต่างจากโครงที่เขียน: ในผลลัพธ์ของสไลด์ 12 และ 18 บรรทัด "Hello! div 1" ไม่เปลี่ยนสี แม้โค้ดเขียน <div> ไว้ใน <p id="p1"> — ลองรันใน Chrome แล้วพบว่า browser ปิด <p> ให้เองก่อนถึง <div> ทำให้ <div> ไปเป็นลูกของ <article> ไม่ใช่ลูกของ <p> → ตัวอย่าง "ทุก <div> ใน <p>" ของสไลด์ 10 จึงใช้กับ HTML ชุดนี้จริงไม่ได้ ถ้าข้อสอบถามตามสไลด์ ให้ตอบตามรูปผลลัพธ์ในสไลด์ (div 1 ไม่ถูกแต่ง)

3.2 Universal selector * สไลด์ 11

แก่น* เลือก "ทุก element" ในหน้า

* { /* apply these CSS to all tags*/
    text-align: center;
    color: coral;
    font-family: sans-serif;
    font-size: 30pt;
}

ผล: ทั้ง 5 บรรทัด (paragraph 1, Hello! div 1, another div, paragraph 2, paragraph 3) เป็นสี coral ตัวใหญ่อยู่กลาง

3.3 Element selector p สไลด์ 12

แก่นใช้ชื่อ tag HTML เป็น selector → แต่งทุก tag ชื่อนั้นในหน้า

p { /* apply these CSS to all <p> */
    ...
}

ผล: paragraph 1, 2, 3 เป็นสี coral / "Hello! div 1" กับ "This is another div" ยังเป็นตัวธรรมดา (เพราะเป็น <div>)

3.4 Class selector .clsSp สไลด์ 13

แก่นใช้ attribute class ใน tag เป็น selector — เขียนด้วยจุดนำหน้า .ชื่อclass

.clsSp { /* For class "clsSP" */
    ...
}

ผล: "This is another div" (<div class="clsSp">) และ "This is paragraph 2" (<p class="clsSp">) เป็นสี coral — ข้าม tag ได้ ขอแค่มี class นี้

3.5 ผูก class กับ element: p.clsSp สไลด์ 14

แก่นชื่อtag.ชื่อclass = เฉพาะ tag นั้นที่มี class นั้น

p.clsSp { /* For <p> with class "clsSP" */
    ...
}

ผล: เหลือแค่ "This is paragraph 2" — <div class="clsSp"> ไม่โดนเพราะไม่ใช่ <p>

3.6 หลาย class ใน element เดียว สไลด์ 15

แก่นattribute class ใส่ได้ "หนึ่งหรือหลาย" ชื่อ คั่นด้วยช่องว่าง เช่น class="line red" → ได้ style ของทั้งสอง class

  • class: Specifies one or more class names for an element
  • ใส่ หลาย class ให้ คั่นด้วยช่องว่าง (space) เช่น <p class="line red">
.line {
    text-decoration: underline;
}
.red {
    color: red;
}

<p class="line red">This is paragraph 3</p>

ผล: "This is paragraph 3" เป็น ขีดเส้นใต้ + สีแดง (ได้จากทั้ง .line และ .red)

  • ในรูปผลลัพธ์ "This is another div" กับ "This is paragraph 2" ยังเป็นสี coral ตัวใหญ่อยู่ ซึ่งไม่ได้มาจาก .line/.red ในกล่อง CSS ของสไลด์นี้ (สไลด์ไม่ได้อธิบาย)

3.7 ID selector #p1 สไลด์ 16

แก่นใช้ attribute id (ตัวระบุที่ไม่ซ้ำ — unique identifier) เป็น selector เขียนด้วย #ชื่อid

#p1 { /* For id "p1" */
    ...
}

ผล: เฉพาะ "This is paragraph 1"

3.8 Grouping #p1, .clsSp สไลด์ 17

แก่นหลาย selector ที่ใช้ style เหมือนกัน → เขียนรวมกัน คั่นด้วย comma (,) ไม่ต้องเขียนซ้ำ

#p1, .clsSp {
    ...
}

ผล: paragraph 1 (จาก #p1) + another div และ paragraph 2 (จาก .clsSp)

3.9 Descendant selector article p สไลด์ 18

แก่นเขียน selector ต่อกันคั่นด้วย "ช่องว่าง" = เลือก element ที่เป็นลูกหลาน (descendants) ของอีก element

article p {/* all <p> inside <article> */
    ...
}

ผล: paragraph 1 และ paragraph 2 (อยู่ใน <article>) / paragraph 3 ไม่โดน เพราะอยู่นอก <article>

⚠️ ระวังสับสน: #p1, .clsSp (มี comma) = "อันนี้ หรือ อันนั้น" / article p (มี space) = "p ที่อยู่ ข้างใน article"

3.10 Pseudo-class a:hover a:active สไลด์ 19

แก่นpseudo-class ใช้กำหนด style ตาม "สถานะพิเศษ" ของ element เช่น ลิงก์ที่เคยเข้าแล้ว (visited), เอาเมาส์ชี้ (hover), กำลังกด (active) — เขียน selector:สถานะ

a {  /* Link at normal state */
    color: blue;
}
a:hover { /* Being mouse over */
    color: #00FF00; /* green */
}
a:active { /* Being selected */
    color: #FF0000; /* red */
}

<a href="">Link Link!!</a>
สถานะ selector สีของ "Link Link!!"
Normal state a น้ำเงิน
Mouse-over state a:hover เขียว #00FF00
Being-clicked state a:active แดง #FF0000

4. ถ้า rule ขัดกัน ใครชนะ? สไลด์ 22–23

แก่นID selector เจาะจงที่สุด → class → element ตามลำดับ; ถ้าเจาะจงเท่ากัน rule ที่อยู่หลังสุดชนะ

4.1 CSS Specificity คืออะไร? สไลด์ 22

แก่นเมื่อมี rule 2 อันขึ้นไปชี้ element เดียวกันและขัดกัน browser ใช้ "ความเจาะจง" (specificity) ตัดสิน

/* 1 */
#header3 { background-color: cyan;}
/* 2 */
.style_h1 { background-color: greenyellow;}
/* 3 */
h1 { background-color: yellow;}
/* 4 */
h1 { background-color: orange;}

<div>
    <h1>Test 1</h1>
    <h1 class="style_h1">Test 2</h1>
    <h1 id="header3">Test 3</h1>
</div>
element rule ที่ตรง ผล เหตุผล
Test 1 <h1> 3 (yellow), 4 (orange) orange เป็น element selector ทั้งคู่ เจาะจงเท่ากัน → อันหลังสุด ชนะ
Test 2 <h1 class="style_h1"> 2, 3, 4 greenyellow class เจาะจงกว่า element
Test 3 <h1 id="header3"> 1, 3, 4 cyan id เจาะจงที่สุด
  • The ID selectors are highly specific, then class, and then elements.
  • Equal specificity: the latest rule counts (เจาะจงเท่ากัน → rule ล่าสุดชนะ)

💡 เปรียบเหมือนเรียกคน: เรียกด้วย "เลขบัตรประชาชน" (id) ชัดที่สุด > "ชื่อกลุ่ม/ชมรม" (class) > "นักศึกษาทุกคน" (element) — ถ้าคำสั่งระดับเดียวกันมาสองครั้ง เชื่อคำสั่งล่าสุด

4.2 [Ex2] สีพื้นของ <h1> คืออะไร? สไลด์ 23

แก่นตอบ green — #header ไม่ตรง (id จริงคือ "blue"), .red ไม่ตรง, เหลือ h1.green กับ h1 → class+element เจาะจงกว่า element ล้วน

<!DOCTYPE html>
<html>
  <head>
    <title>Ex1</title>
    <style>
      #header {background-color: blue;}
      h1.green {background-color: green;}
      h1 {background-color: yellow}
      .red {background-color: red;}
    </style>
  </head>
  <body>
    <h1 id="blue" class="green">This is our tester</h1>
  </body>
</html>

เฉลยทีละขั้น:

  1. ดูว่า <h1> มีอะไร: tag = h1, id="blue", class="green"
  2. ไล่ทีละ rule ว่าตรงไหม:
    • #header → ต้องมี id="header" แต่ h1 มี id="blue" → ไม่ตรง (ชื่อ id "blue" ไม่ได้แปลว่าได้สีน้ำเงิน)
    • h1.green → เป็น <h1> และมี class green → ตรง → green
    • h1 → เป็น <h1> → ตรง → yellow
    • .red → ไม่มี class red → ไม่ตรง
  3. เหลือ 2 rule ที่ตรงและขัดกัน: h1.green (มี class) เจาะจงกว่า h1 (element ล้วน) → ได้ green

✅ คำตอบ: green (รันใน Chrome ได้ rgb(0, 128, 0) = green ตรงกัน)

⚠️ กับดักของข้อนี้: ชื่อ id/class เป็นแค่ "ชื่อ" ไม่ใช่สี — ต้องดูว่า selector ตรงกับ element จริงหรือเปล่า

body {

6.3 Internal vs External — อะไรชนะ? สไลด์ 36

แก่นInternal กับ External มีลำดับความสำคัญเท่ากัน ไม่ใช่ว่า Internal ชนะ External เสมอ — อันที่ include ทีหลังจะทับ

<!DOCTYPE html>
<html lang="en">
    <head>
        <style>
            h1 {
                background-color: deeppink;
            }
        </style>
        <link rel="stylesheet" href="myStyle.css" />
    </head>
    <body>
        <h1>Let's see the style output</h1>
    </body>
</html>

/* myStyle.css */
h1 {background-color: orange;
    font-family: sans-serif; }
  • Internal CSS and External CSS has equally priority of the style, i.e., it is not always that Internal CSS override the External CSS
  • ตัวอย่างนี้ external CSS ถูก include หลัง internal CSS
  • All styles that affect <h1>: background-color: deeppink / background-color: orange; / font-family: sans-serif;
  • ผล: พื้น orange (external มาทีหลัง) + ฟอนต์ sans-serif (ไม่มีใครขัด) — สไลด์ไม่ได้โชว์รูปผลลัพธ์ แต่รันใน Chrome ได้ orange ตรงตามหลักที่สไลด์บอก

⚠️ สไลด์ 35 เขียนเรียง "Internal > External" แต่สไลด์ 36 บอกว่าทั้งสองเท่ากัน — ใช้ความหมายของสไลด์ 36: ที่สไลด์ 35 Internal ชนะเพราะ <style> อยู่ หลัง <link> ในโค้ดตัวอย่างนั้น

6.4 [Ex3] สีพื้นของ <h1> คืออะไร? สไลด์ 37

แก่นตอบ deeppink — external มาทีหลังก็จริง แต่ .colored (class) เจาะจงกว่า h1 (element) จึงชนะ

<head>
    <style>
        .colored {
            background-color: deeppink;
        }
    </style>
    <link rel="stylesheet" href="myStyle.css" />
</head>
<body>
    <h1 class="colored">
        Let's see the style output</h1>
</body>

/* myStyle.css */
h1 {background-color: orange;}

เฉลยทีละขั้น:

  1. rule ที่ตรง <h1 class="colored"> มี 2 อัน: .colored → deeppink (internal) และ h1 → orange (external)
  2. เทียบ specificity ก่อน: .colored = class, h1 = element → class เจาะจงกว่า
  3. "the latest rule counts" ใช้ เฉพาะตอน specificity เท่ากัน (สไลด์ 22) — ข้อนี้ไม่เท่า จึงไม่ต้องดูว่าใครมาทีหลัง

✅ คำตอบ: deeppink (รันใน Chrome ได้ rgb(255, 20, 147) = deeppink ตรงกัน)

6.5 [Ex4] สีพื้นของ <h1> คืออะไร? สไลด์ 38

แก่นตอบ orange — ทั้งสองเป็น .colored เจาะจงเท่ากัน และ internal กับ external ศักดิ์เท่ากัน → external ที่มาทีหลังชนะ

  2. specificity เท่ากัน (class ทั้งคู่)
  3. internal กับ external ศักดิ์เท่ากัน (สไลด์ 36) → ดูลำดับ: <link> (external) อยู่ หลัง <style> → rule หลังสุดชนะ

✅ คำตอบ: orange (รันใน Chrome ได้ rgb(255, 165, 0) = orange ตรงกัน)

                               border:width, style,color;*/
    margin: 40px; /* space around elements from borders */
    padding: 20px; /* space around an element's content */
}

ชั้น property ความหมาย (ตาม comment ในสไลด์)
Margin (นอกสุด) margin: 40px; space around elements from borders — ที่ว่างรอบนอกเส้นขอบ
Border border: 5px solid gray; เส้นขอบ — shorthand ของ border: width style color;
Padding padding: 20px; space around an element's content — ที่ว่างระหว่างเส้นขอบกับเนื้อหา
Content (ในสุด) width: 600px; เนื้อหาจริง

ผล: กล่องเส้นทึบสีเทาหนา 5px ข้อความอยู่ห่างจากขอบด้านใน และกล่องห่างจากของรอบ ๆ

💡 เปรียบเหมือนรูปติดกรอบแขวนผนัง: รูป = content, กระดาษรองขาวรอบรูป = padding, กรอบไม้ = border, ระยะห่างจากรูปอื่นบนผนัง = margin

7.5 Dimension: width / height สไลด์ 44

แก่น% = สัดส่วนของ container (relative), px = ค่าตายตัว (fixed)

/* Height and Width property*/
.outerBox {
    width: 80%; /* 80% of its container (relative) */
    height: 400px; /* height in pixel (fixed) */
    padding: 0px;
    background-color: palevioletred;
}
.innerBox {
    width: 50%; /* 50% of its container */
    margin: 0px;
    padding: 0px;
    background-color:ghostwhite;
}
  • กล่องชมพูด้านนอก กว้าง 80% ของความกว้าง browser
  • กล่องขาวด้านใน กว้าง 50% ของกล่องด้านนอก (relative)
  • ความสูงของกล่องนอกเป็น 400px ตายตัว

7.6 CSS Units มีกี่แบบ? สไลด์ 45

แก่นหน่วยความยาวมี 2 แบบ — Absolute (ตายตัว: cm, mm, in, px, pt) กับ Relative (เทียบกับค่าอื่น: em, rem, vm, %) — relative เช่น em/rem ทำ layout ที่ปรับขนาดได้ดีบนหลายอุปกรณ์

  • ใช้กับค่า "length" เช่น width, height, margin, padding, font-size ฯลฯ
แบบ ความหมาย ตัวอย่าง
Absolute length units ตายตัว — ขนาดที่ระบุจะแสดงออกมาเท่านั้นเป๊ะ cm, mm, in, px, pt
Relative length units ความยาว เทียบกับ length property อื่น em (relative to font-size), rem, vm, %
  • Relative unit เช่น em และ rem สร้าง perfectly scalable layout สำหรับแสดงบนอุปกรณ์ต่าง ๆ

⚠️ สไลด์ 45 เขียน "vm" — หน่วย viewport ที่ใช้กันจริงเขียนว่า "vw" (น่าจะพิมพ์ผิด) ถ้าข้อสอบถามให้ระวังตัวเลือกนี้ หรือถามอาจารย์

7.7 Float: ให้ element ลอยไปซ้าย/ขวา สไลด์ 46

แก่นfloat บอกว่า element จะลอยยังไง: none | left | right — ข้อความรอบ ๆ จะไหลอ้อมรูปที่ลอย

img { float: none; }   img { float: left; }   img { float: right; }
ค่า ผลในรูปตัวอย่าง (รูปกระต่าย "clap clap" + ข้อความ Lorem ipsum)
float: none; รูปอยู่ในบรรทัดตามปกติ ข้อความเริ่มต่อที่ระดับล่างของรูป แล้วไหลลงไปใต้รูป ไม่อ้อมข้าง
float: left; รูปลอยไป ซ้าย ข้อความไหลอ้อมอยู่ ทางขวา ของรูป
float: right; รูปลอยไป ขวา ข้อความไหลอ้อมอยู่ ทางซ้าย ของรูป

7.8 Clear: ห้ามมีของลอยข้าง ๆ สไลด์ 47

แก่นclear กำหนดว่าด้านไหนของ element "ห้ามมี" element ที่ลอยอยู่ข้าง ๆ: none | left | right | both

  • clear: specifies what elements can float beside the cleared element and on which side
/* ซ้าย */                 /* ขวา */
img { float: left; }       img { float: left; }
p   { clear: none; }       p   { clear: left; }
p { clear: none; } p { clear: left; }
ผล ข้อความ <p> ไหลอยู่ ข้างขวาของรูป ที่ลอยซ้าย <p> ลงไปเริ่มใต้รูป — "Not allowed any float elements on its left"

💡 เปรียบเหมือนป้าย "ห้ามจอดฝั่งซ้าย": clear: left ทำให้ <p> ไม่ยอมให้มีของลอยอยู่ทางซ้าย จึงต้องขยับลงไปจนพ้นรูป

8. CSS in Action: จัดเนื้อหาให้อยู่กลาง (Alignment) ทำยังไง? สไลด์ 48–51

แก่นsection { width: 80%; margin: auto; } ทำให้ section แคบลงและอยู่กลาง แล้ว p { border: 1px grey dashed; padding: 10px; } ตีกรอบแต่ละย่อหน้าให้อ่านง่าย

8.1 โครง HTML และเป้าหมาย สไลด์ 48–49

<main>
    <section>
        <p> ... </p>
        <p> ... </p>
    </section>
    <section>
        <p> ... </p>
    </section>
</main>

Original with no CSS (สไลด์ 49) Target Design (สไลด์ 49)
3 ย่อหน้ากว้างเต็มกรอบ ชิดซ้าย ไม่มีกรอบ 3 ย่อหน้าแคบลง อยู่กลาง แต่ละย่อหน้ามี กรอบเส้นประบาง ๆ และมีที่ว่างในกรอบ

8.2 ขั้นที่ 1: ทำให้ section แคบและอยู่กลาง สไลด์ 50

แก่นwidth: 80% = กว้างเทียบกับ container, margin: auto = จัด block element ให้อยู่กลางแนวนอน

section {
   width: 80%;
   margin: auto;
}
  • width: 80%; makes the element width relatively to its container
  • margin: auto; horizontally center a block element
  • ผล: เนื้อหาแคบลงและอยู่กลาง แต่ยังไม่มีกรอบ

8.3 ขั้นที่ 2: ตีกรอบ + เว้นที่ว่างให้ย่อหน้า สไลด์ 51

แก่นborder ประให้เห็นขอบเขต + padding ช่วยให้อ่านง่ายและแบ่ง section ชัดขึ้น

section {
   width: 80%;
   margin: auto;
}
p {
   border: 1px grey dashed;
   padding: 10px;
}
  • padding increase the readability of the text and better partitioning the section
  • ผล: ได้ตาม Target Design

9. CSS in Action: ทำ Navigation bar ทำยังไง? สไลด์ 52–55

แก่นทำ <nav> เป็น block → ทำ <a> ใน nav เป็น block ให้เรียงแถวละอัน + ใส่สีพื้น → แต่งฟอนต์ สี จัดกลาง และ text-decoration: none เอาเส้นใต้ออก

9.1 จุดเริ่มต้นและเป้าหมาย สไลด์ 52

<nav>
    <a href="">Menu 1</a>
    <a href="">Menu 2</a>
    <a href="">Menu 3</a>
</nav>
  • ไม่มี CSS: "Menu 1 Menu 2 Menu 3" เป็นลิงก์ขีดเส้นใต้ เรียงในบรรทัดเดียว — กรอบเขียวคือพื้นที่ <nav> กรอบส้มคือ <a> 1 ตัว
  • Target Design: แถบพื้นฟ้า เมนู 3 อัน เรียงแถวละอัน อยู่กลาง ไม่มีเส้นใต้ ตัวหนังสือสีน้ำเงินเข้ม

9.2 ขั้นที่ 1: ทำ <nav> เป็น block สไลด์ 53

แก่นdisplay: block; = เริ่มบรรทัดใหม่และกินเต็มความกว้าง — ใส่สีเหลืองชั่วคราวไว้ดูพื้นที่ของ block

nav {
   display: block;
   background-color: yellow;
   /* for checking the area of the block */
   padding: 10px;
}
  • display: block; make an element as a block element. It starts on a new line, and takes up the whole width
  • background-color: yellow; ใส่ไว้ เพื่อเช็กพื้นที่ของ block (for checking the area of the block)
  • ผล: แถบเหลืองกว้างเต็ม เมนูยังอยู่บรรทัดเดียวและมีเส้นใต้

9.3 ขั้นที่ 2: ทำ <a> ใน nav เป็น block สไลด์ 54

แก่นstyle ต้องปรับตามโครงของ <nav> — ในที่นี้ <a> คือเมนูแต่ละอัน จึงใช้ descendant selector nav a

nav {
   display: block;
   /* background-color: yellow; */
   /* for checking the area of the block */
   padding: 10px;
}
nav a{
   display: block;
   background-color: #AED6F1 ;
   padding: 5px;
}
  • The style is needed to adjust according to the structure of <nav>
  • For example, the <a> is used as the menu item in <nav>
  • comment สีเหลืองทิ้ง (ใช้เช็กพอแล้ว)
  • ผล: เมนูแยกเป็น แถวละอัน พื้นฟ้า แต่ยังชิดซ้ายและมีเส้นใต้

9.4 ขั้นที่ 3: แต่งตัวอักษร สไลด์ 55

แก่นเพิ่มฟอนต์ สี จัดกลาง และ text-decoration: none; เอาเส้นใต้ของลิงก์ออก → ได้ Target Design

nav a{
   display: block;
   background-color: #AED6F1 ;
   padding: 5px;
   font-family: Arial, sans-serif;
   color: #1F618D;
   text-align: center;
   text-decoration: none;
}
  • text-decoration: none; removes any decoration (underline) that apply
  • ผล: ตรงกับ Target Design ของสไลด์ 52
