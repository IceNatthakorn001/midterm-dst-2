Lecture 3 – Cascading Style Sheet (Part I)

⏱ อ่านประมาณ 8 นาที · 12 หัวข้อ

📖 ฉบับเต็ม⚡ สรุปสั้น
🧠 Quiz Pro

เลขสไลด์ = เลขหน้า PDF

0. เป้าหมาย (สไลด์ 1–2)

  • คุมหน้าตาเว็บด้วย style sheet | เขียน selector / property / value | ใส่ CSS 3 แบบ: inline, internal, external

1. ทำไมต้องมี CSS (สไลด์ 3–5)

  • HTML = โครง but no style | ใส่ CSS → "shape the page to the style we want" (header/nav/3 คอลัมน์/footer)
  • CSS = Cascading Style Sheets อธิบายว่า element แสดงยังไงบน screen, paper, media อื่น
  • ⭐ CSS แยก style ออกจาก HTML | external style sheet ประหยัดแรงมาก

2. Syntax + สี (สไลด์ 6–8)

  • ⭐ selector { property: value; } | Selector → Declaration block {} → Declaration | comment /* */
  • declaration = property + value คั่น : ปิด ; | property = style attribute ที่อยากเปลี่ยน
  • ตัวอย่าง header: background-color darkblue | text-align center | padding 30px | font-size 35px | color white
  • สี = ชื่อสี หรือ #RRGGBB
สี hex สี hex
red #FF0000 orange #FFA500
green #00FF00 gold #FFD700
blue #0000FF ivory #FFFFF0
magenta #FF00FF maroon #800000
cyan #00FFFF etc…
  • ตัวอย่างสไลด์ 8: header { color: darkblue; /* or color: #4169E1; */ }

3. Selectors (สไลด์ 9–21)

  • Selector = WHERE to apply | HTML ตัวอย่าง: article > p#p1 (มี div ข้างใน), div.clsSp, p.clsSp | p นอก article
⭐ Selector ชนิด โดน
* Universal ทั้ง 5 บรรทัด
p Element paragraph 1, 2, 3
.clsSp Class another div, paragraph 2
p.clsSp tag + class paragraph 2
.line .red + class="line red" หลาย class (คั่น space) paragraph 3 ขีดเส้นใต้+แดง
#p1 ID (unique) paragraph 1
#p1, .clsSp Grouping (คั่น comma) p1, another div, paragraph 2
article p Descendant (คั่น space) paragraph 1, 2 (ไม่โดน 3)
  • ⭐ Pseudo-class = สถานะพิเศษ (visited, hover, active): a blue | a:hover #00FF00 | a:active #FF0000
  • [EX1] CSS Diner https://flukeout.github.io/ → ถึง level 10
  • Selector 5 กลุ่ม: Simple (name/id/class) | Combinator (ความสัมพันธ์) | Pseudo-class (state) | Pseudo-elements (บางส่วนของ element) | Attribute (attribute/ค่า)
  • ⚠️ "Hello! div 1" ไม่ถูกแต่งในผลของ p และ article p (browser ปิด <p> ก่อน <div> — รันจริงแล้ว)

4. Specificity (สไลด์ 22–23)

  • ⭐ ID > class > element | ⭐ เท่ากัน → rule หลังสุดชนะ
  • สไลด์ 22: Test1 (h1 yellow, h1 orange) → orange | Test2 .style_h1 → greenyellow | Test3 #header3 → cyan
  • ⭐ [Ex2] <h1 id="blue" class="green"> + #header blue / h1.green green / h1 yellow / .red red → green (#header, .red ไม่ตรง; h1.green > h1)

5. ใส่ CSS 3 วิธี (สไลด์ 24–32)

⭐ เขียนที่ ⭐ ผลกับ
External ไฟล์ .css + <link rel="stylesheet" href="myStyle.css" /> ใน <head> 1 CSS → MANY HTML
Internal <style> ใน <head> หน้านั้นหน้าเดียว
Inline attribute style="..." ใน tag (ใส่ rule อะไรก็ได้) element นั้น
  • games.html + myStyle.css: * Arial | header/footer darkblue ตัวขาว | .row display:flex | .column dashed 1px grey, width 50%, padding 10px (2 คอลัมน์) | .more font-weight 600, block, darkslateblue
  • "change the look of an entire website by changing just one CSS file"
  • Internal ตัวอย่าง: body darkblue + Arial | h1 white italic
  • Inline ตัวอย่าง: body red + Arial | p white 10em

6. Cascading Order (สไลด์ 33–38)

  • ⭐ Inline > Internal > External > Browser Default
  • <body> 3 แหล่ง: external cornflowerblue/serif | internal deeppink/monospace | inline greenyellow/sans-serif → greenyellow + sans-serif
  • ⭐ Internal = External (ศักดิ์เท่ากัน) → อันที่ include ทีหลัง ชนะ | สไลด์ 36: style deeppink แล้ว link orange → orange (+ sans-serif)
ข้อ ขัดกัน ตัดสินด้วย ⭐ ตอบ
Ex2 h1.green vs h1 class > element green
Ex3 .colored (internal) vs h1 (external มาหลัง) class > element deeppink
Ex4 .colored (internal) vs .colored (external มาหลัง) เท่ากัน → หลังสุด orange

7. Basic Properties (สไลด์ 39–47)

  • Font: color grey (#4F4F4F) | font-family specific/generic | font-size 2em (px/em) | font-weight normal/bold | font-style italic
  • Font family: Specific (Arial, Courier News, Google Fonts) | Generic (almost all browsers): ⭐ serif มีขีดปลายเส้น | sans serif ไม่มี | monospaced กว้างเท่ากัน
  • Border: border-color #FF5511 | border-width 2px | border-style dashed (solid/dotted/hidden) | border-radius 12px (แยกมุมได้)
  • ⭐ Box model นอก→ใน: Margin → Border → Padding → Content | width 600px | border: 5px solid gray = shorthand width style color | margin 40px = ที่ว่างรอบนอก border | padding 20px = ที่ว่างรอบ content
  • Dimension: outer width: 80% (relative ต่อ container) height: 400px (fixed) | inner width: 50% ของกล่องนอก
  • ⭐ Units (ใช้กับ width, height, margin, padding, font-size): Absolute cm, mm, in, px, pt | Relative em (เทียบ font-size), rem, vm, % | em/rem → scalable layout
  • ⭐ float: none | left | right (ข้อความไหลอ้อม)
  • ⭐ clear: none | left | right | both — img{float:left} + p{clear:left} → p ลงใต้รูป ("Not allowed any float elements on its left")
  • ⚠️ "Courier News" (น่าจะ Courier New) | "vm" (น่าจะ vw)

8. CSS in Action: Alignment (สไลด์ 48–51)

  • main > section(p, p) + section(p)
  • ⭐ section { width: 80%; margin: auto; } → width เทียบ container, margin: auto = center block แนวนอน
  • p { border: 1px grey dashed; padding: 10px; } → padding เพิ่ม readability + แบ่ง section

9. CSS in Action: Navigation bar (สไลด์ 52–55)

  • nav > a ×3 | เริ่ม: ลิงก์บรรทัดเดียวมีเส้นใต้ → เป้า: แถบฟ้า เมนูแถวละอัน กลาง ไม่มีเส้นใต้
  • ⭐ nav { display: block; background-color: yellow; padding: 10px; } — display: block = บรรทัดใหม่ + เต็มความกว้าง | เหลืองไว้เช็กพื้นที่
  • nav a { display: block; background-color: #AED6F1; padding: 5px; } → แถวละอัน (style ต้องปรับตามโครง nav)
  • เพิ่ม font-family: Arial, sans-serif; color: #1F618D; text-align: center; ⭐ text-decoration: none; = เอาเส้นใต้ออก
