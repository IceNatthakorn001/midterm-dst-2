1. Tic Tac Toe (สไลด์ 3–15)

  • UI: Title | 3x3 grid คลิกได้ | แสดงเครื่องหมายในช่อง | ข้อความตาใคร / ชนะ-เสมอ | Restart button
  • Flow: ดักคลิก → move valid? → update state → เช็กชนะ/เสมอ → หยุดเกม → update UI → Restart
  • ⭐ HTML: div.game-container > div.cell ×9 มี data-cell-index 0–8 (บน 0 1 2 · กลาง 3 4 5 · ล่าง 6 7 8) | h1.game-title | h2.game-status (ว่าง JS เติม) | button.game-restart | <script src="script.js"> (สไลด์วางหลัง </body>)
  • ⭐ CSS: .game-container {display: grid; grid-template-columns: repeat(3, auto); width: 306px; margin: 50px auto} | .cell 100×100px, border #333333, cursor: pointer, line-height 100px, font-size 60px
  • JS: document.querySelectorAll(".cell").forEach((cell) => cell.addEventListener("click", handleCellClick)) | .game-restart → handleRestartGame
⭐ ฟังก์ชัน (สไลด์) ทำอะไร
handleCellPlayed (11) gameState[index] = currentPlayer (state) + clickedCell.innerHTML = currentPlayer (UI)
handlePlayerChange (12) ternary currentPlayer === "X" ? "O" : "X" + แสดงตาใคร
handleResultValidation (13) ไล่ winningConditions 8 แบบ (นอน 3 ตั้ง 3 ทแยง 2) ช่องว่าง → continue
handleCellClick (14) event.target

  • ⚠️ สไลด์ไม่แสดงการประกาศ gameState, currentPlayer, gameActive, statusDisplay, winningMessage(), drawMessage(), currentPlayerTurn() | คอมเมนต์ "weather" = คำผิด

2. JavaScript คืออะไร (สไลด์ 17–21)

  • ⭐ Web app = HTML 1 ไฟล์ (เนื้อหา+โครง) + Media 0+ + CSS 0+ (style) + JS 0+ (dynamic, interactive)
  • หน้าเว็บ: Client-side (device + browser) ⇄ HTTP request/response ⇄ Server-side (web server) — สไลด์ไฮไลต์ Client-side
  • ⭐ JS: เพิ่ม interactivity | scripting, lightweight | ฝังตรงใน HTML | interpreted (ไม่ compile ก่อน) | มี APIs
  • ทำได้: dynamic text | react to events | read/write HTML elements | validate data | detect browser | create cookies

3. ใส่ JS ในหน้าเว็บ (สไลด์ 22–24)

  • ⭐ (1) <script>...</script> ใส่ได้ใน <head>, <body> หรือทั้งคู่ | comment // บรรทัดเดียว, /* */ หลายบรรทัด
  • ⭐ (2) <script src="myScript.js"></script> — ในไฟล์ .js ไม่ต้องมี <script>
  • ⚠️ สไลด์ 24 พิมพ์ "Hello Word!!!" (สไลด์ 23 = World)

4. ตัวแปร (สไลด์ 25–36)

  • Declaration+Initialization var a = "x"; | Declaration var b, c; | Assignment b = "y" | ต่อ string ด้วย + | console.log()
  • Ex สไลด์ 27 → 9999999 Wudhichart Sawangphol
  • ชื่อตัวแปร: ขึ้นต้นด้วยตัวอักษร | ตัวอักษร+ตัวเลข ไม่มีช่องว่าง | ห้ามเป็น keyword
  • ⭐ = = assignment ไม่ใช่เท่ากับ | Ex สไลด์ 30 (Wudhichart → Jidapa + " " + Pa) → Jidapa Pa
  • ⭐ What is the output? (สไลด์ 31–32):
โค้ด Output เพราะ
var number = 1; { var number = 4; } number is 4 var ไม่มี block scope → redeclaration problem

var i = 5; for (var i = 0; i<10; i++) i is 10 i ตัวเดียวกัน
let j = 5; for (let j = 0; j<10; i++) + log i ⚠️ พิมพ์ผิด: เดี่ยว = ReferenceError / ต่อกล่องแรก = infinite loop ถ้าแก้เป็น j++, log j → j is 5
  • const = cannot be updated or re-declared (TypeError / SyntaxError)

5. Data types (สไลด์ 37–39)

  • ⭐ 6 ชนิด: Boolean (true/false) | Number (−(253−1) ถึง 253−1) | String | Null (ตั้งใจไม่มีค่า "Nothing") | Undefined (ยังไม่กำหนดค่า) | Objects
  • typeof: 10 → number | "ten" → string | true → boolean | myNum = "Hello World!!" → string (Is this possible? ได้)
  • ⭐ JS = weakly typed (ตัวแปรเปลี่ยนชนิดได้) — ⚠️ สไลด์เขียน "same data type" ขัดกับตัวอย่าง

6. Objects (สไลด์ 40–48)

  • 2 กลุ่ม: User-defined | Built-in: Number, Dates, Math, Array, String
  • ⭐ เข้าถึง property: .property หรือ ["property"] | ชื่อมีช่องว่าง / ชื่ออยู่ในตัวแปร → ต้องใช้ [ ]
  • ⭐ aCandidate = wudhichart → object ก้อนเดียวกัน แก้ทางไหนเห็นทั้งคู่ → output: age 40, 40 | feesPaid false | parking permit blue, blue | age 40
Built-in จุดจำ + ตัวอย่าง → output
⭐ Number new Number("10")
⭐ Math ไม่มี constructor
Date ms ตั้งแต่ 1 Jan 1970 UTC
⭐ Array ["a","b"] / new Array(5)
⭐ String primitive "..." / new String(...)

7. Operators (สไลด์ 49–56)

  • ⭐ Arithmetic + - * / % (binary) | 5 % 3 = 2 | ** ยกกำลัง | ++x/x++ | -- | unary -x, +x | * / % ก่อน + - | วงเล็บจัดกลุ่ม
  • Assignment: x op= y = x = x op y (= += -= /= *= %= **=)
  • ⭐ === strict = type + content เหมือน | == type-converting (abstract) = แปลงชนิดก่อน
    • "1" === 1 false | "1" === "1" true | "1" == 1 true | "1" == "1" true
    • อื่น ๆ: != !== > >= < <=
  • Logical: && จริงทั้งคู่ | || จริงอย่างน้อย 1 | ! กลับค่า
  • ⭐ Precedence: () → x++ x-- → ! +x -x ++x --x (R→L) → ** → * / % → + - → < <= > >= → == != === !== → && → || → = += (หลังสุด)

8. Execution Control Structure (สไลด์ 57–59)

  • ปกติรัน sequential | Decision = เลือก block ตามเงื่อนไข | Repetition = รันซ้ำขณะเงื่อนไขจริง
  • หัวข้อ: if-then-else | loops | loop กับ Arrays + User-defined Object's Properties

9. Decision (สไลด์ 60–65)

  • if = ทำหรือไม่ทำ | เงื่อนไข = logical/comparison หรืออะไรที่คืน Boolean (เช่น function)
  • ⭐ What is the output?
โจทย์ Output
if 1 === '1' (สไลด์ 60) ไม่มี output
if-else 10 === '1' (สไลด์ 61) The condition num1 === str1 is false
ternary condition ? expr1 : expr2, 1 > 3 ? num1 : num2 (สไลด์ 62) biggerNumber is 3
if-else-if mark = 75 (สไลด์ 63) The grade is B
switch expr = "Soda" (สไลด์ 65) Soda or Sparking Water is 30 Baht.
  • เกรด: 0–<50 F | 50–<60 D | 60–<70 C | 70–<80 B | 80–100 A | นอกช่วง → ERROR: range violation for mark: + mark
  • if-else-if = ซ้อน if-else ใน ส่วน else | เจอตัวแรกที่จริง → ข้ามที่เหลือ
  • ⭐ switch: จับคู่ค่ากับ case | ไม่มี break → ไหลลง case ถัดไป (Soda → Sparking Water) | ไม่ตรงเลย → default (Pepsi → Sorry, we are out of Pepsi.)

10. Loops (สไลด์ 66–73)

  • Loop = iteration = repetition | ⭐ เงื่อนไขต้อง พร้อมก่อนรอบแรก + โค้ดใน loop ต้อง เปลี่ยนเงื่อนไข (กัน infinite loop) | ชนิด: while, do-while, for, label
  • for ([initialization]; [condition]; [final-expression]) — init ครั้งเดียว | condition เช็กก่อนทุกรอบ | final ทำท้ายรอบ
  • break [label]; = ยุติ loop/switch/label | continue [label]; = จบ รอบนี้ ไปรอบถัดไป | label = ชื่อเรียก code block
⭐ What is the output? Output
while n<10: n++; x+=n (สไลด์ 67) n = 10, x = 55
while (1<1) vs do-while (สไลด์ 69) n = 1, x = 0 / n = 2, x = 2 (do-while ทำ ≥ 1 รอบ)
for i=0..<10 (สไลด์ 70) i = 0 … i = 9 (10 บรรทัด)
if(i%3==0) continue myForLoop (สไลด์ 71, 73) 1 2 4 5 7 8
if(i==ind) break myForLoop, ind=5 (สไลด์ 73) Break at i=5!!

11. Counter vs Sentinel (สไลด์ 74–75)

  • ⭐ Counter-controlled = ตัวนับอัปเดตทุกรอบ จบเมื่อถึงค่าที่กำหนด | ใช้ for / while | Ex for (var i=5; i>0; i--) = while เดียวกัน → i = 5 … i = 1
  • ⭐ Sentinel-controlled = จบเมื่อเจอ sentinel | คาดเดาไม่ได้ก่อน → ไม่รู้จำนวนรอบ | ปกติใช้ while | var flag=0; while(!flag){...} → เจอเงื่อนไขตั้ง flag = 1 → หยุด

12. Nesting (สไลด์ 76)

  • control structure ซ้อนกัน ลึกเท่าไรก็ได้
  • ⭐ outer a=0..9, inner b=0..9, if(a%6!=0) continue myOuterLoop → พิมพ์แค่ a=0 และ a=6 คู่กับ b=0..9 = 20 บรรทัด (สไลด์ไม่ได้ถาม output)

13. Loop กับ Array / Object (สไลด์ 77)

  • ⭐ Array: for (var i=0; i < arr.length; i++) → Instructor1: Wudhichart / Instructor2: Wuddy / Instructor3: Wud ((i+1) ในวงเล็บ = บวกเลขก่อน)
  • ⭐ Object: for (var prop in obj) → prop = ชื่อ property | อ่านค่า obj[prop] (ไม่ใช่ obj.prop) → firstName=Wudhichart … feesPaid=true (5 บรรทัด)
