1. ECMAScript คืออะไร (สไลด์ 2–4)

  • ⭐ ES = general-purpose language | มาตรฐานโดย Ecma International | JavaScript = implementation ที่นิยมที่สุด
  • Objective: อธิบายแนวคิดแต่ละเวอร์ชัน + ระบุฟีเจอร์ของแต่ละเวอร์ชัน

2. เวอร์ชัน (สไลด์ 5–7)

  • ES1 1997 | ES2 1998 | ES3 Dec 1999 | ⭐ ES4 Abandoned | ES5 Dec 2009 | ES5.1 2011
  • ⭐ ES6 = ES2015 | ES7 = 2016 … ES13 = 2022 | ES14 = 2023 | ES15 = 2024 | ES16 = 2025 | ES17 = 2026 (ออก June ทุกปี)

3. ES6 / ES2015 (สไลด์ 8–33)

  • ลิสต์: Arrow fn, let/const, Classes (แค่ชื่อ) | Promises, Template literals, Default params, Spread, Destructuring, For-of, Map/Set, String/Object methods, Rest param
  • ⭐ Promise = eventual completion/failure ของงาน async | ตัวเชื่อม producing code (ใช้เวลา เช่นโหลด DB) ↔ consuming code (รับผลเมื่อพร้อม)
  • ⭐ State: pending (เริ่ม) → fulfilled (สำเร็จ) / rejected (ล้มเหลว) | ทั้งสองทาง return promise ใหม่ → ต่อ .then()/.catch() ได้
  • ⭐ new Promise(function(resolve, reject){ executor }) | resolve/reject = callback ที่ engine เตรียมให้
  • ⭐ ภายใน: "pending"/undefined → resolve(value) → "fulfilled"/value | reject(error) → "rejected"/error
  • ตัวอย่าง x = 5 → reject Error: No No! หลัง 1 วิ | x = 0 → resolve "finished" (⚠️ สไลด์ 16 โค้ด x = 5 แต่รูปเป็น fulfilled)
  • ⭐ Consumer: .then, .catch, .finally | .then(arg1 = สำเร็จรับ result, arg2 = rejected รับ error) | .catch = เน้น/สนใจแค่ error
  • Template literal: backtick + ${} → Hello, Wudhichart | Tagged: tag`Hello` → literals = ['Hello'] (array ของ string), substitutions = [] (array ของ expression)
  • Default param: someFunction() → index = 0, value = true
  • ⭐ Spread: [...a,4,5,6] → 1..6 | [...a] = copy (ใช้กับ object, string ได้) | [..."Hello"] → H,e,l,l,o
  • ⭐ Destructuring: [one,two]=[1,2] → 1, 2 | { firstName: name, age } → name = Wudhichart, age = 30 (ไม่มีตัวแปร firstName)
  • for-of: วน iterable → a, b, c | ⭐ ต่างจาก forEach: ใช้ break, continue, return ได้
Map WeakMap ⭐
key อะไรก็ได้ key object เท่านั้น
ไม่มี GC GC ได้ ถ้าไม่มี reference อื่น
keys()/values()/entries() ไม่มี (not enumerable)
มี size ไม่มี size
Fast Slow
ใช้: key ชนิดใดก็ได้, วนลูป, นับจำนวน ใช้: ผูกข้อมูลกับ object ที่อาจถูกทำลาย (DOM node), กัน memory leak
  • 'Hello'.repeat(3) → HelloHelloHello | Object.is() = สองค่าเป็นค่าเดียวกันไหม | ⭐ [10,30,25,48].find(n<30) → 10 | findIndex = index ตัวแรก
  • Rest param ...args = argument ไม่จำกัด สัญลักษณ์เดียวกับ spread | findMax: max เริ่ม 0

4. ES2016 (สไลด์ 34–36)

  • ⭐ includes() → boolean (includes(30) → true) vs indexOf → -1 ถ้าไม่มี | Exponentiation operator (แค่ชื่อ)

5. ES2017 (สไลด์ 37–45)

  • ⭐ "World".padStart(10) → " World" | padStart(10,"Hello") → "HelloWorld" | padEnd(10) → "World " (⚠️ สไลด์มีจุดเกิน) | padEnd(10,"Hello") → "WorldHello"
  • Object.values → ["Wudhichart","Sawangphol",true,30] | Object.entries → [["firstName","Wudhichart"], …] | ใช้กับ array ได้
  • getOwnPropertyDescriptors + defineProperties → copy property ทั้งหมดไป person2
  • Trailing commas ใน function declaration/call (ตัวอย่างสไลด์ = age: 30,)
  • ⭐ async = คืน promise เสมอ | await = รอ promise settle แล้วคืนผล
  • ⭐ สไลด์ 44: Before → After → finished | สไลด์ 45: async f(){return 2} → f().then(alert) → 2

6. ES2018 (สไลด์ 46–50)

  • Rest props: {firstName, lastName, ...otherProperties} → other = {lecturer:true, age:30} | Spread props: {firstName, lastName, ...otherProperties} → object ครบ 4
  • ⭐ forEach(async) ×2 → Start, Finished, 21=2, 22=4, 2*3=6 (forEach ไม่รอ) ⚠️ สไลด์ลืม processArray(a)
  • ⭐ for await ×3 → Start, 31=3, 32=6, 3*3=9, Finished (รอทีละรอบ) ⚠️ ป้าย "Without" ผิด

7. ES2019 (สไลด์ 51–56)

  • ⭐ flat() → ["Apple","Orange","Grape",Array(1)] | flat(2) → […,"Pineapple"] (เลข = level)
  • ⭐ map(n=>[n,n*2]) → Array(2)×6 | flatMap → [1,2,2,4,3,6,4,8,5,10,6,12]
  • Object.fromEntries(entries) → object ใหม่ (person ≠ person2) | trimStart/trimEnd = ลบช่องว่างต้น/ท้าย

8. ES2020 (สไลด์ 57–63)

  • BigInt = primitive ใหม่ ไม่จำกัดยกเว้น memory
  • ⭐ ?? default เมื่อ null/undefined: name ?? "Jidapa" → Wudhichart | null ?? "Jidapa" → Jidapa
  • ⭐ ?.: obj.prop.secondsubLevelProp.value → TypeError | obj?.prop?.secondsubLevelProp?.value → undefined | cars[3] (null) → TypeError | cars?.[3] → undefined
  • matchAll(/\b(orange)+\b/g) → 3 match ที่ index 0, 16, 31

9. ES2021 (สไลด์ 64–71)

  • 1000_000_000 → 1000000000 | replaceAll("first","last") → เปลี่ยนทั้ง 2 ตัว | WeakRef & Finalizers (แค่ชื่อ)
  • ⭐ &&= ซ้าย truthy | ||= ซ้าย falsy | ??= ซ้าย nullish
โค้ด ผล
x=1, x &&= 5 5
y=0, y &&= 5 0
x=1, x ||= 5 1
y=0, y ||= 5 5
a.age(36) ??= 20 36
a.height ??= 175 175

10. ES2022 (สไลด์ 72–76)

  • [1,2,3,4].at(2) → 3 | "1234".at(3) → 4 | Object.hasOwn({foo:false},"foo") → true
  • Error cause: throw new Error('This is error', { cause: error }) | Top-level await = await นอกฟังก์ชัน

11. ES2023 (สไลด์ 77–81)

  • ⭐ [5,10,15,20] findLast(>10) → "The last element is 20 at 3."
  • Symbol เป็น WeakMap key ได้ → get(key) → 5
  • Change by copy: toReversed(), toSorted(compareFn), toSpliced(start, deleteCount, ...items), with(index, value)

12. ES2024 (สไลด์ 82–100)

  • toWellFormed() → Unicode ถูกต้อง ลด encoding error, cross-platform (รันจริง \uD800 → �)
  • Atomics.waitSync → thread รอจนเงื่อนไขใน shared memory เป็นจริง กัน race condition (⚠️ รันจริงไม่มีฟังก์ชันนี้)
  • Top-level await → ลด boilerplate | ⚠️ สไลด์ 73 ใส่ใน ES2022 ด้วย
  • ⭐ Proposal: Pipeline |> stage 1 (-10 |> max(0,n) |> pow 2 |> ceil = 0) | Records #{} / Tuples #[] immutable (React state) | Decorators stage 2 @ (Angular, TypeScript) | Temporal Stage 3
  • Decorator 5 แบบ: class, method, accessor (getter/setter), property, parameter | ใช้เพิ่ม logging, validation, access control
  • Date ปัญหา: ใช้ยาก, มี moment.js/date-fns, มาจาก Java ที่เลิกใช้, ไม่เคยแก้ | Temporal: time zones, strict string parsing, non-Gregorian, คำนวณง่าย, ไม่ต้องใช้ library

13. ES2025 (สไลด์ 101–109)

  • JSON import: with { type: 'json' } | dynamic → cfg.default.apiUrl
  • ⭐ Iterator helpers (lazy): [1..5] filter คู่ → map ยกกำลัง → take(2) → [4, 16]
  • ⭐ Set A={1,2,3} B={3,4,5}: union {1,2,3,4,5} | intersection {3} | difference {1,2} | symmetricDifference {1,2,4,5} | isSubsetOf false | isDisjointFrom false
  • RegExp.escape() (⚠️ จริงได้ \x68ello…) | Inline modifier /a(?i:b)c/ → "aBc" match | Duplicate named groups num → "123", "abc"
  • Promise.try() → sync throw กลายเป็น rejection → Value: 42 หรือ Caught: Oops
  • Float16Array = ½ memory ของ Float32, ¼ ของ Float64 (0.1 → 0.0999755859375, π → 3.140625)

14. ES2026 (สไลด์ 110–123)

  • ⭐ Math.sumPrecise([1e16,1,-1e16]) → 1 (reduce ได้ 0) | ยังไม่รองรับทุก browser → core-js polyfill
  • ⭐ Error.isError() ข้าม realm: instanceof Error false | isError true
  • Array.fromAsync() แทน for await + push
  • getOrInsert(key, default) แทน has→set→get → visits 1
  • ⭐ JSON.rawJSON: เลข 9007199254740993 → แบบเก่าได้ …992 | rawJSON ได้ …993 | BigInt → TypeError
  • Base64/Hex: "Hello" → SGVsbG8= / 48656c6c6f | fromBase64/fromHex ถอดกลับ → true
