1. Internet & WWW (L1)

  • Internet = เครือข่ายใหญ่สุดในโลก ใช้มาตรฐาน TCP/IP เกิดจาก ARPANET (1969 node แรกที่ UCLA, 1983 DNS, 1990 ARPANET ปิดและเกิด WWW)
  • TCP แบ่งข้อมูลเป็น packet และประกอบกลับ · IP ส่ง/route packet ไปถึงปลายทาง
  • IPv4 = ###.###.###.### แต่ละช่อง 0–255
  • Port = "เลขห้อง" ของบริการ: HTTP 80 · FTP 21 · Telnet 23 · SMTP 25
  • DNS แปลงชื่อโดเมน ↔ IP · โดเมนเป็นลำดับชั้น: .com .edu .gov .org .th
  • WWW (Tim Berners-Lee) ใช้โปรโตคอล HTTP · Browser ส่ง HTTP Request → Web Server ตอบ Response
  • ส่วนประกอบ: Client (ขอ) · Server (ให้) · Network · Router/Gateway (เชื่อม 2 เครือข่าย) · Firewall (ความปลอดภัย)
http://john:secret@www.example.com:8080/demo/index.html └protocol┘└user:password┘└──domain name──┘└port┘└───path───┘

Front-end = HTML (โครงสร้าง) + CSS (หน้าตา) + JavaScript (พฤติกรรม/โต้ตอบ)

2. HTML พื้นฐาน (L1)

  • HTML = HyperText Markup Language ไฟล์ .html/.htm · Tag ไม่สนตัวพิมพ์เล็ก-ใหญ่ (แต่นิยมเขียนเล็ก)
  • Tag ซ้อนกันได้ แต่ห้ามไขว้กัน (<b><i>..</b></i> ผิด)
  • บาง tag ไม่มี tag ปิด: <br> <img> <input> · Tag ที่ browser ไม่รู้จักจะถูกข้ามเฉย ๆ ไม่ error
  • Attribute อยู่ใน tag เปิด รูปแบบ name="value" · ถ้าค่ามี " อยู่ข้างในให้ใช้ '...' ครอบ
  • Comment: <!-- ข้อความ --> · ตรวจความถูกต้องได้ที่ validator.w3.org
<!DOCTYPE html>          <!-- ต้องอยู่บรรทัดแรกเสมอ -->

  <head>
    <title>I Love HTML</title>   <!-- ชื่อบนแท็บ browser -->

  </body>
</html>

3. ตาราง (L1)

  • <table> → แถว <tr> → ช่อง <td> (ข้อมูล: ตัวปกติ ชิดซ้าย) หรือ <th> (หัวตาราง: ตัวหนา + กึ่งกลาง)
  • เนื้อหาทุกอย่างต้องอยู่ใน <td>/<th> เท่านั้น · ช่องว่าง: <td>&nbsp;</td>
  • ค่าเริ่มต้นไม่มีเส้นขอบ ต้องใส่ CSS: table, tr, th, td { border: 1px solid black; }
  • colspan="3" = ขยายช่องไปทางขวา 3 คอลัมน์ · rowspan="2" = ขยายลงล่าง 2 แถว
<table>
  <tr> <td rowspan="3"><img src="Usagi.gif" alt="Usagi"></td>
       <th colspan="3">Character: Usagi</th> </tr>
  <tr> <th>Color</th> <th>Type</th> <th>Best friends</th> </tr>
  <tr> <td>Light Pink</td> <td>Rabbit</td> <td>Piske</td> </tr>
</table>

HTML Style Guide: ใช้ <!DOCTYPE html> · ปิด tag ให้ครบ · ชื่อ tag/attribute ตัวเล็ก · ค่า attribute ใส่ double quote · เยื้องบรรทัดให้อ่านง่าย

7. CSS: Syntax & Selectors (L3)

selector {                 /* declaration block */
    property: value;       /* declaration: ปิดด้วย ; */
    background-color: red;
}                          /* comment ใน CSS ใช้ /* */ เท่านั้น */

สี: ชื่อ (red) หรือ hex (#FF0000) — red #FF0000 · green #00FF00 · blue #0000FF · magenta #FF00FF · cyan #00FFFF

Selectorตัวอย่างเลือกอะไร
Universal*ทุก element
Elementpทุก <p>
Class.clsSpทุกตัวที่ class="clsSp"

8. Specificity & Cascading Order (L3) — ออกสอบบ่อย

กฎข้อ 1 — Specificity (ความเจาะจง): ID > Class > Element · ถ้าเจาะจงเท่ากัน → กฎที่อยู่ทีหลังชนะ

กฎข้อ 2 — วิธีใส่ CSS 3 แบบ:

แบบเขียนที่ไหนตัวอย่าง
Externalไฟล์ .css แยก ลิงก์ใน <head> · 1 ไฟล์ใช้ได้หลายหน้า<link rel="stylesheet" href="myStyle.css">
Internal<style> ใน <head> · เฉพาะหน้านั้น<style> body{...} </style>
Inlineattribute style ของ tag นั้น<p style="color:white;">
Inline > Internal = External > Browser default
Internal กับ External มีลำดับความสำคัญเท่ากัน → ตัวที่ถูกประกาศทีหลังในโค้ด (อยู่ล่างกว่าใน <head>) ชนะ
แต่ต้องเทียบ specificity ก่อน: class ใน internal ชนะ element ใน external เสมอ ไม่ว่าลำดับจะเป็นยังไง

วิธีคิดเวลาเจอโจทย์: (1) ตัดกฎที่ selector ไม่ตรงทิ้ง → (2) inline ชนะทุกอย่าง → (3) เทียบ ID/class/element → (4) ถ้าเท่ากัน ดูว่าอันไหนอยู่ล่างสุด

10. Layout: Float & Flexbox (L4)

5 วิธีทำ multi-column: (1) table — ไม่แนะนำ ใช้กับข้อมูลตารางเท่านั้น (2) float (3) flexbox (4) framework เช่น Bootstrap (5) grid

Float layout (3 คอลัมน์)

nav { overflow: hidden; background-color: darkblue; }
nav a { float: right; display: block; padding: 14px 16px; }
.column { float: left; width: 33.33%; }
.row::after { content: ""; display: table; clear: both; }   /* clear float หลังแถว */

Flexbox — ตั้งที่ container (แม่) แล้วมีผลกับลูกโดยตรง

.container {
    display: flex;
    flex-direction: row;            /* row | row-reverse | column | column-reverse */
    flex-wrap: wrap;                /* nowrap | wrap | wrap-reverse */
    justify-content: space-evenly;  /* แกนหลัก: flex-start | flex-end | center |
                                       space-between | space-around | space-evenly */
    align-items: center;            /* แกนขวาง: flex-start | flex-end | center */
}
justify-contentภาพ (3 กล่อง)
flex-start[■■■ ]
flex-end[ ■■■]
center[ ■■■ ]
space-between[■ ■ ■] ชิดขอบสุดสองข้าง
space-around[ ■ ■ ■ ] ขอบได้ครึ่งหนึ่งของช่องระหว่างกล่อง
space-evenly[ ■ ■ ■ ] ทุกช่องเท่ากันหมด

ถ้า flex-direction: row → justify-content = แนวนอน, align-items = แนวตั้ง (ถ้าเป็น column จะสลับกัน) · ตัวอย่างสไลด์: nav ใช้ justify-content: flex-end ให้เมนูชิดขวา — "No more float and clear"

Grid (ในตัวอย่าง Tic Tac Toe): display: grid; grid-template-columns: repeat(3, auto); → ตาราง 3 คอลัมน์

11. Responsive Web Design + Media Query (L4)

  • RWD = หน้าเว็บแสดงผลดีทุกขนาดจอ ใช้แค่ HTML + CSS (Media Query)
  • Mobile first = ออกแบบสำหรับมือถือก่อน แล้วค่อยใช้ min-width ขยายสำหรับจอใหญ่ (สวนทางกับแบบดั้งเดิม)
  • ต้องมี viewport meta ใน <head>: <meta name="viewport" content="width=device-width, initial-scale=1.0"> (width ตามจออุปกรณ์, initial-scale = zoom ตอนโหลด)
div { font-size: 4em; }                              /* ค่าเริ่มต้น */
@media screen and (max-width: 768px) {               /* จอ ≤ 768px */
    div { font-size: 2em; }
}
@media screen and (min-width: 1000px) {              /* จอ ≥ 1000px */
    div { font-size: 8em; }
}
/* จอ 769–999px → ไม่เข้าเงื่อนไขไหน → ใช้ 4em */
max-width: 768px = "ไม่เกิน 768" (จอเล็ก) · min-width: 1000px = "อย่างน้อย 1000" (จอใหญ่) · ถ้าหลายเงื่อนไขตรงพร้อมกัน ตัวที่อยู่ล่างสุดชนะ
/* Mobile first ตามสไลด์ */
nav, .container { display: flex; flex-direction: column; }  /* มือถือ: เรียงแนวตั้ง */
@media screen and (min-width: 600px) {
    nav { flex-direction: row-reverse; justify-content: flex-start; }
    .container { flex-direction: row; }                      /* จอใหญ่: เรียงแนวนอน */
}

ทดสอบได้ใน Developer Tools ของ browser (โหมดอุปกรณ์)

12. Bootstrap (L4)

  1. HTML5 template + <meta charset> + viewport (BS ต้องการ HTML5 doctype)
  2. ใส่ CSS (<link>) และ JS (<script>) ของ Bootstrap จาก CDN
  3. จัด layout ด้วย grid: container → row → col → content
  4. ใส่ class / component (card, navbar, modal, carousel, accordion ฯลฯ)
  • .container = มี max-width ตาม breakpoint · .container-fluid = กว้าง 100% ทุกขนาด · .container-{bp} = 100% จนถึง breakpoint นั้น
  • Grid สร้างจาก flexbox · 1 แถว = 12 หน่วย (ผลรวม col ≤ 12) · มี 6 breakpoints
  • col-sm-6 = กว้าง 6/12 เมื่อจอ ≥ sm (576px) · ถ้าจอ < 576px คอลัมน์จะซ้อนลงมาเป็นแนวตั้ง
<main class="container">
  <section class="row">
    <div class="col-sm-8">8 หน่วย</div>
    <div class="col-sm-4">4 หน่วย</div>      <!-- 8+4 = 12 -->
  </section>
</main>

18. Scope, Lifetime & Closure (L7)

  • Global = ประกาศนอกฟังก์ชัน ใช้ได้ทั้งหน้า (ทุก <script> ปกติ) อยู่จนปิดหน้าเว็บ

  • ชื่อ global กับ local ซ้ำกัน → ในฟังก์ชันใช้ตัว local
  • ตัวแปรควรมี scope เล็กที่สุดเท่าที่ทำได้

23. กับดักที่มักพลาด

  1. <!DOCTYPE html> ต้องอยู่ก่อน <html> · <title> อยู่ใน <head>
  2. <br> <img> <input> ไม่มี tag ปิด
  3. <th> ตัวหนาและกึ่งกลางเอง · ตารางไม่มีเส้นขอบถ้าไม่ใส่ CSS
  4. colspan = ขยายแนวนอน (หลายคอลัมน์) · rowspan = ขยายแนวตั้ง (หลายแถว)
  5. radio/checkbox กลุ่มเดียวกันต้อง name เหมือนกัน · label ผูกกับ input ด้วย for = id
  6. GET โชว์ข้อมูลใน URL · POST ไม่โชว์
  7. ใน CSS ใช้ . กับ class และ # กับ id · แต่ใน getElementById("x") / getElementsByClassName("x") ไม่ต้องใส่ · ส่วน querySelector ต้องใส่
  8. Inline > Internal = External (ตัวหลังชนะ) · แต่ ID > class > element มาก่อนลำดับ
  9. Flexbox ตั้ง display:flex ที่แม่ ไม่ใช่ที่ลูก
  10. max-width = จอเล็กกว่าค่านี้ · min-width = จอใหญ่กว่าค่านี้
  11. Bootstrap: 1 row = 12 หน่วย · container → row → col
  12. == แปลงชนิด · === ไม่แปลง · "5" + 3 = "53"
  13. input.value เป็น string → ต้อง parseFloat ก่อนบวก ไม่งั้นได้ "12" แทน 3
  14. const เปลี่ยนค่าไม่ได้ · let ประกาศซ้ำไม่ได้ · var ทะลุ block
  15. switch ลืม break → ไหลไป case ถัดไป · do-while ทำอย่างน้อย 1 รอบ
  16. substring(3,10) ไม่รวม index 10 · getDay() = วันในสัปดาห์ (0 = อาทิตย์) ไม่ใช่วันที่
  17. subclass ต้องเรียก super() · สร้าง object ต้องใช้ new
