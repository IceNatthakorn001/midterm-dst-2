💡 Programmed: CPU วนเช็ก status เอง · Interrupt-driven: CPU ไปทำอย่างอื่น แต่ยังย้ายข้อมูลเองทุก word · DMA: CPU สั่งครั้งเดียวทั้ง block แล้วรอ interrupt ตอนจบ — เหมาะกับข้อมูลปริมาณมาก
