Objectives & CLOs

เป้าหมาย: ศึกษาบทบาทของสถาปัตยกรรมต่อ performance ด้วย quantitative approach ไม่ใช่วิชา: hardware design / รายละเอียด semiconductor

CLO เนื้อหา Objectives
1 องค์ประกอบคอมพิวเตอร์ดิจิทัล, instruction execution, ISA formats, addressing modes, pipelining, parallelism 1–2
2 ประเมิน performance metrics, memory hierarchy, I/O organisation 3–5
3 process management, concurrency, synchronisation, deadlocks (OS) 6–8
4 memory management, file systems (OS) 9–10

Objectives 10 ข้อ: เข้าใจองค์ประกอบ+pipelining+parallelism / อธิบาย instruction execution, ISA, addressing mode / ประเมิน performance metrics / อธิบาย memory hierarchy / อธิบาย I/O / อธิบาย process management / เข้าใจ concurrency & synchronisation / วิเคราะห์ deadlocks / เข้าใจ memory management / อธิบาย file systems

ลำดับเรียนรู้: Architecture basics → performance/hardware → OS process → OS storage
