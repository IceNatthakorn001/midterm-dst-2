Course Objectives

  • ⭐ ศึกษาบทบาทของ architecture ต่อ performance ของระบบ/โปรแกรม: อะไรกระทบ performance, key components, processor สมรรถนะสูงวันนี้, emerging trends, quantitative approach
  • ไม่สอน: hardware design, รายละเอียด semiconductor technology
  • 10 ข้อ: (1) organisation, pipelining, parallelism (2) instruction execution, ISA format, addressing mode (3) performance metrics (4) memory hierarchy (5) I/O organisation (6) process management (7) concurrency & synchronisation (8) deadlocks (9) memory management (10) file systems
