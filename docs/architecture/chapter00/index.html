2. Course Description (สไลด์ 3)

สไลด์ให้คำอธิบายรายวิชาทั้งภาษาอังกฤษและไทย ครอบคลุมทั้งส่วน Computer Architecture และ Operating System

ภาษาอังกฤษ (ตามสไลด์): The structure and architecture of the computer systems; basic components of computers; data representations; the Assembly Language; memory system organization; the memory hierarchy; the cache memory; input and output systems; storage systems; computing units; the multiprocessor architecture; basic principles of operating systems; the computer resource management; the process management and scheduling; synchronization; deadlocks; memory management: segmentation and paging; the virtual memory; protection; sharing; the access control; file and I/O systems

ภาษาไทย (ตามสไลด์): โครงสร้างและสถาปัตยกรรมของระบบคอมพิวเตอร์ ส่วนประกอบพื้นฐานของเครื่องคอมพิวเตอร์ การแทนข้อมูล ภาษาแอสเซมบลี โครงสร้างระบบหน่วยความจำและการจัดลำดับชั้น หน่วยความจำแคช ระบบการรับเข้าและส่งออกข้อมูล ระบบการเก็บข้อมูล สถาปัตยกรรมของหน่วยประมวลผลแบบหลายหน่วย หลักการพื้นฐานของระบบปฏิบัติการ การจัดการหน่วยประมวลผลงานและการจัดลำดับงาน การประสานเวลา การติดตาย การจัดการหน่วยความจำ การป้องกันและการใช้ร่วมกัน ระบบแฟ้มข้อมูล ระบบข้อมูลเข้า-ออก

แบ่งหัวข้อในคำอธิบายเป็น 2 กลุ่มให้เห็นภาพ:

Operating System basic principles of OS, resource management, process management & scheduling, synchronization, deadlocks, memory management (segmentation & paging), virtual memory, protection, sharing, access control, file and I/O systems

5. Course Objectives (สไลด์ 6–7)

5.1 เป้าหมายของฝั่ง Computer Architecture (สไลด์ 6)

หลักใหญ่: ศึกษาบทบาทของ computer architecture ต่อ ประสิทธิภาพ (performance) ของระบบและโปรแกรม โดยตั้งคำถามว่า

  • ส่วนไหนของการออกแบบ architecture ที่ส่งผลต่อ performance ของแอปพลิเคชัน
  • องค์ประกอบหลัก (key components) ของ CA มีอะไรบ้าง
  • architecture ของ processor สมรรถนะสูงในปัจจุบันเป็นอย่างไร
  • แนวโน้มใหม่ (emerging trends) ของ CA คืออะไร
  • ใช้แนวทางเชิงปริมาณ (quantitative approach) กับ CA

สิ่งที่วิชานี้ "ไม่ได้" สอน:

  • Hardware design (การออกแบบฮาร์ดแวร์)
  • รายละเอียดของ semiconductor technology

💡 วิชานี้มองคอมพิวเตอร์ในมุม "ออกแบบอย่างไรให้เร็ว" ไม่ได้ลงไปถึงการออกแบบวงจรหรือเทคโนโลยีชิป

5.2 Objectives 10 ข้อ (สไลด์ 7)

เมื่อจบวิชา นักศึกษาควรจะ:

  1. เข้าใจการจัดองค์กรพื้นฐานของ digital computer, pipelining และ parallelism
  2. อธิบาย instruction execution, ISA format และ addressing mode ได้
  3. ประเมิน performance metrics ได้
  4. อธิบาย memory hierarchy ได้
  5. อธิบาย I/O organisation ได้
  6. อธิบาย process management ได้
  7. เข้าใจ concurrency และ synchronisation
  8. วิเคราะห์ deadlocks ได้
  9. เข้าใจ memory management
  10. อธิบาย file systems ได้

💡 ข้อ 1–5 เป็นฝั่ง Architecture ส่วนข้อ 6–10 เป็นฝั่ง OS

6. Course Learning Outcomes — CLOs (สไลด์ 8)

CLO เนื้อหา (ตามสไลด์) มาจาก Objectives กลุ่ม
CLO 1 อธิบาย basic organisation ของ digital computer รวมถึง instruction execution, ISA formats, addressing modes, pipelining, parallelism 1, 2 Architecture fundamentals
CLO 2 ประเมิน computer performance metrics และอธิบาย memory hierarchy กับ I/O organisation 3, 4, 5 Performance & hardware resources
CLO 3 อธิบาย process management, concurrency, synchronisation และวิเคราะห์ deadlocks ใน OS 6, 7, 8 OS process/concurrency topics
CLO 4 เข้าใจ memory management และ file systems ใน OS 9, 10 OS storage management

ลำดับที่สไลด์สรุปไว้: Architecture basics → performance/hardware → OS process handling → OS storage handling
