Architecture review

  • Components: Hardware (CPU, memory, I/O) → OS (ควบคุม/ประสาน hardware ระหว่างโปรแกรมและผู้ใช้) → Application programs → Users
  • CPU (registers, ALU, control unit) + memory (RAM) + I/O controllers → I/O devices
  • Fetch → Decode → Execute วนจนจบโปรแกรม

⭐ OS

  • เป้าหมาย: ระบบ ถูกต้อง มีประสิทธิภาพ ใช้ง่าย (หลายโปรแกรมพร้อมกัน, แชร์ memory, คุม I/O)
  • OS เป็น software มี 3 บทบาท: | บทบาท | สรุป | |---|---| | 1. Virtualization | ทรัพยากรจำกัด → ดูเหมือนไม่จำกัด; OS = virtual / extended machine | | 2. APIs (standard library) | system calls ให้โปรแกรมขอบริการ (รันโปรแกรม, ไฟล์, memory); ซ่อนความซับซ้อน hardware | | 3. Resource manager | แบ่ง CPU time, memory, disk/I/O → efficiency + fairness |
  • Virtualize CPU: สลับ process อย่างไร? ใครได้ก่อน? | Virtualize memory: แต่ละโปรแกรมมี address space (เริ่ม 0x00000) — map virtual → physical อย่างไร? จัดสรรอย่างไร? memory ไม่พอทำอย่างไร?
  • OS เป็น interface: application ↔ beautiful interface ↔ OS ↔ ugly interface ↔ hardware
  • ⭐ Design goals: Abstraction (ใช้ง่าย), Performance (overhead ต่ำ), Protection (แยก process), อื่น ๆ: energy, security, mobility

⭐ History 5 ยุค

ยุค จุดเด่น
1. Human OS mainframe, operator (คน) ทำทีละ job, เสียเวลาเดินในห้อง
2. Batch OS แรก = automatic job sequencing, รวม jobs คล้ายกันลด setup, FORTRAN/Assembly; cards → 1401 → tape → 7094 คำนวณ → 1401 พิมพ์
3. Multiprogramming hardware ถูก คนแพง, หลาย jobs ใน memory สลับเร็ว → CPU utilization (IBM System/360) + Spooling
4. Personal Computer hardware ถูกมาก; multitasking (หลายโปรแกรม), multiprocessing (หลาย CPU), GUI
5. Mobile energy efficiency, UI ใหม่, wireless; mobile OS ใช้มากสุดตั้งแต่ 2017
  • Spooling = Simultaneous Peripheral Operation On Line — I/O ของ job หนึ่งซ้อนการคำนวณอีก job; อ่าน job ถัดไปลง disk (job queue) + พิมพ์ job ก่อนหน้าจาก disk
  • Job pool: ให้ OS เลือก job ถัดไปเพิ่ม CPU utilization
  • Migration: ฟีเจอร์จาก mainframe (MULTICS, time shared, multiuser) ย้ายลง minicomputer → microcomputer (UNIX) → network computers
  • OS Zoo: mainframe OS/360 | server UNIX (Linux, FreeBSD, AIX), Windows 2012 R2 | PC Windows, Mac OS, Linux | real-time VxWorks, QNX | mobile Android, iOS
