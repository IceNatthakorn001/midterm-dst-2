1. Environment variables (สไลด์ 4)

  • ⭐ USER, HOME, SHELL, LOGNAME, PATH (ค้น dir ตามลำดับ ใช้ executable ตัวแรกที่เจอ), LANG, TERM

2. Shell vs Environment variable (สไลด์ 5–10)

  • echo LOGNAME → LOGNAME | echo $LOGNAME → ค่า (ต้องมี $)
  • ⭐ shell var อยู่แค่ shell ที่สร้าง | env var inherit ไป child, shell var ไม่ | export = ทำเป็น env var | built-in สำหรับ create/assign/delete
  • ⭐ shell เริ่ม → env ทั้งหมด copy เป็น shell var ชื่อเดียวกัน; แก้/unset shell var ไม่กระทบ env (สไลด์ 8: LOGNAME=bob → echo ได้ bob แต่ /proc/$$/environ ยัง LOGNAME=seed)
  • foo=bar; echo $foo → bar; unset foo; echo $foo → ว่าง
  • ps -f: ls/more/ps มี PPID 2011 = ลูกของ bash
  • child ได้: shell vars copied from env + user-defined exported | ไม่ได้: not exported, predefined (BASHPID)

3. Shell (สไลด์ 11–12)

  • Kernel (hardware, scheduler, memory) ← Shell (CLI) ← Application | Shell script = รวมคำสั่ง shell
shell จุดเด่น prompt
⭐ sh (Bourne) ยุคแรก, standard ใน UNIX ทุกตัว, ย้าย script ได้ไม่ต้องแก้ $
csh ไวยากรณ์เหมือน C, เรียกคำสั่งเก่าได้ ⭐ %
ksh รวมข้อดี sh + csh, ไม่มีทุก UNIX $
⭐ bash Bourne ใหม่, line editing, ไม่ใช่ standard UNIX แต่ default ของ Linux $

4. 17 ขั้น (สไลด์ 13)

สร้างไฟล์ | shebang | ใส่คำสั่ง | chmod | รัน | สร้างตัวแปร | เรียกใช้ตัวแปร | env var | ตัวแปรพิเศษ | comment | array | expression | if | case | while | for | input argument

5. ทำให้ script รันได้ (สไลด์ 14–17)

  • ⭐ nano hello.sh → #!/bin/bash (หรือ sh/csh/ksh) → echo "Hello World!" → chmod 700 test.sh (-rw-rw-r-- → -rwx------) → ./test.sh → Hello World!

6. ตัวแปร + quote (สไลด์ 18–20)

  • ⭐ variable=value ห้าม space รอบ = | ค่ามี space ใช้ ' หรือ "
  • ⭐ '...' = ตามที่พิมพ์ | "..." = แทนค่า → var5='$var1 $var2' → $var1 $var2 | var6="$var1 $var2" → shell script
  • ผลทั้งหมด: shell / script / shell script / shell script / $var1 $var2 / shell script

7. ตัวแปรพิเศษ (สไลด์ 21)

  • ⭐ $0 ชื่อ script, $1 $2… argument (position parameter) | $# จำนวน arg | $* arg ทั้งหมด | $@ คล้าย $* คั่นด้วยช่องว่าง | $? = 0 สำเร็จ, ≠0 ผิดพลาด | $! PID (สไลด์ 21: ของ shell; สไลด์ 48: ใช้กับงาน &)

8. Env var ใน script (สไลด์ 22)

  • echo $NAME → ว่าง (null) | export NAME=dst แล้วรัน → dst

9–10. Comment, Array (สไลด์ 23–24)

  • # = comment (บรรทัดแรก #! = shebang) → output hello
  • ⭐ index เริ่ม 0 | echo $txt[0] $txt[1] $txt[2] → a[0] a[1] a[2] | ${txt[0]}… → a b c

11. Expression (สไลด์ 25–26)

ประเภท ตัวดำเนินการ
⭐ int -eq = · -ne ≠ · -gt > · -ge ≥ · -lt < · -le ≤
⭐ string = · != · str ไม่ว่าง · -n ยาว>0 · -z ยาว=0
⭐ file -d dir · -f file · -r อ่านได้ · -w เขียนได้ · -x run ได้ · -s ขนาด≠0
อื่น !expr not · -a and · -o or

12–16. if / case / while / for / argument (สไลด์ 27–31)

  • ⭐ if [ ] then … elif [ ] then … else … fi → cat = cat → Yes, it is equal
  • ⭐ case $x in a) …;; *) …;; esac → It is a cat
  • while [ $num -le 10 ] … ((num=$num+1)) → Loop 1–10 (วนจนเงื่อนไขเท็จ)
  • for i in 1 2 3 4 5 → Loop 1–5 | ⭐ for ((i=1;i<5;i++)) → Loop 1–4 (สไลด์โชว์ 1–5 เป็นของแบบแรก)
  • echo "$1 & $2": ./test.sh a b → a & b | ./test.sh "a c d" b → a c d & b
