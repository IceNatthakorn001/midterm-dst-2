Virtual Memory: แปล address ผ่าน TLB และ Page table

Chapter 04 — Virtual Memory · main memory ทำหน้าที่เป็น "cache" ของ disk · block = page, miss = page fault

Virtual address = virtual page number (VPN) + page offset · page 4 KB → offset 12 bit (= hex 3 หลักขวา) · แปลเฉพาะ VPN → physical page number (PPN) ส่วน offset ใช้เหมือนเดิม
TLB = cache ของ page table entry (16–512 entries, hit 0.5–1 cycle, miss 10–100 cycles)
