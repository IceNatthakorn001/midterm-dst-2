Magnetic Disk

  • Platter = substrate (ไม่เป็นแม่เหล็ก) เคลือบสารแม่เหล็ก | เดิม aluminium → ปัจจุบัน glass
  • Glass ดีกว่า: ผิวสม่ำเสมอ, defect น้อย, fly height ต่ำได้, แข็งกว่า, ทนแรงกระแทก
  • ทิศทางอนุภาคแม่เหล็กแทน 0/1 | เขียน: กระแส → สนามแม่เหล็ก → จัดทิศ | อ่าน: ทิศแม่เหล็ก → เหนี่ยวนำไฟฟ้า → bit
  • หัว: inductive write + MR (magnetoresistive) read
  • Layout: platter, spindle, 1 หัวต่อ surface บน boom, track (inter-track gap), sector (inter-sector gap), cylinder
⭐ CAV Multiple zone
sector/track เท่ากัน วงนอกมากกว่า
ความหนาแน่น ไม่สม่ำเสมอ (วงในแน่น) ใกล้เคียงทุกโซน
ความจุ ต่ำกว่า สูงกว่า
ระบบ ง่าย ซับซ้อน (หลาย data rate)
ปัจจุบัน พบน้อย HDD ส่วนใหญ่
  • ST506: 30 sectors × 600 bytes = gap1 17 + ID 7 + gap2 41 + data 515 + gap3 20 | ID = synch, track(2), head, sector, CRC(2) | data = synch + 512 + CRC(2)

ลักษณะ disk
Head motion fixed (1/track) / movable (1/surface)
Portability nonremovable / removable (floppy, ZIP)
Sides single / double
Platters single / multiple
Head mechanism contact (floppy) / fixed gap / aerodynamic gap (Winchester)
  • หัวแคบ → track แคบ → หนาแน่นสูง แต่ต้องใกล้จาน → เสี่ยง error
  • Winchester: sealed drive, ใกล้ผิวกว่า, aerodynamic foil วางบนจานตอนหยุด ลอยขึ้นด้วยแรงอากาศตอนหมุน

⭐ Disk performance

  • Timing: wait for device → wait for channel → seek → rotational delay → data transfer (device busy = ตั้งแต่ wait channel)
  • Seek = เลื่อนหัวไป track | Rotational delay = รอ sector หมุนมา | Access time = seek + rotational | Transfer time แยก
  • HDD ตัวอย่าง: Enterprise 6 TB 7200 rpm seek 4.16 ms 216 MB/s cache 128 MB | Barracuda XT 3 TB | Cheetah NS 600 GB 10,075 rpm | Laptop 2 TB 5400 rpm seek 13 ms

⭐ RAID (Redundant Array of Independent Disks)

  • 7 ระดับ ไม่ใช่ลำดับชั้น | ร่วมกัน 3 ข้อ: OS เห็นเป็น logical drive เดียว, striping, parity กู้ข้อมูล
Level วิธี Disks จุดเด่น จุดด้อย ใช้กับ
0 striping ไม่มี redundancy N I/O เร็วมาก, ง่าย เสีย 1 ตัว หายหมด video/image editing, bandwidth สูง
1 mirror 2N ไม่ต้อง rebuild, ไม่มี write penalty, อ่านได้ 2 ตัว overhead 100% (แพง) accounting, payroll, financial
2 bit striping + Hamming (parallel, sync spindles) N+m (m ∝ log N) transfer สูงสุด ECC disks เยอะ ไม่มีใช้เชิงพาณิชย์
3 byte/bit striping + parity disk เดียว N+1 transfer สูงมาก, reduced mode transaction-oriented แย่ video streaming, throughput สูง
4 block striping + parity disk เดียว (independent) N+1 read transaction สูง parity disk คอขวด, write = 2 reads + 2 writes ไม่มีใช้เชิงพาณิชย์
5 block + parity หมุนเวียน (round-robin) N+1 read transaction สูงสุด, แก้คอขวด RAID 4 controller ซับซ้อน file/DB/web servers — หลากหลายที่สุด
6 block + parity 2 ชุด (P, Q) N+2 availability สูงสุด — ต้องเสีย 3 ตัวใน MTTR ถึงหาย write penalty มาก mission critical
  • RAID 0 mapping: disk 0 = strip 0, 4, 8, 12 … (array management software)
  • RAID 0 สำหรับ I/O rate สูง: กระจาย load, strip ใหญ่ → request ขนานกัน ลด queuing

⭐ SSD

  • ข้อดีเทียบ HDD: IOPS สูง, ทนทาน, อายุยาว, ประหยัดไฟ, เงียบเย็น, latency ต่ำ | | NAND SSD | Laptop HDD | |---|---|---| | speed | 200–550 Mbps | 50–120 Mbps | | power | 2–3 W | 6–7 W | | ความจุ | ≤512 GB notebook, 1 TB desktop | ~500 GB–2 TB, 4 TB desktop | | ราคา | ~$0.50/GB | ~$0.15/GB |
  • Architecture: host (OS → file system → I/O driver → interface) → SSD (interface → controller: addressing, data buffer/cache, error correction → flash components)
  • Practical issues: (1) ช้าลงเมื่อใช้นาน — อ่านทั้ง block ไป RAM → erase ทั้ง block → เขียนกลับ (2) flash สึกหลังเขียนหลายครั้ง → cache รวม write, wear-leveling, bad-block management, ประเมินอายุตัวเอง

⭐ Optical

ความหมาย
CD เสียง, 12 cm, > 60 นาที
CD-ROM ข้อมูล, > 650 MB (682 MB ในภาพ)
CD-R เขียนครั้งเดียว (dye layer)
CD-RW เขียนซ้ำ (phase change: amorphous สะท้อนแย่ ↔ crystalline สะท้อนดี; วัสดุเสื่อมในที่สุด)
DVD 8/12 cm, double-sided ถึง 17 GB
DVD-R / RW เขียนครั้งเดียว / ซ้ำ, ด้านเดียว
Blu-ray 405 nm, 25 GB ต่อ layer ต่อด้าน
  • ผลิต CD-ROM: polycarbonate → pits ด้วยเลเซอร์ (master) → die ปั๊ม → เคลือบ aluminum/gold → acrylic → label
  • CD-ROM block 2352 bytes: SYNC 12 + ID 4 + data 2048 + L-ECC 288
  • CD-ROM: ข้อดี ผลิตซ้ำถูก, ถอดได้ (archive) | ข้อเสีย อ่านอย่างเดียว, access ช้ากว่า disk
  • Laser: CD 780 nm / DVD 650 nm / Blu-ray 405 nm | beam spot 2.11 / 1.32 / 0.58 µm
  • DVD double-sided dual-layer อ่านทีละชั้นทีละด้าน ต้องกลับ disk

Magnetic Tape

  • polyester tape เคลือบแม่เหล็ก, parallel tracks, serial recording, physical records คั่นด้วย inter-record gaps
  • Serpentine: อ่านกลับทิศทีละ track
  • LTO-1 (2000) 200 GB 40 MB/s → LTO-5 (2010) 3.2 TB → LTO-8 32 TB 1.18 GB/s | WORM ตั้งแต่ LTO-3, encryption ตั้งแต่ LTO-4, partitioning ตั้งแต่ LTO-5

คู่ที่มักสับสน

ข้อ จำให้ถูก
Access time seek + rotational (ไม่รวม transfer)
RAID 3 vs 4 byte/bit + parallel vs block + independent
RAID 4 vs 5 parity disk เดียว (คอขวด) vs หมุนเวียน
RAID 5 vs 6 1 ชุด (N+1) vs 2 ชุด P,Q (N+2)
RAID 1 ไม่มี write penalty แต่ overhead 100%
ไม่มีใช้เชิงพาณิชย์ RAID 2 และ 4
