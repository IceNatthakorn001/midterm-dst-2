1. Single-cycle vs Pipelined

คำสั่ง ld 3 คำสั่ง แต่ละขั้นใช้เวลา: IF 200 · Reg read 100 · ALU 200 · MEM 200 · Reg write 100 ps (ตารางในสไลด์)
Single-cycle: clock ต้องยาวเท่าคำสั่งที่ช้าที่สุด = 800 ps · Pipelined: clock = ขั้นที่ช้าที่สุด = 200 ps

2. Pipeline diagram + Hazards

IFID EXMEM WB stall (ค้างอยู่ขั้นเดิม) bubble / nop A / B ในกล่อง EX = ค่า mux ForwardA / ForwardB (00 register, 10 EX/MEM, 01 MEM/WB)

3. สรุปกฎที่ต้องจำ

สถานการณ์ไม่มี forwardingมี forwarding
ALU → ALU ติดกัน (add x19 → sub ..x19..)bubble 2 รอบ (รอ WB; เขียนครึ่งแรก อ่านครึ่งหลังของ cycle)ไม่ต้อง stall — forward จาก EX/MEM (mux = 10)
ห่างกัน 1 คำสั่งbubble 1 รอบforward จาก MEM/WB (mux = 01)
Load-use (ld x1 → ใช้ x1 ทันที)bubble 2 รอบยัง stall 1 รอบ แล้ว forward ("can't forward backward in time")
Branch takenตัดสินใน MEM → flush 3 คำสั่ง · ย้ายไปตัดสินใน ID → flush 1 คำสั่ง (IF.Flush)

💡 Forward เฉพาะเมื่อ RegWrite = 1 และ Rd ≠ x0 · ถ้าทั้ง EX/MEM และ MEM/WB เขียน register เดียวกัน (double data hazard) ให้ใช้ค่าใหม่สุด คือจาก EX/MEM
Load-use ตรวจในขั้น ID: ID/EX.MemRead and (ID/EX.Rd = IF/ID.Rs1 or ID/EX.Rd = IF/ID.Rs2) → control ใน ID/EX = 0 และไม่อัปเดต PC กับ IF/ID
