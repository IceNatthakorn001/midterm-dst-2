1. Process states

⚠️ Blocked → Ready เมื่อ I/O เสร็จ (ไม่ได้กลับไป Running ทันที ต้องรอ scheduler เลือกอีกครั้ง)

2. Context switch (timer interrupt)

OS ได้ CPU คืนเมื่อ process yield, ถูก block, รอ child, จบ — แต่ถ้า process วนลูปไม่รู้จบ? → timer interrupt ทุกไม่กี่ ms (สไลด์ 39–41)

โหมด CPU: user mode

💡 save registers 2 ครั้ง: hardware save ลง kernel stack ตอน interrupt · OS save ลง proc_t (PCB) ตอนเรียก switch()

3. fork() / wait()

โค้ดตัวอย่างสไลด์ 23 · child เริ่มเป็นสำเนาของ parent ทุกอย่าง (มี address space + PCB ของตัวเอง) · fork() คืน PID ของ child ให้ parent และ 0 ให้ child

4. System call: read() กับ trap

user mode ทำ privileged operation เองไม่ได้ → เรียก system call ซึ่งใช้ trap สลับเข้า kernel mode (สไลด์ 33–36)
