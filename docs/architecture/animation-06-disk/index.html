1. การอ่าน 1 sector

💡 Access time = seek + rotational delay (ยังไม่รวม transfer) · ลำดับเต็ม: wait for device → wait for channel → seek → rotational delay → data transfer (device busy นับตั้งแต่ wait for channel)

2. คำนวณเวลาอ่าน 1 sector (ตัวอย่าง Chapter 04)

ค่าในสไลด์: 4 + ½ / (15000/60) + 512B / 100MB/s + 0.2 = 4 + 2 + 0.005 + 0.2 = 6.2 ms · ถ้า seek จริงแค่ 1 ms (ค่า seek ของผู้ผลิตคิดจากทุกแบบที่เป็นไปได้ ของจริงมักน้อยกว่า) → 3.2 ms · rotational delay เฉลี่ย = รอครึ่งรอบ

3. CAV vs Multiple zone recording

CAV (constant angular velocity)

ทุก track มี sector เท่ากัน → วงในอัดแน่น วงนอกห่าง (ความหนาแน่นไม่สม่ำเสมอ) · ระบบง่าย แต่ความจุต่ำกว่า

Multiple zone recording

แบ่งเป็นโซน วงนอกมี sector มากกว่า → ความหนาแน่นใกล้เคียงกันทุกโซน ความจุสูงกว่า แต่ซับซ้อน (หลาย data rate) · HDD ปัจจุบันส่วนใหญ่ใช้แบบนี้
