3. Hardware multithreading — การใช้ issue slots




processor ออกคำสั่งได้ 4 ช่องต่อ cycle (issue slots) · thread A–D มีช่วงที่ stall (แถวว่าง) · รูปแบบของแต่ละ thread อ่านจากรูปในสไลด์ 17












แบบสลับ thread เมื่อข้อสังเกต


Coarse-grainstall นาน (เช่น L2 miss)hardware ง่าย แต่ซ่อน stall สั้นไม่ได้


Fine-grainทุก cyclethread หนึ่ง stall ตัวอื่นทำต่อได้ทันที


SMTหลาย thread ออกคำสั่งใน cycle เดียวกันใช้กับ multiple-issue · Pentium-4 HT: 2 threads, registers ซ้ำ, FU/cache ใช้ร่วม


แผนภาพผลลัพธ์จำลองจากกฎง่าย ๆ (coarse: สลับเมื่อเจอ stall เสีย 1 cycle · fine: วนทีละ thread ข้ามตัวที่ stall · SMT: เติมช่องว่างจากหลาย thread) จึงอาจไม่ตรงกับรูปในสไลด์ทุกช่อง





4. Sum reduction บน shared memory (UMA)




บวกเลข 64,000 ตัว ด้วย 64 processors: ขั้นแรกแต่ละตัวบวกส่วนของตัวเอง 1,000 ตัว แล้ว reduce แบบ divide and conquer ครึ่งละครึ่ง ต้อง synch() ทุกขั้น


half = 64;
do
    synch();
    if (half%2 != 0 && Pn == 0)
        sum[0] += sum[half-1];   /* half คี่: P0 บวกตัวที่เหลือ */
    half = half/2;               /* dividing line on who sums */
    if (Pn < half) sum[Pn] += sum[Pn+half];
while (half > 1);










ตัวเลขในช่อง = ผลรวมครอบคลุมกี่ตัวแล้ว (k = 1,000)
