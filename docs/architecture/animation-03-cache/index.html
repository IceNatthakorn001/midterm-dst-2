Cache: แบ่ง address · Direct mapped · Associativity

Chapter 04 — Memory Hierarchy & Cache · ใส่ address หรือลำดับการอ้างอิงเองได้

  • 1. แบ่ง address
  • 2. Direct mapped ทีละครั้ง
  • 3. Direct vs 2-way vs Fully

1. แบ่ง address เป็น tag | index | offset

💡 ตัวอย่างสไลด์: 64 blocks × 16 B, address 1200 → block address = ⌊1200 / 16⌋ = 75 → index = 75 mod 64 = 11 · offset 4 bit, index 6 bit, tag 22 bit

2. Direct mapped cache ทีละการอ้างอิง

index = block address mod จำนวน block (= bit ต่ำ) · tag = bit ที่เหลือด้านบน · valid bit เริ่มต้นเป็น 0

3. เทียบ Direct mapped · 2-way set associative · Fully associative

💡 ตัวอย่างสไลด์ (4 blocks, 0, 8, 0, 6, 8): direct 5 miss · 2-way 4 miss 1 hit · fully 3 miss 2 hit · แทนที่แบบ LRU (ตัวที่ไม่ได้ใช้นานที่สุดออก)
associativity สูง → conflict miss ลด แต่ต้องมี comparator มากขึ้น (direct 1 ตัว, n-way n ตัว, fully = ทุก entry)
