I/O Module

  • I/O module อยู่ระหว่าง system bus (address/data/control lines) กับ peripheral devices
  • External devices 3 แบบ: human readable, machine readable, communication (remote เช่น terminal)
  • External device: control logic + buffer + transducer (ตัวแปลงสัญญาณ)
  • ⭐ 5 หน้าที่: Control & timing, Processor communication (command decoding, data, status, address recognition), Device communication, Data buffering (ปรับความเร็ว), Error detection
  • Block: data registers, status/control registers, I/O logic, external device interface logic

วิธี ข้อสังเกต
Programmed I/O CPU สั่งแล้ว รอ/วนเช็ก status เสียเวลา CPU
Interrupt-driven สั่งแล้วไปทำอย่างอื่น, I/O interrupt ตอนพร้อม CPU ยังย้ายข้อมูลเอง
DMA I/O ↔ memory ตรง CPU ยุ่งแค่เริ่ม/จบ
No interrupts Interrupts

ผ่าน processor Programmed Interrupt-driven
ตรงถึง memory — DMA
  • I/O commands: Control (สั่งให้ทำ), Test (เช็กสถานะ), Read (ดึงจาก peripheral เข้า buffer), Write (จาก data bus ส่งไป peripheral)

⭐ Memory-mapped vs Isolated

Memory-mapped Isolated
address space ร่วม memory แยก address space
ไม่มีคำสั่ง I/O พิเศษ, ใช้คำสั่ง memory ได้มาก ต้องมี select lines + คำสั่งพิเศษ (จำกัด)
read/write line อย่างละ 1
  • ตัวอย่าง keyboard: data reg 516, status 517 (1 = ready, 0 = busy) | memory-mapped ใช้ Load/Store/Branch | isolated ใช้ Load I/O, Test I/O, Branch Not Ready, In

⭐ Interrupt processing

  • HW: device ส่ง interrupt → CPU จบคำสั่งปัจจุบัน → ส่ง ack → push PSW + PC ลง control stack → โหลด PC ใหม่
  • SW: save state ที่เหลือ → process interrupt → restore state → restore PSW + PC
  • interrupt หลังคำสั่ง N: push N+1 (SP T → T−M), PC = Y (ISR) → return ที่ Y+L แล้วกลับ N+1
  • Design issues: อุปกรณ์ไหนส่ง? และ ทำตัวไหนก่อน?

⭐ Device Identification

เทคนิค สรุป
Multiple interrupt lines ตรงไปตรงมา แต่แต่ละสายยังมีหลาย module
Software poll ISR poll ทุก module — ช้า
Daisy chain (HW poll, vectored) ack ส่งต่อเป็นโซ่, module ส่ง vector
Bus arbitration (vectored) ต้องได้ bus ก่อนจึงขอ interrupt → ส่ง vector ลง data lines
  • Vectored interrupt: ใช้ vector ชี้ไป device-service routine ตรง ไม่ต้องรัน general ISR ก่อน

ชิป Intel

  • 82C59A: slave รับ IR0–IR7 → master → INTR ของ 80386 (ต่อได้ถึง 64 อุปกรณ์ตามภาพ)
  • 8255A PPI: Port A (8), Port B (8), Port C upper/lower (4+4), Group A/B control
    • Control word D7 = 1: mode set (D6–D5 mode A: 00/01/1X, D4 Port A, D3 PC upper, D2 mode B, D1 Port B, D0 PC lower; 1 = input)
    • D7 = 0: bit set/reset Port C (D3–D1 เลือก bit, D0 1 = set)
  • Keyboard/Display กับ 82C55A: Port A = keyboard input, Port B = display output, Port C = handshake (data ready, ack, interrupt request)

⭐ DMA

  • ข้อเสีย programmed/interrupt: rate จำกัดด้วย CPU + CPU ถูกผูก → ข้อมูลมากใช้ DMA
  • DMA block: data count, data register, address register, control logic (request, ack, interrupt, read, write)
  • DMA breakpoint แทรกถี่กว่า interrupt (DMA เกี่ยวกับ bus ตรง; interrupt รอจบคำสั่ง)
  • Configurations: (a) single-bus detached (b) single-bus integrated DMA-I/O (c) I/O bus แยก
  • 8237: disk → DREQ → 8237 → HRQ → CPU → HLDA → 8237 → DACK → disk
  • Fly-by: ข้อมูลไม่ผ่าน/ไม่เก็บใน DMA chip, เฉพาะ I/O port ↔ memory; memory-to-memory ผ่าน register; 4 channels (0–3) active ทีละตัว
  • 8237A registers: Command, Status, Mode, Single Mask, All Mask (E/D = enable/disable, TC = terminal count)

⭐ DCA / DDIO

  • DMA scale ไม่ทัน network 10/100 Gbps และ Wi-Fi 3.2/6.76 Gbps
  • packet: Ethernet (link) → IP → TCP | NIC สร้าง packet ขาออก / ตัด Ethernet ขาเข้า
  • DMA ปกติ: application buffer ↔ system buffer ↔ NIC → ใช้ memory + cache หลายรอบ
  • Incoming: arrives → DMA → NIC interrupt → descriptors/headers → cache miss → header → payload
  • Outgoing: requested → created → output invoked → DMA → NIC completion → free buffer
  • DCA แบบง่าย (Xeon 2006–2010): incoming only, DCA function ใน memory controller ส่ง prefetch hint
  • Cache injection = DDIO (Xeon): ข้าม main memory ไป last level cache โดยตรง ทั้งขาเข้าและขาออก

Evolution & Channels

  1. CPU คุมเอง → 2. I/O module + programmed → 3. + interrupt → 4. DMA → 5. I/O module เป็น processor (instruction set เฉพาะ) → 6. มี local memory (คอมพิวเตอร์ในตัว)
  • I/O channel: Selector vs Multiplexor
