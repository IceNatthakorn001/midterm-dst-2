Fetch–Decode–Execute และ MARIE

Chapter 02 — Computer Systems & Processor Structure · ดูค่าไหลระหว่าง register กับ memory ทีละขั้น

  • 1. ตัวอย่าง Instruction cycle
  • 2. MARIE datapath (RTL)
  • 3. Multiple interrupts

1. ตัวอย่าง Instruction cycle (สไลด์ 14)

คำสั่ง 16 bit: 4 bit แรก = opcode, 12 bit หลัง = address (อ่านเป็น hex: 1940 = opcode 1, address 940) · opcode ในตัวอย่างนี้: 1 = Load AC, 2 = Store AC, 5 = Add to AC

⚠️ opcode ชุดนี้เป็นของตัวอย่างนี้เท่านั้น — ใน MARIE 5 = Input, 3 = Add

2. MARIE: Fetch–Decode–Execute แบบ RTL

โปรแกรม (สไลด์): 100 Load 104 · 101 Add 105 · 102 Store 106 · 103 Halt · ข้อมูล 104 = 0023, 105 = FFE9 (= −23) · MAR, PC = 12 bit · AC, MBR = 16 bit · bus กลาง 16 bit (เลข bus: 0 Memory, 1 MAR, 2 PC, 3 MBR, 4 AC, 5 InREG, 6 OutREG, 7 IR)

    ⚠️ ตารางในสไลด์เข้ารหัส Store 106 เป็น 4106 แต่ตาราง opcode ของ MARIE ในสไลด์เดียวกันให้ Store = 2 (4 = Subt) — แอนิเมชันนี้ใช้ 2106 ตามตาราง opcode

    ตาราง trace ของ Add 105 (ตรงกับสไลด์)

    3. Multiple interrupts (สไลด์ 44–45)

    มี user program + ISR 3 ตัว (Printer, Communication, Disk) — แบบ nested: ISR ที่กำลังทำอยู่ถูกขัดได้ แล้วกลับมาทำต่อทีหลัง (ต้องเก็บจุดที่ค้างไว้)

    สไลด์บอกเฉพาะเวลา t = 0, 10, 15, 25, 35, 40 — ไม่ได้บอก priority ของแต่ละอุปกรณ์หรือเวลาที่ disk ส่ง interrupt
