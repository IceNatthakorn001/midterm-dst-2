A. Data Representation

  • n-bit register: min 0, max 2ⁿ − 1 | Data → Quantitative (integers / non-integers × signed / unsigned) + Qualitative
  • ระบบเลข: decimal 0–9, binary 0–1, octal 0–7, hex 0–F
  • Signed มี 3 วิธี: Sign & Magnitude, Complement, Bias (Excess)

⭐ เทียบวิธีแทนค่าลบ (8 bit)

วิธี ช่วง ศูนย์ หมายเหตุ
S&M sign bit + magnitude −127..+127 (±(2ⁿ−1)) 2 ตัว กลับเครื่องหมาย/หา |a| ง่าย; บวกค่าลบ ≠ ลบ
1's กลับทุก bit = (2ⁿ−1) − m −127..+127 2 ตัว (+0, −0) carry → บวกกลับที่ LSB
2's 1's + 1 −128..+127 1 ตัว carry → ทิ้ง; ไม่ต้องมีวงจรลบ; คูณ/หารช้า
Bias 127 unsigned − 127 −127..+128 — 0111 1111 = 0
  • (r−1)'s = (rⁿ−1) − m | r's = rⁿ − m | decimal ใช้ 9's/10's (382 → 617 / 618)
  • ตัวอย่าง: 0101 → 1's 1010 (= −5) | 0101011 → 2's 1010101 | 6 + (−5): 0110 + 1011 = 1 0001 → 0001
  • Shortcut 2's: หา 1 ตัวแรกจาก LSB แล้วกลับทุก bit ที่ตามมา
  • ตาราง 1000 0000: S&M −0, 1's −127, 2's −128 | 1111 1111: S&M −127, 1's −0, 2's −1

⭐ Floating point / IEEE 754

  • N = (−1)ˢ × m × 2ᵉ (sign, mantissa, radix, exponent) | | Sign | Exponent | Mantissa | รวม | |---|---|---|---|---| | Single | 1 | 8 | 23 | 32 | | Double | 1 | 11 | 52 | 64 |
  • Single: N = (−1)ˢ × 1.m × 2^(E−127), E = e + 127 (เก็บ E)
  • E 1–254 (0, 255 สงวนไว้แทน ±∞, NaN) | e −126..+127 | m 1..(2 − 2⁻²³) | max 2 × 2¹²⁷ = 2¹²⁸
  • 101.1101₂ = 5.8125 | ทศนิยม → binary: คูณ 2 ไปเรื่อย ๆ (0.8125 = .1101)
  • 17.15 = 10001.0010011 = 1.00010010011 × 2⁴ → E = 131 → 0 | 1000 0011 | 0001 0010 0110 0000…

Characters / ASCII

  • Qualitative: letters, digits, symbols, control chars | 1 byte = 256 ตัว | ASCII, EBCDIC, Unicode
  • ASCII: 128 รหัส, 7 bit + parity | '0'–'9' = 48–57 (0x30–39), 'A'–'Z' = 65–90 (0x41–5A), 'a'–'z' = 97–122 (0x61–7A), space = 32
  • รหัสตัวเลข ≠ ค่าตัวเลข | ใหญ่-เล็กต่างกัน 0x20 (Shift clear bit 5) | A = 0100 0001, a = 0110 0001
  • Assignment 2: กลุ่ม 2 คน, 16 บิต, แสดง add/sub แบบ S&M และ 2's complement; Sec1 ส่ง 23 ส.ค. 2569, Sec2 25 ส.ค. 2569

B. RISC-V (PART I)

  • RISC-V: open ISA จาก UC Berkeley, ดูแลโดย RISC-V Foundation
  • ⭐ Design Principles: (1) Simplicity favours regularity (2) Smaller is faster (3) Good design demands good compromises | + Make the common case fast (immediate)
  • add a,b,c = 3 operands (2 source + 1 dest)
  • 32 × 64-bit registers | 64 bit = doubleword, 32 bit = word
Reg หน้าที่
x0 0
x1 return address
x2 / x3 / x4 sp / gp / tp
x5–x7, x28–x31 temporaries (callee ไม่รักษา)
x8 frame pointer
x9, x18–x27 saved (callee save/restore)
x10–x11 args/results
x12–x17 args
  • Memory: byte addressed, Little Endian (LSB ที่ address ต่ำสุด), ไม่บังคับ aligned
  • A[12] = h + A[8] → ld x9,64(x22) / add x9,x21,x9 / sd x9,96(x22) (offset = index × 8)
  • Register เร็วกว่า memory; spill เฉพาะตัวแปรที่ใช้ไม่บ่อย
  • Sign extension: lb sign-extend, lbu zero-extend | negate = complement + 1

⭐ Instruction formats (32 bit)

7 5 5 3 5 7
R funct7 rs2 rs1 funct3 rd opcode
I imm[11:0] (12) rs1 funct3 rd opcode
S imm[11:5] rs2 rs1 funct3 imm[4:0] opcode
Shift funct6 (6) + immed (6) rs1 funct3 rd opcode
  • add x9,x20,x21 = 0|21|20|0|9|51 = 015A04B3₁₆
  • I = immediate arithmetic + load | S = store (แยก imm เพื่อให้ rs1, rs2 อยู่ที่เดิม)
  • Stored program: คำสั่งเป็น binary เหมือนข้อมูล, binary compatibility → standardized ISAs

Logical / Shift / Branch

  • slli/srli, and/andi (mask), or/ori (set bits), xor/xori (กับ 1 ทุก bit = NOT)
  • slli i = ×2ⁱ | srli i = ÷2ⁱ (unsigned)
  • beq (==), bne (!=), blt (<), bge (>=) | unsigned: bltu, bgeu
  • x22 = 1111…1, x23 = 0…01 → signed: −1 < +1 | unsigned: 4,294,967,295 > 1
  • if-else: bne → add → beq x0,x0,Exit → Else: sub | while: slli, add, ld, bne Exit, addi, beq Loop
  • Basic block: ไม่มี branch ข้างใน (ยกเว้นท้าย), ไม่มี target (ยกเว้นต้น)

⭐ Procedures

  1. args ใน x10–x17 → 2. โอนการควบคุม → 3. จองที่ → 4. ทำงาน → 5. ใส่ผล → 6. กลับ (address ใน x1)
  • เรียก: jal x1, Label | กลับ: jalr x0, 0(x1)
  • Leaf = ไม่เรียกฟังก์ชันอื่น | Non-leaf = ต้อง save return address + args/temps บน stack
  • stack โตลง: addi sp,sp,-N / sd … / ld … / addi sp,sp,N
  • Memory layout (ล่าง→บน): Reserved → Text (code) → Static data (globals, x3 gp) → Heap (malloc/new) ↑ … ↓ Stack (sp)
  • Procedure frame = activation record
  • Character data: ASCII 128 (95 graphic, 33 control), Latin-1 256, Unicode 32 bit, UTF-8/16 ยาวไม่คงที่
  • lb/lh/lw sign extend, lbu/lhu/lwu zero extend, sb/sh/sw store 8/16/32 bit ขวาสุด

C. PART II (Self-study)

  • lui rd, const → 20 bit ไปที่ [31:12] (ใช้คู่ addi) | auipc = (imm<<12) + pc
  • Branch = SB format, PC-relative: target = PC + imm × 2 | jal = UJ format (imm 20 bit)
  • Addressing: Immediate, Register, Base, PC-relative | Types: R, I, S, SB, UJ, U
  • Sync: data race → atomic op; lr.d จอง address, sc.d สำเร็จคืน 0 / ล้มเหลวคืน ≠ 0
  • Translation: compiler → assembler → linker (merge segments, resolve labels, patch refs) → loader (header, VA space, copy, stack args, init regs, startup → main)
  • Object module: header, text, static data, relocation info, symbol table, debug info
  • Dynamic linking = link เมื่อเรียก, lazy linkage ผ่าน stub | Java: bytecode → JVM interpret / JIT compile hot methods
  • Lessons: IC และ CPI อย่างเดียวไม่ใช่ตัวชี้วัดที่ดี, Java/JIT เร็วกว่า interpret มาก, "Nothing can fix a dumb algorithm!"
  • Arrays vs Pointers: strength reduction (คูณ → shift), induction variable elimination → เขียนให้ชัดและปลอดภัยดีกว่า
  • MIPS: รุ่นก่อน RISC-V, ใช้ slt/sltu + beq/bne แทน blt/bge
  • Extensions: M mul/div, A atomic, F single FP, D double FP, C compressed 16-bit

⚠️ จุดที่สไลด์พิมพ์ไม่ตรง

  • สไลด์ 15 ใช้ชื่อ 1'/2' complement กับเลขฐานสิบ 382 (ตามนิยามคือ 9's/10's)
  • สไลด์ 44 add f, t0, t1 // f = t0 - t1 (ตัวอย่างสไลด์ 47 ใช้ sub)
  • สไลด์ 45 เขียน x0 to x30; สไลด์ 46 vs 76 นับ x8 ต่างกัน
  • สไลด์ 74 add x6,x12,x1 (j อยู่ใน x13) | สไลด์ 78 return f (โค้ดคืน 1) | สไลด์ 107 restore ใช้ sd
