1. The Internetwork

⭐ อินเทอร์เน็ตไม่ใช่เครือข่ายเดียว แต่คือ "เครือข่ายที่เชื่อมต่อเครือข่ายเข้าด้วยกัน" เครือข่ายหลายแบบต่อเข้า โครงข่ายหลัก (Global ISP / backbone) ตรงกลาง: เครือข่ายระดับภูมิภาค (บ้าน) + เครือข่ายองค์กร (เซิร์ฟเวอร์) + เครือข่ายมือถือ (เสาสัญญาณ) 💡 เหมือนระบบถนน — ซอยในหมู่บ้าน ถนนนิคมฯ ถนนในเมือง ต่างมีเจ้าของของตัวเอง แต่ทุกสายเชื่อมกับทางหลวงสายหลัก

2. มาตรวัดขนาดเครือข่าย ⭐

ระยะ พื้นที่ ประเภท เทคโนโลยี
1 เมตร พื้นที่ส่วนบุคคล PAN Bluetooth
10 ม. – 1 กม. ห้อง / อาคาร / วิทยาเขต LAN Ethernet, WiFi
10 กม. เมือง MAN Cable, 802.16
100 กม.+ ประเทศ / ทวีป WAN Optical Backbone, 5G
10,000 กม. โลก The Internet TCP/IP

💡 Personal → Local → Metropolitan → Wide → Internet = ตัวเรา → ตึก → เมือง → ประเทศ → โลก ⚠️ 802.16 = WiMAX (ระดับเมือง) อย่าสับสนกับ 802.11 (WiFi, ระดับ LAN)

3. PAN (Personal Area Network)

เครือข่ายไร้สายระยะสั้นรอบตัวบุคคล — โครงสร้างแบบ master-slave

  • Master device (สมาร์ทโฟน) — ควบคุมการเชื่อมต่อและจัดสรรความถี่
  • Slave devices (หูฟังไร้สาย, นาฬิกาอัจฉริยะ, เครื่องเสียงในรถ) — เชื่อมต่อแบบ Piconet
  • Technology: Bluetooth — ตัดปัญหาสายสัญญาณทับซ้อน 💡 Piconet = เครือข่ายเล็ก ๆ ที่มี master 1 ตัวคุม slave หลายตัว (เหมือนหัวหน้าห้องเรียกชื่อให้พูดทีละคน)

4. Home Access Networks + NAT

องค์ประกอบ หน้าที่
DSL/Cable modem เชื่อมโยงบ้านเข้ากับ ISP
Gateway เราเตอร์หลักที่เชื่อมบ้านเข้ากับ ISP
Convergence รองรับทั้ง Elastic (เว็บเพจ — รอได้ ปรับความเร็วได้) และ Time-Sensitive (สตรีมมิ่ง — ต้องทันเวลา)
IoT Integration เซ็นเซอร์และเครื่องใช้ไฟฟ้าที่ต้องการความเสถียร

⚠️ Elastic vs Time-sensitive: เว็บช้าไป 1 วินาทีไม่เป็นไร / วิดีโอคอลกระตุก 1 วินาทีใช้ไม่ได้

NAT (Network Address Translation) ⭐ ปัญหา: อุปกรณ์ในบ้านมีหลายเครื่อง แต่ ISP ให้ IP สาธารณะแค่ 1 ตัว

  1. เครือข่ายส่วนตัว: laptop 10.0.0.1, มือถือ 10.0.0.2, แท็บเล็ต 10.0.0.3 → ⭐ IP ภายในมีความหมายแค่ในบ้าน
  2. NAT Router: แปลงที่อยู่
  3. อินเทอร์เน็ตสาธารณะ: ออกไปด้วย IP สาธารณะเดียว 138.76.29.7 → ใช้ IP เดียวเป็นตัวแทนทั้งบ้าน 💡 เหมือนคอนโดที่มีที่อยู่ไปรษณีย์เดียว — นิติบุคคล (NAT router) จำไว้ว่าจดหมายตอบกลับส่งเข้าห้องไหน

5. Enterprise LAN + VLAN

โครงสร้างพื้นฐานมีสายความเร็วสูงแบบลำดับชั้น: Institutional Router (ต่อออกอินเทอร์เน็ต) → Core/Edge Switches → End Systems (Workstations, Servers)

จุดเด่น ความหมาย
Link-Layer Switches ขจัดปัญหาการชนกันของข้อมูล ส่งเฟรมแยกตามพอร์ตอย่างอิสระ
High Throughput 1 Gbps ถึง 10 Gbps
Resource Sharing แชร์ข้อมูลและเซิร์ฟเวอร์ส่วนกลาง
Physical (แบบเดิม) Logical (VLAN)
ข้อจำกัดทางภูมิศาสตร์ — การจัดกลุ่มถูกกำหนดโดยสายเคเบิล นิยามใหม่ด้วยซอฟต์แวร์ — จัดกลุ่มตามแผนกหรือความปลอดภัย ไม่ใช่ตามชั้นของอาคาร

💡 ฝ่ายบัญชีอยู่ชั้น 2 และชั้น 5 — physical ต้องเดินสายใหม่ / VLAN ตั้งค่าใน switch ได้เลย

6. WiFi (802.11)

Infrastructure Mode Ad-hoc Mode
สื่อสาร ผ่าน Access Point (Base Station) ที่เชื่อมกับ wired network อุปกรณ์สื่อสาร เองโดยตรง ไม่ต้องใช้โครงสร้างพื้นฐาน
WiFi บ้าน/ออฟฟิศ แชร์ไฟล์ระหว่างเครื่องโดยตรง
  • Bandwidth: แชร์ช่องสัญญาณวิทยุร่วมกันภายในรัศมี (ยิ่งคนใช้เยอะ ยิ่งแบ่งกันเยอะ)

7. Cellular 4G/5G + Handover

เครือข่ายไร้สายระยะไกลครอบคลุมระดับประเทศ — พื้นที่แบ่งเป็น เซลล์รูปหกเหลี่ยม

องค์ประกอบ หน้าที่
Mobile Device (UE — User Equipment) อุปกรณ์เคลื่อนที่ มีรหัสยืนยันตัวตนผ่านซิมการ์ด
Base Station (eNode-B) บริหารจัดการทรัพยากรคลื่นวิทยุในพื้นที่เซลล์
Core Network ศูนย์กลางการจัดการข้อมูลและการเคลื่อนที่

Mobility & Handover 3 ขั้น ⭐:

  1. Association — อุปกรณ์เชื่อมต่อกับเสาสัญญาณปัจจุบัน (Tower A)
  2. Coordination — ระบบประเมินความแรงสัญญาณและเตรียมโอนย้าย (อยู่รอยต่อ A กับ B)
  3. Handover — ส่งมอบการเชื่อมต่อไปยังเสาใหม่ (Tower B) โดยไม่ทำให้การดาวน์โหลดสะดุด 💡 เหมือนวิ่งผลัด — ไม้ถูกส่งต่อขณะวิ่ง โดยไม่ต้องหยุดการแข่งขัน

8. Data Center / The Cloud

โครงสร้างเป็นชั้น: Internet → Core Routers → Edge Switches (เชื่อมกับ core routers แบบไขว้กันหนาแน่น) → Server Racks

คุณสมบัติ ความหมาย
Massive Scale เชื่อมต่อโฮสต์ หลายหมื่นเครื่อง ในศูนย์ข้อมูลเดียว
Load Balancing กระจายภาระงาน ไม่ให้เซิร์ฟเวอร์ใดทำงานหนักเกินไป
Purpose ประมวลผลแบบขนานและให้บริการเนื้อหา (Netflix, Google)

9. Wired vs Wireless ⭐

Wired Wireless
ตัวกลาง สายทองแดง / ใยแก้วนำแสง คลื่นวิทยุ (Radio Spectrum)
Collision Mgt. สวิตช์แยกช่องสัญญาณ ป้องกันการชน ใช้สื่อกลางร่วมกัน ต้องมีกลไกหลีกเลี่ยงการชน
Mobility อุปกรณ์อยู่กับที่ (stationary) รองรับอุปกรณ์เคลื่อนที่และการโอนย้าย
เทคโนโลยี Ethernet, Fiber Backbone WiFi (802.11), 4G/5G, Bluetooth

10. A Day in the Life of a Packet

กดสตรีมภาพยนตร์ 1 เรื่อง:

  1. (PAN/Mobile) สมาร์ทโฟนส่งคำขอผ่านสัญญาณ 5G
  2. (Cellular Edge) Base Station รับสัญญาณและส่งเข้าโครงข่ายหลัก
  3. (Global WAN) ข้อมูลเดินทางข้ามประเทศผ่าน Optical Backbone
  4. (Data Center) Load Balancer ส่งคำขอไปยังเซิร์ฟเวอร์ที่เก็บภาพยนตร์

11. The Network of Networks (สรุป)

วงกลมซ้อนกันจากในออกนอก: PAN (1m) → LAN/Home (10m–1km) → MAN/Cellular (10km) → WAN/Internet (Global)

  • แต่ละประเภทถูกออกแบบมาเพื่อแก้ปัญหาเฉพาะทาง
  • จาก 1 เมตรถึง 10,000 กิโลเมตร ทุกเครือข่ายสื่อสารกันได้ผ่านโปรโตคอลมาตรฐาน

จุดที่มักออกสอบ

  1. อินเทอร์เน็ต = เครือข่ายที่เชื่อมเครือข่ายเข้าด้วยกัน
  2. ⭐ ตารางขนาดเครือข่าย: PAN 1 m Bluetooth / LAN 10 m–1 km Ethernet, WiFi / MAN 10 km Cable, 802.16 / WAN 100 km+ Optical backbone, 5G / Internet 10,000 km TCP/IP
  3. PAN: master คุมการเชื่อมต่อและความถี่, slave ต่อแบบ Piconet
  4. Home network: modem + gateway, convergence ของ elastic และ time-sensitive, IoT
  5. ⭐ NAT: IP ภายใน (10.0.0.x) มีความหมายแค่ในบ้าน → NAT router แปลงเป็น IP สาธารณะเดียว (138.76.29.7)
  6. Enterprise LAN: link-layer switches ขจัด collision, 1–10 Gbps, resource sharing
  7. VLAN: physical = กลุ่มตามสาย / logical = กลุ่มตามแผนกด้วยซอฟต์แวร์
  8. WiFi: infrastructure mode (ผ่าน AP) vs ad-hoc mode (คุยตรง); แชร์ bandwidth ในรัศมี
  9. Cellular: UE (SIM), eNode-B (คลื่นในเซลล์), core network (ข้อมูล + mobility)
  10. ⭐ Handover 3 ขั้น: Association → Coordination → Handover
  11. Data center: core routers → edge switches → server racks; massive scale, load balancing
  12. Wired vs Wireless: สื่อกลาง / collision (switch แยกช่อง vs หลีกเลี่ยงการชน) / mobility
  13. Packet journey 4 ขั้น: 5G → base station → optical backbone WAN → load balancer ใน data center
