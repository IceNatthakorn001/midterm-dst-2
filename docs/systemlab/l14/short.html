L14 – Windows System Admin (Lecture 14 + Lab 14)

ภาค Lecture

1. บทนี้เรียนอะไร (สไลด์ 1–4)

  • สัปดาห์ 14 = บริหารจัดการ Windows (ต่อจาก 13 Linux admin, ก่อน 15 System monitoring)
  • Objectives: Architecture · File Systems · Registry · Admin (User / File System / Process management)

2. Windows Evolution (สไลด์ 5)

  • ⭐ 1.0 Nov 1985 | 2.0 Dec 1987 | 3.0 May 1990 | 95 Aug 1995 | 98 June 1998 | ME Sep 2000 | XP Oct 2001 | Vista Nov 2006 | 7 July 2009 | 8.0 Oct 2012 | 8.1 Oct 2013 | 10 July 2015 | 11 October 2021

3. Boot (สไลด์ 6)

  • ⭐ F8 = Windows Boot Manager (กดทันทีที่เครื่องเริ่ม) | boot loader = boot manager = โปรแกรมเล็กที่โหลด OS เข้า memory | ⭐ F12 Boot Menu = เลือกอุปกรณ์บูต ระหว่าง POST (Power On Self Test)
  • Boot Menu ตัวอย่าง: Removable Devices, Hard Drive, CD-ROM Drive, Network boot

4. Architecture (สไลด์ 7, 15)

แก่นuser mode ↔ kernel mode, HAL ล่างสุดติด hardware

  • สไลด์ 7 ซ้าย: user-mode (Applications, Subsystem servers, DLLs, System Services, Login/GINA, Kernel32, Critical services, User32/GDI, ntdll) | kernel-mode (Trap interface/LPC, Security refmon, I/O Manager, Memory Manager, Procs & threads, Win32 GUI, ..., Object Manager / Configuration Management (registry), Kernel run-time / HAL)
  • สไลด์ 7 ขวา: Environment Subsystems (Session Manager, CSRSS), System Processes (Wininit, Winlogon, SCM), Services (Spooler, SvcHost), Applications → NTDLL.DLL → System Service Dispatcher → managers (I/O, Security Reference Monitor, Power, PnP, Memory, Process, Object, Configuration, ALPC), Windows USER & GDI, drivers, Kernel, HAL → Hyper-V Hypervisor
  • ⭐ Windows NT = layered (user mode + kernel mode), preemptive, reentrant multitasking, uni- และ multiprocessor
  • NT: Integral subsystems (Workstation, Server service, Security) | Environment subsystems (Win32, POSIX, OS/2) | Executive (Executive Services, I/O, Security Ref Monitor, IPC, VMM, Process, PnP, Power, Window Manager+GDI, Object Manager) | Kernel mode drivers, Microkernel | HAL | Hardware

5. Windows Components (สไลด์ 8)

  • Application icon, Title bar, Minimize / Maximize / Close button, Menu bar, Client area, Vertical / Horizontal scroll bar, Sizing border

6. Volume / Directory / File (สไลด์ 9–10)

  • ⭐ Volume = collection of directories & files | Directory = hierarchical collection | File = logical grouping of related data
  • User's view: Linux เปิดจากราก (bin, etc, home, ...) | Windows: This PC › Local Disk (C:) (PerfLogs, Program Files, Program Files (x86), Users, Windows)

7. File systems (สไลด์ 11–12)

  • ⭐ Windows มี 3 FS: NTFS, FAT32, FAT16 | FAT โดย Microsoft 1977 | ตระกูล FAT: FAT12, FAT16, FAT32, exFAT
FAT32 NTFS exFAT
⭐ Max volume 32GB 16TB 128 PB (แนะนำ 512 TB)
⭐ Max file 4GB 16TB 128 PB (theoretical 16 EB – 1 byte)
Cluster 4–32 KB 4 KB 32MB
Fault tolerance No Auto repair Yes ถ้าเปิด TFAT
Conversion Possible Not Allowed Not available
Compression No Yes No
Performance สูงบน volume เล็ก ต่ำบนใหญ่ ต่ำบนเล็ก สูงบนใหญ่ High
Compatibility ทุก Windows, macOS, Linux, PS3/4, Android, iPhone ฯลฯ ทุก Windows, Mac OS X (read-only), Linux ทุก Windows, PS4/5

8. FAT chain (สไลด์ 13–14)

แก่นentry = ชื่อ + ขนาด + cluster แรก · ช่อง FAT N = cluster ถัดไป · จบที่ EOF

  • ⭐ FAT16 = 16-bit → 65,536 clusters (สไลด์เขียน 65.536 = จุดคั่นหลักพัน)
  • ⭐ file.txt (20000, 4k cluster, เริ่ม 50): 50 → 51 → 52 → 160 → 130 → EOF (5 cluster)
  • File.dat (10000 Bytes, เริ่ม Cluster 16): 16 → 17 → 18 → 19 → 20 (EOF)
  • FAT ช่อง 2–9 = 0003, 0004, FFFF, 0006, 0008, FFFF, FFFF, 0000 → FILE1 = 2,3,4 | FILE2 = 5,6,8 | FILE3 = 7 | ช่อง 9 = 0000 ไม่มีไฟล์ชี้

9. Disk Management (สไลด์ 16)

  • คอลัมน์: Volume, Layout, Type, File System, Status, Capacity, Free Space, % Free
  • C: NTFS 118.02 GB (free 54.50, 46%) | D: NTFS 931.50 GB (free 436.74, 47%)
  • Disk 0 (931.50 GB) = D: (Page File, Basic Data) | Disk 1 (119.23 GB) = 500 MB EFI System + 100 MB + C: (Boot, Crash Dump, Basic Data) + 637 MB Recovery

10. NTFS (สไลด์ 17–18)

  • ⭐ MFT = central system structure | เก็บ หลายสำเนา ของส่วนสำคัญของ MFT กัน corruption
  • MFT Entry = MFT Entry Header + MFT Attributes Header + MFT Attributes Content + Unused Space
  • ⭐ ส่วนประกอบ: PBS + MFT + meta files | เรียง: PBS | MFT | System Files | File Area

11. PBS (สไลด์ 19)

  • ⭐ format จอง 16 sector แรก ให้ boot sector + bootstrap code
  • 0x00 Jump Instruction (3) | 0x03 OEM ID (LONGLONG) | 0x0B BPB (25) | 0x24 Extended BPB (48) | 0x54 Bootstrap Code (426) | 0x01FE End of Sector Marker (WORD) → รวม 512 bytes

12. MFT (สไลด์ 20–23)

  • ⭐ record ทุกไฟล์ | 16 record แรก = special data | record 1 = MFT | record 2 = MFT mirror | record 3 = log file (file recovery)
  • ⭐ record แรกเสีย → อ่าน record 2 หา MFT mirror (record แรกเหมือนกัน)
  • boot sector เก็บตำแหน่ง MFT + mirror | สำเนา boot sector อยู่ logical center ของดิสก์
  • ⭐ ไฟล์/dir ≤ 1500 bytes อยู่ใน MFT record ทั้งหมด | ไฟล์ใหญ่ชี้ไปหลาย extent (สไลด์ 21)
  • สไลด์ 22: MFT → File Entry ใน Directory Data → MFT record → File | Bitmap = 0,1 marking for each cluster | ดิสก์มี MFT, MFT Mirror, Directory, File

13. NTFS metadata (สไลด์ 24)

  • system files ซ่อนทั้งหมด | ใช้ implement FS + เก็บ metadata | Format utility เขียนลง volume
  • File System Metadata (PBS + MFT + System Files) | User Files

14. Registry (สไลด์ 25–27)

  • ⭐ hierarchical database เก็บ low-level settings ของ Windows + โปรแกรม | ผู้ใช้: kernel, drivers, services, SAM, UI | มี performance counters
  • ติดตั้งโปรแกรม → เพิ่ม subkey (location, version, วิธี start)
  • เปิด: search Registry editor | path ตัวอย่าง Computer\HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control | ค่า: Name / Type (REG_SZ, REG_DWORD, REG_MULTI_SZ) / Data
  • ⭐ subtrees (root) → keys → subkeys (เหมือนโฟลเดอร์)
  • ⭐ 5 subtree: HKEY_CLASSES_ROOT, HKEY_CURRENT_USER, HKEY_LOCAL_MACHINE, HKEY_USERS, HKEY_CURRENT_CONFIG

15. สร้าง user (สไลด์ 28–31)

  • ⭐ Start > Settings > Accounts > Family & other users > Add someone else to this PC → test (Local account)
  • Other users = ไม่ใช่ family "This won't add them to your family" | Add a family member อยู่ส่วน Your family

16. Permission (สไลด์ 32–36)

  • ⭐ 6 แบบ: Full Control, Modify, Read & Execute, List Folder Contents, Read, Write
  • ⭐ Full Control = view names/subfolders, navigate, view data, add, change, delete, change permissions, take ownership
  • ⭐ เพิ่ม user: Properties → Security → Edit → Add... → พิมพ์ "test" → OK → OK
  • ตั้งสิทธิ์: Properties → Security → เลือก user → ติ๊ก checkbox (Allow/Deny) → Apply → Okay
  • ตัวอย่าง test ได้ Allow: Read & execute, List folder contents, Read

17. Process (สไลด์ 37)

  • ⭐ Start → Task Manager → คลิกขวาหัวคอลัมน์ เลือก Type, PID, CPU ฯลฯ → kill = คลิกขวาโปรแกรม → End Task
