2. สร้าง / คัดลอก / ย้าย / ลบไฟล์ L2–L3

คำสั่งความหมายตัวอย่างบท

$ touch test2
$ file test2  → test2: empty
L3
> ไฟล์สร้างไฟล์ว่าง — ถ้ามีอยู่แล้วจะล้างเนื้อหาทิ้ง

$ echo "Computer System LAB" > test4
$ file test4  → test4: ASCII text
L2–L3

mv ต้นทาง ปลายทาง ⭐move เปลี่ยนชื่อ หรือย้ายไฟล์ (ต้นฉบับหายไป)

$ mv test5 myfile5

6. สิทธิ์ไฟล์ (Permission) L5

คำสั่งความหมายตัวอย่างบท
chmod เลข ไฟล์ ⭐change mode แบบตัวเลข — r=4 w=2 x=1 บวกกัน 3 หลักเรียง user–group–other · กำหนดสิทธิ์ใหม่ทั้งหมด
$ chmod 755 foo
$ ls -l foo  → -rwxr-xr-x ... foo
$ sudo chmod 700 test2   → drwx------
$ sudo chmod 750 test2   → drwxr-x---
L5
chmod u/g/o ± r/w/x ⭐แบบตัวอักษร — แก้เฉพาะส่วนที่ระบุ · u owner, g group, o other (เพิ่ม a ทุกกลุ่ม, = กำหนดให้เท่ากับ)
$ chmod g+w sample.txt   → เพิ่ม write ให้ group
$ chmod o-r sample.txt   → ลบ read ของ other
$ chmod +x sample.txt    → เพิ่ม execute ทุกกลุ่ม
$ chmod g+x foo  → -rw-r-xr-- ... foo
L5
chown user ไฟล์ ⭐change owner เปลี่ยนเจ้าของ · user:group เปลี่ยนทั้งคู่ · :group เปลี่ยนแค่กลุ่ม · ต้อง sudo
$ sudo chown test3 foo   → -rw-r-xr-- 1 test3 root ...
$ chown games test       → owner = games
$ chown :staff test      → group = staff
$ sudo chown test1:test1 /home/test1
L4–L5
chgrp group ไฟล์change group เปลี่ยนกลุ่มของไฟล์/directory (ไม่แตะสิทธิ์ rwx)
$ sudo chgrp group2 test2
→ drwx------ 3 test2 group2 ... test2
L5

4 r--   5 r-x   6 rw-   7 rwx
